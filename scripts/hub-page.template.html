앱 전체구조 (hub/STRUCTURE.md, 흐름은 손으로 · 영역별 코드는 코드에서 자동)

모든 채팅이 시작할 때 읽고, 코드를 고칠 때 여기서 영향 범위를 본 뒤 같은 커밋에서 고칩니다. 새 화면 파일·API·페이지에 영역이 없으면 CI structure가 실패합니다.

광고 구조 (hub/ADS.md, 원칙은 손으로 · 자리·설정·손익은 코드에서 자동)

광고 자리·설정을 바꾸는 채팅이 먼저 읽습니다. 영역 이름(call 같은)을 누르면 앱 전체구조의 그 영역으로 갑니다. 새 전면 광고 순간에 설명이 없으면 CI ads-map이 실패하고, main push 때 아래쪽은 저절로 다시 만들어집니다.

저장하는 데이터 (hub/data-map.md, 코드에서 자동)

키 묶음마다 기능·누구 것·보관 기간·계정을 지울 때 어떻게 되는지. 새 키에 설명이 없으면 CI가 실패하고, 점검 데이터(simcheck-)는 점검이 끝날 때 지워집니다.
