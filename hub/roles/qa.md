# 내부 점검

## 맡는 일
- 바뀐 기능을 실제 입력으로 돌려 보고, 화면을 찍고, 통과/실패와 어긋난 점을 남긴다.
- 언어 조합 점검: 영어/한국어 외에 최소 셋 — 일본어·중국어·태국어 학습/한국어 앱,
  영어 학습/일본어 앱, 스페인어 학습/아랍어 앱(오른쪽→왼쪽).
- 기기에서만 볼 수 있는 것(영상, 아이콘, 업데이트 안내)은 사용자에게 확인 목록으로 넘긴다.

## 하지 않는 일
- 찾은 문제를 직접 고치지 않는다. `inbox.md`에 `qa → dev` 로 넘기고 사용자에게 알린다.
- 확인을 "좋아 보일 때까지" 반복하지 않는다. 한 번 돌리고 결과를 남긴다.

## 시작할 때
1. `git pull`, `inbox.md`에서 `→ qa` 항목(무엇을 볼지) 확인.
2. `npm run build:capacitor`로 지금 main을 빌드. 무엇을 볼지는 `PRODUCT.md`의 기능·대표 장면 기준.

## 도구
- 언어 조합 자동 점검: `npm run check:browser-languages`
  (PLAYWRIGHT_MODULE, CHROMIUM, LANGUAGE_PASS_USER, API_BASE 환경변수).
- 문구 누락: `npm run check:strings`, `npm run check:languages`.
- 테스트 사용자는 날짜를 붙여 새로 만든다 (`x-rc-user: <이름>-YYYYMMDD`).
  무료 채팅은 하루 10번이라 같은 사용자로 오래 돌리면 막힌다.
- 스크린샷은 `tmp/verify/YYYY-MM-DD/`에 (git에 안 올라감).
- **가상 사용자 점검** `npm run sim:users` (`scripts/sim-users/`): 속성 조합 페르소나(언어 배경·수준·약점·태도·입력·이상 행동, pairwise 46행)가
  14×14 학습 조합에 운영 API로 앱 기능을 써 본다. **기능 묶음**(`--suite`, `--list`): chat(채팅·표현 카드, 전원) · map(지도·미션, 7명 중 1명, gpt-4.1이라 비쌈) ·
  next(오늘 해볼 것·요약·자라는 중·내 표현, 전원, 모델 없음) · ask(직접 묻기, 2명 중 1) · sheet(해석·문장분석·표현 자세히·빠른 질문·단위·단어장, 2명 중 1) ·
  pack(통화 턴은 받아쓴 글로·오늘의 팩 en/ja, 4명 중 1, 포인트 안 씀) · rooms(방장·손님 임시 계정 2개: 프로필 저장·다른 사람이 보기·팔로우·손들기·올리기·내리기·내보내기·차단 시 목록 숨김, 신고는 입력 검사만, 끝에 삭제, 28명 중 1).
  `--suite all`(196명 × 3턴 약 3,300요청·$5, map 빼면 약 2,500요청·$2.5) · `--full`(비율 무시) · `--only th:*` · `--persona p042` · `--api <미리보기>` ·
  `--rescan <폴더>`(채팅만 재검사, 요청 0) · `--judge`/`--llm-persona`(OPENAI_API_KEY, 사용자 PC). 결과 `tmp/sim-users/<실행>/report.html`(히트맵·묶음별·종류·속성별·실패 대화와 재현 명령).
  사용자 id `simcheck-<실행>-pNNN`(비용 보고 제외). 한 사람 안에서 채팅 턴 + 미션 확인 2 + 직접 묻기 1이 무료 하루 10번을 넘지 않게(턴 ≤ 6).
  **기능 화면 찍기** `npm run sim:screens -- [--combos ja:ko,en:ja,es:ar,en:ko] [--scenes …]`(www 필요): 24장면(채팅·문장분석·단어장·지도·미션·오늘 해볼 것·자라는 중·직접 묻기·
  내 표현·통화·영상·사용법·의견·프로필·편집·방 목록·방 안·댓글 학습 언어로·방장 프로필)을 실제 입력으로 찍고, `node scripts/sim-users/gallery.mjs <폴더>`로 그림을 담은 한 장 갤러리.
  2026-10-18 갤러리: https://claude.ai/artifact/72hmTUMxEEy5xxkDXcFwtb (4조합 96장, 막힘 0). 한 조합 약 5분, 채팅 7번.
  **새 서버 기능을 만들면 `suites/`에 묶음을 하나 더한다.** 시드 문장 `bank.json`은 원어민 검수 전. 테스트 `npm run test:sim`.

## 최근 결과 (2026-10-18, 기능 묶음 전체 · 196명 × 3턴 · 운영 API)
- 첫 전체 실행(`all-suites-20261018`, map 포함): 오류 16 · 경고 47. 고친 것(서버, 바로 반영):
  단어장 검색이 검색어를 그대로 돌려줌(id·zh '累'→'累') → 학습 언어 문자 아닌 표제어 버리고 다시 묻기(첫 판이 중국어 학습을 전부 버려 바로 고침, `vocabScript.ts`),
  표현 자세히 예문에 앱 언어 섞임 → 거름(`exampleLanguage.ts`), 통화 팁이 학습 언어로만 → 버림(«» 따옴표도 인용으로), 표현 카드가 다른 언어 → 언어 밝혀 다시 묻기.
- 고친 뒤(`all-suites3-20261018`, map 빼고 2,519요청): **오류 1 · 경고 13.** 남은 오류는 통화 턴 간헐 502 `NO_DIRECTION`(두 실행에 1번씩, 통화 턴 약 140번에 1번, 다시 돌리면 재현 안 됨 → dev).
  지도·미션(28명 실행): 지도·미션·확인·진행·복습·지도에 넣기 모두 동작, 지도 그리기 10~15초.
- 경고로 남긴 것: 말투(존댓말) 실수 안 고침·중국어 '把' 안 고침(모델 판단), 같은 라틴 문자끼리(es↔id·pt)는 통화 팁·뜻 질문 언어를 못 가림,
  뜻 질문에 질문을 번역해 버림 2/30, 설명 속 낱말에 다른 문자가 붙음 1~2건.
- 사용자 결정 필요: "자라는 중" 정확도는 문장부호·대문자만 고쳐도 '고침'이라 안 오름 — 폰으로 마침표 없이 쓰는 사람은 맞게 써도 정확도가 0(받아쓰기형 29명 전원).
- 기능 화면(같은 날 오후): 24장면 × ja/ko·en/ja·es/ar·en/ko = 96장 모두 찍힘, 방·프로필 묶음(2명) ar/th·ko/ja·es/ar 통과.
  눈에 띈 것: 방 화면 문구가 한국어 앱 밖에서는 영어(시험 기능이라 ko/en만 — dev 열린 일에 있음).
- 못 한 것: 소리·결제·다음 날 복습, 영상 재생(YouTube 막힘 — 목록만), LLM 평가(키 없음).
