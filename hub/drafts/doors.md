# 창구(door) — 겉은 여러 서비스, 속은 하나 (2026-10-20)

사용자 결정: "서비스 전체를 하나의 유입창구로 만들기보다 보이스룸·채팅·통화 등 여러 창구로 유입, 겉으로는 다른 서비스 같지만 내부적으로는 하나".
"랜덤채팅이라고 검색해도, 단체통화로 검색해도 유입되도록". 첫 창구 단체통화 → 만듦. 랜덤채팅은 "가(본인인증 정식)·나(규제 밖 설계)를 섞은 방식" 검토.

## 구조 (코드)
- `src/lib/doors.ts`: 창구 한 묶음 = id·하위 도메인·이름·기본 언어·첫 화면·하단 탭·색(`[data-door]` 토큰)·소개 글 14개 언어.
- `next.config.ts` rewrites: `<host>.languagebank.net` 의 `/` → `/door/<id>`, `/<언어>` → `/door/<id>/<언어>`, `?screen=` 붙으면 앱 그대로.
- `src/app/door/[id]/[[...lang]]/page.tsx`: 소개 페이지(서버, 60초마다 열린 방 수), hreflang·canonical. 앱 정적 빌드에서는 뺌.
- 앱(`AppHome`): 창구 주소(또는 확인용 `?door=<id>`)면 창구 모드 — 첫 화면·하단 탭·상단 이름표·탭 제목. 기기에 저장하지 않음.

## 지키는 것
- 구글 스팸 정책 "출입구 페이지"(비슷한 검색어용 사이트를 여럿 만들어 한 곳으로 몰기)에 걸리지 않게: 창구마다 실제로 다른 쓸모, 그 주소에서 바로 씀. 비슷한 창구를 찍어내지 않는다.
- 운영자(languagebank)는 숨기지 않는다(페이지 아래). 사람 이름·방 이름은 소개 페이지에 싣지 않는다.
- 앱 스토어는 앱 하나(비슷한 앱 여러 개는 Play "반복 콘텐츠" 정책 위험).

## 사람이 할 일 (창구마다)
1. Vercel 프로젝트 → Domains → `call.languagebank.net` 추가.
2. 가비아 DNS: 호스트 `call`, 타입 CNAME, 값은 Vercel이 보여 주는 값(보통 `cname.vercel-dns.com`).
3. Google Cloud OAuth 클라이언트: 승인된 자바스크립트 원본·리디렉션 URI에 `https://call.languagebank.net` 추가(웹 Google 로그인).
4. 서치 콘솔에 `call.languagebank.net` 등록 → 사이트맵/색인 요청.

## 랜덤채팅 — 가+나 섞기 (안)
배경: 2020-12부터 랜덤채팅 앱은 ①본인인증 ②대화 저장 ③신고가 없으면 청소년유해매체물(19금). 기능(모르는 사람과 무작위 연결)으로 판단.

두 단계로:
- **기본(로그인만, 나):** "지금 접속한 사람" 목록 — 무작위가 아니라 언어가 맞는 사람(내 배우는 말 = 상대 쓰는 말)을 프로필(사진·소개·언어)과 함께 보여 주고, 내가 골라 대화 요청 → 상대가 수락하면 1:1(지금 메시지 요청 흐름). 모르는 사람과 자동 연결이 아니라 서로 보고 고르는 구조.
- **바로 연결(본인인증한 성인만, 가):** "아무나 바로" 버튼 — 언어 맞는 접속자와 즉시 1:1 연결(채팅 또는 음성), 다음 사람으로 넘기기. 본인인증(만 19세 이상 확인)한 사람끼리만 연결, 대화 30일 보관(지금 1:1과 같음), 신고·차단 바로.
- 검색어는 둘 다 "랜덤채팅·외국인 랜덤채팅·언어교환 채팅"을 겨냥하되 창구 이름과 소개는 "바로 연결"을 앞에.
- 필요한 것: 본인인증 업체 계약(포트원 등으로 다날·KCP 휴대폰 인증, 사업자 필요, 건당 비용), 접속자 표시(지금 presence 있음), 매칭 대기열(서버 새 키 묶음), 미성년 차단.
- 확인 필요: 위 구조가 규제 범위에 드는지는 법률 확인(Claude는 법률 전문가 아님).

## 무작위 연결 검토 (2026-10-21, 법률 확인 전 조사)
- 국내(여가부 고시, 2020-12-11 시행): "익명의 상대와 무작위 1:1 연결"이 대상. ①실명·휴대폰 인증 ②대화 저장 ③신고 셋 다 있으면 지정 제외, 없으면 19금(표시 안 하면 2년/2천만, 미성년 안 막으면 3년/3천만). 지인 대상·다른 서비스 연계 채팅·공개 게시판은 제외.
  우리는 ②(1:1 30일 보관)·③(신고) 있음 → ①만 붙이면 법 요건은 맞출 수 있다.
- 걸림돌: 휴대폰 본인인증은 한국 번호만 됨 → 무작위 연결 쪽에 외국인이 거의 못 들어와 언어 교환 취지와 어긋남. 해외 신원 확인(여권 등)이 ①로 인정되는지는 법률 확인.
- iOS: App Store 지침 1.2(2026-02 개정)에 "random or anonymous chat"이 주 용도인 앱은 예고 없이 내릴 수 있다고 명시 → iOS 앱에는 무작위 연결 넣지 않음(`platform.ts`에서 끔). 웹·안드로이드만 검토.
- 중간안(법·스토어 위험 낮음, 인증 없이 가능): "추천 한 명" — 서버가 언어 맞는 접속자 한 명을 프로필과 보여 주고 내가 요청, 상대 수락(지금 흐름 그대로, 고르는 수고만 줄임). "동시 수락 매칭"(둘 다 찾기 → 서로 프로필 보고 둘 다 수락)은 무작위로 볼지 애매 → 법률 확인.

## 랜덤 창구 Spin (2026-10-21, 사용자 결정 "Pingo에서 파생된 별도 웹·하위 주소·다른 이름, 미성년은 랜덤만 막기, 앱은 보류")
- 나눈 이유: 랜덤은 위험·평판·광고 정책(AdSense)·스토어 정책(애플 1.2)을 한곳에 가둔다. Pingo는 "골라서 요청" 그대로.
- 코드: 창구 `random-meet`(`lib/doors.ts`, `webOnly`), 🎲 탭 `random`(`RandomScreen.tsx`), `/api/random`(status·verify·join/poll·leave), `server/randomStore.ts`(성인 기록·ci 해시·대기열·짝), `server/identityVerify.ts`(포트원 조회),
  `lib/random/protocol.ts`(나이 규칙·언어 맞춤), 짝 = `dmStore.openThreadDirect`(요청 없이 열린 1:1) + 영상이면 비공개 영상 방(`RoomMeta.random` → 상대 영상 흐림, 눌러야 보임).
- 법 요건 맞추기: ① 본인인증(성인만) ② 1:1 대화·통화 자막 30일 ③ 신고·차단. 운영자가 막기: KV `random:v1:off:<ci해시>`(손으로, ci 기준이라 새 계정도 막힘).
- 사람 할 일 문서(체크리스트·켜는 순서·OmeTV 비교·AI 영상 검열 제안): https://claude.ai/code/artifact/44d51b53-1373-4156-a23f-39e39824dc4d
- **켜기 전 사람 일:** ①사업자 등록 ②포트원 가입 + 본인인증 채널(다날 또는 KG이니시스, 건당 비용) → `PORTONE_API_SECRET`·`NEXT_PUBLIC_PORTONE_STORE_ID`·`NEXT_PUBLIC_PORTONE_IDV_CHANNEL_KEY`
  ③법률 확인(고시 요건·해외 신원 확인 인정 여부) ④가비아 CNAME `spin` → Vercel 도메인 ⑤Google 로그인 원본에 `https://spin.languagebank.net` ⑥처리방침에 본인인증 항목 ⑦Vercel `RANDOM_ENABLED=1`.
- 외국인: 휴대폰 본인인증은 한국 번호만 → 처음에는 한국 번호 인증자만 랜덤. 해외 신원 확인(여권·얼굴 등)은 법률 확인 뒤.
- 아직 없는 것: 대화 안 "다음 사람" 버튼(지금은 Spin 탭으로 돌아와 다시 누름), 신고 누적 자동 막기, 랜덤 대화의 영상 노출 자동 감지, 대기 중 인원 표시.
