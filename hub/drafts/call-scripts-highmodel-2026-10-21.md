# 통화 탭을 고가 모델이 쓴 대본으로 — 가능한지 시범 (2026-10-21)

- 요청: 사용자 "문장 은행 설계, 스크립트 설계를 고가 모델에 맡겨서 통화 탭을 고퀄리티의 스크립트로 대체 가능한지 봐줘".
- 결론: **가능하고 이득이 크다. 다만 "대체"가 아니라 "대본이 받는 몫을 크게 늘리기"** — 대본 밖 말은 지금처럼 살아 있는 튜터(디렉터)가 받는다. 시범에서 진짜 막힌 곳은 글이 아니라 **대답 맞추기**였고, 싼 모델로 가지를 고르게 하면 풀린다.

## 지금 통화 탭

- 구조는 이미 대본용: 상황 31개 요약(`roleplay/situations.ts`) → 그래프 대본(`script.ts`, 가지가 갈라졌다 다시 만남) → 튜터 줄은 미리 녹음(`build-roleplay-audio.mjs`, 모두가 같은 파일) → 대본이 못 받는 차례만 디렉터 모델(`director.ts`).
  초안·검토 도구도 있음(`draft-roleplay-scenario.mjs` gpt-4o-mini, `draft-roleplay-repertoire.mjs` gpt-4.1, `review-roleplay-lines.mjs` gpt-5-mini) — 사람이 읽는 단계가 늘 병목("태국어 문장을 읽고 자연스러운지 말할 사람이 없음").
- 채운 정도: 영어 대본 8개·문장 120, 일본어 문장 55, **나머지 12개 언어는 인사·작별 2줄뿐** — "그냥 대화" 한 장면에서 튜터 말을 매 턴 모델이 쓰고 음성을 그때 합성(턴당 어림: 디렉터 0.6원 + 합성 2.1원 + 받아쓰기 0.4원 ≈ 3.1원, 응답도 느림).

## 시범: 한국어 카페 주문 한 장면

1. **초안(Opus 5.5)**, 기존 요약·규칙 그대로(배우는 사람은 영어 화자): 29마디·문장 16·받아 주는 학습자 표현 127개. 앱 규칙 검사(도달·끊긴 연결·끝 하나·학습자→학습자 금지·표현 2개 이상) **전부 통과**. 영어 카페 대본은 13마디.
2. **원어민 검토(Fable, 쓴 모델과 다름)**: "고쳐서 내보내기" — 튜터 문장 16개 중 15 ok, 1 고침(현금 받는 줄 순서·금액), 학습자 표현 고침 2·빼기 1, 더 받을 표현 39개 제안, 흐름 제안(가격 말하기, 아이스/따뜻한 것 묻기). "포장이세요?" 못 알아들었을 때 쉬운 말로 다시 묻는 회복은 좋은 가르침으로 평가.
3. **걸어 보기**(Sonnet이 초급 학습자 15명씩 마디마다 120개 대답, 뜻 표시) → 앱의 실제 맞추기(`session.ts judge`)로 채점:

| 장면 | 보통 난이도(3)에서 대본이 받은 대답 | 엉뚱하게 다른 가지 | 대본 밖 말을 대본이 잘못 받음 |
|---|---|---|---|
| 한국어 카페(Opus 초안) | 51% | 0 | 0/12 |
| 영어 카페(지금, 사람이 검토) | 60% | 0 | 3/13 |
| 한국어 카페 + **싼 모델(Haiku)이 가지 고르기** | **90%** | 0 | 0/12 |

- 떨어진 이유: 맞추기가 낱말 겹침이라 한국어처럼 조사·어미가 붙는 말에 약함("라지로 할게요" ≠ 받는 표현 "라지요"). 영어도 40%가 떨어짐("big one please" 등).
- Haiku 가지 고르기: 규칙이 못 맞춘 대답만, 그 마디의 가지 목록(뜻 + 예시)에서 하나 또는 "없음". 떨어진 53개 중 42개를 맞게 살림, 틀린 가지 0, 대본 밖 말 12개는 모두 "없음"(살아 있는 튜터로). 한 번 약 0.06원(입력 400 토큰 안팎).

## 제안 — 만든다면

1. **가지 고르기(서버, 앱 빌드 없이 시작 가능):** `roleplay/turn`에서 `judge`가 못 맞추면 디렉터 전에 Haiku(llm.ts basic)로 가지 고르기 → 녹음된 줄 재생. 디렉터는 "없음"일 때만. 비용은 턴당 오히려 줄고(디렉터+합성 3원 → 0.06원) 응답도 빨라짐. 영어 대본에도 바로 효과(60% → 비슷하게 오를 것).
2. **대본 만들기 공장(한 번 비용):** 상황 31개 × 14개 언어 = 434장면, 언어마다 "그냥 대화"용 문장 은행(약 120~200줄).
   초안 Opus → 다른 고가 모델 원어민 검토 → 고쳐 쓰기 → 걸어 보기(가상 학습자) 통과 기준(예: 보통 난이도 85% 이상, 잘못 받음 0) → 언어마다 첫 장면은 사람(가능하면 원어민) 확인 → 녹음.
   어림: 장면당 모델 약 $0.4(초안·검토·걸어 보기) → 434장면 약 $175(25만 원 안팎) + 녹음 약 7,500원. 문장 은행 12개 언어 약 $10.
3. **녹음 파일 위치:** 지금은 앱 안(`public/`, 영어 8장면 4MB). 434장면이면 약 200MB라 **서버(Blob/CDN)에서 받아 기기에 저장**으로 바꿔야 함 — 앱 빌드 필요(스크립트 주석이 이미 예고한 길).
4. 효과(어림): 영어 밖 언어 통화 한 턴 약 3.1원 → 대본 90%면 약 0.7원, 첫 소리는 녹음이라 바로. 품질은 사람이 안 읽어도 두 모델 + 걸어 보기로 "고쳐서 내보내기" 수준.

## 위험·정할 것

- 대본은 레일처럼 느껴질 수 있음 — 가지·회복·디렉터가 받쳐서 지금 구조로 완화. "그냥 대화"는 대본이 아니라 문장 은행 + 디렉터로.
- 원어민 확인: 모델 두 개로 거의 되지만, 언어마다 첫 장면(또는 10%)은 사람 확인을 권함.
- 순서 제안: ① 가지 고르기(서버) → ② 한국어·일본어·스페인어부터 장면 공장 → ③ 녹음 파일 서버로(앱 빌드) → ④ 나머지 언어.

파일: 초안·검토는 `hub/drafts/pilot-call-scripts/`(draft-cafe-ko.json, review-cafe-ko.json). 걸어 보기 대답·가지 고르기 결과는 스크래치(사라짐).
