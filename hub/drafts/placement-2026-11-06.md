## 3. ② 단어 범위 — 계산

**예/아니오(Yes/No) 체크** — 어휘 크기 시험에서 쓰는 방식(가짜 낱말로 "안다"고 과장하는 것을 바로잡음).

- 한 장에 낱말 하나 + [앎] [모름]. 읽기가 있는 언어는 읽기 줄, 글자를 못 읽으면 🔊만.
- 진짜 낱말 30개: 순위 로그 눈금에서 고르게 시작(첫 6장 = 단계 구간마다 하나), 그 뒤는 지금 어림 b 근처에서(위·아래 번갈아, `knowChance`가 0.3~0.7인 구간). 기능어·고유명사 빼고, 같은 주제 연속 금지.
- 가짜 낱말 6개: 무작위 자리(처음 셋 안에는 안 넣음).
- 셈:
  - 거짓 앎 비율 f = 가짜에 [앎] 수 / 6.
  - 진짜 낱말마다 p(앎) = `knowChance(b, rank)`, 관측 [앎]을 f로 바로잡아 `(h − f) / (1 − f)`(0~1로 자름)로 보고 b를 최대가능도로 고른다(b 후보 50~7,000을 로그 눈금 60칸, σ = 0.35 지금 값). 모델 없음.
  - f ≥ 0.5면 예/아니오를 버리고 뜻 고르기만으로(다음 줄) b를 잡는다.
- **뜻 고르기 5문제**: b 근처(0.5 ≤ p ≤ 0.8) 낱말, 보기 넷은 같은 품사 뜻(지금 퀴즈 오답 규칙). 맞음·틀림마다 지금 `noteLevel`로 b를 고친다.
- 결과: `Level { b, n: PROBE }` — Quizbank 수준 맞추기 가늠 단계(처음 20문제)를 건너뜀. 장부에는 뜻 고르기만 사건으로(예/아니오는 어림 재료라 표제어 사건으로 안 남김 — "확실히 학습한 것"이 아님).

## 4. ③ 표현·문법

- 문제: 단계 n의 고정 수업 퀴즈(`fixedLessons/toQuiz.ts`)에서 쓰기 한 문제 — 표현 하나, 문법 하나를 번갈아. 고정 수업이 없는 앱 언어는 문장구조 예문 빈칸.
- 단계 1부터 올라감. 같은 종류 두 번 연달아 틀리면 그 종류 멈춤. 둘 다 멈추거나 5단계 끝이면 끝(최대 10문제).
- 결과: 표현 시작 단계·문법 시작 단계 = 마지막으로 맞힌 단계. 그 아래 단계 항목은 "아마 앎"(어림 — 사전·Logbank 띠의 진하기), 표제어 체크 셋은 비어 있음.
