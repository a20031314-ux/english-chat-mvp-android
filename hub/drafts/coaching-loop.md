# 대화 중심으로: 짚어주고, 쌓고, 권해서 채우기 (초안, 2026-10-16)

> 사용자 요청: 지도가 시키고 탭이 따라가는 구조가 애매함(통화로 가면 장면 없이 탭만 열리고, 채팅은 첫 문장만 붙음).
> 숙지한 표현을 나열하기보다 대화 중에 "전에 봤던 표현이에요. 잘 썼어요"처럼 짚어주고, 쌓인 데이터로 "이렇게 해보세요"를 권해서
> 부족한 부분을 채워가는 흐름으로. 지도는 측정 중심, 세부는 눌러서 보기.
> 결정(추천대로, 2026-10-16): 권하는 것은 한 번에 하나 + "다른 것", 목표는 권하기의 방향으로 남기고 주제 지도는 세부 화면으로,
> 미션은 없애지 않고 권하기의 한 선택지로, 측정은 점수 없이 추이와 사실로(레벨 원칙 유지), 대화는 상황 제안이 있는 자유 대화.
> 상태: 설계안. 사용자 확인 후 구현.

## 지금 구조의 문제 (코드 기준)

- 지도 → 탭: `openTab`만 보냄. 통화 탭은 지도 요청을 받는 코드가 없어 장면 목록에서 멈춤(`cafe-order` 장면이 있어도).
  채팅은 `chatDraft`로 첫 문장만 넣고 튜터는 주제를 모름. 단어장도 탭만 열림. 영상만 장면 검색으로 이어짐.
- 탭 → 지도: 채팅·통화 문장을 지도 표현·장부와 대조해 숙지 기록(강함).
- 같은 주제에 "미션 할 일"과 "연습하기 카드"(지도 생성 때 같이 만든 것)가 따로 있음.
→ 학습자는 무엇을 하러 왔는지 모른 채 연습하고, 결과만 지도에 쌓인다.

## 새 흐름

```
대화(자유, 상황 제안) → 그 자리에서 짚어줌 → 안에 쌓임 → 쌓인 것으로 "이렇게 해보세요" 하나 → 누르면 그 목표를 품은 대화 → …
```

학습자가 관리하는 것은 없다. 대화 속에서 "늘고 있다"를 느끼고, 다음 할 일을 하나씩 받는다.

## 1. 대화 중 짚어주기 (조용하게, 줄 아래 한 줄)

| 순간 | 판단 재료 | 문구 예 | 지금 |
|---|---|---|---|
| 전에 만난 표현을 맞게 씀 | 장부 대조(이미 함) | "전에 봤던 표현이에요. 잘 썼어요 · 영상 0:42" | "○○에서 만난 표현" 칩 → 말투만 바꿈 |
| 도움 없이 써서 숙지로 | 턴 응답의 상태 변화(이미 옴) | "이제 혼자 쓸 수 있어요" | "숙지로 올라갔어요" 유지 |
| 숙지했던 걸 틀림 / 같은 실수 종류 반복 | 장부 + 자주 틀리는 것 | "지난번에도 헷갈렸던 부분이에요" + 교정 | 일반 교정만 → 한 줄 추가 |
| 막힘(통화 stuck, 채팅에서 편한 말로 씀) | 통화 director stuck, 채팅 "표현 보기" | 도움말 그대로 + 그 표현을 장부에 **막혀서 배운 것**으로 | 도움말은 쓰고 사라짐 → 기록 추가 |
| 튜터 말에 아는 표현 | 장부 대조(이미 함) | "아는 표현"·"본 적 있는 표현" | 유지 |

- 소음 막기: 한 대화에 칭찬 최대 3번, 같은 표현 칭찬은 하루 한 번, 짚어주기는 대화를 끊지 않고 줄 아래에만.
- 막혀서 배운 표현은 튜터 다시 써 주기(이미 있음, `phrasesToRecycle`) 대상에 먼저 넣는다 → 다시 나오고 → 쓰면 숙지.
- 모델 호출 추가 없음. 판단은 이미 오는 턴 응답·장부 대조·실수 종류.

## 2. 쌓기 (안에서만)

이미 쌓이는 것: 표현 장부(만남·배운 것·숙지, 어디서 만나고 썼는지), 자주 틀리는 것(실수 종류), 이해도(찾아본 표현), 턴 측정(`learnerMetrics`: 교정 여부·길이·응답 지연, 문장 없음).

더할 것:
- 장부 만남 종류에 `stuck`(막혀서 배운 것), 출처 탭과 상황(장면 id 또는 대화 상황).
- **주별 능력 기록**(언어별, 학습자 문장 없음). 장부 주별 줄처럼 한 주에 한 줄, 지난 기록은 다시 계산하지 않음:

| 항목 | 재료 | 보여줄 사실 예 |
|---|---|---|
| 말 이어가기 | 통화·채팅 턴 수, 막힘 수, 도움 받은 수, 평균 문장 길이 | "막힘 12 → 7", "한 번에 말하는 길이가 늘었어요" |
| 정확도 | 교정 붙은 턴 비율, 실수 종류별 횟수 | "과거 시제 실수가 이번 주 0번" |
| 표현 폭 | 숙지·배운 것 수, 유지율(장부 summarize) | "이번 주 혼자 쓴 표현 +5" |
| 알아듣기 | 해석 연 비율, 찾아본 표현 수, 다시 들은 수 | "해석 없이 들은 통화가 늘었어요" |
| 상황 | 장면·상황별 대화 수, 막힘 없이 끝낸 대화 | "카페 주문: 막힘 없이 끝냄" |

- 비교는 **내 지난 2주 대 이번 2주**만. 절대 점수·레벨·백분율 없음.
- 대화가 적으면(항목별 최소 턴 수 미만) "아직 재는 중"으로.
- 해석 연 비율·다시 들은 수는 지금 서버에 없음 → 통화·영상 이벤트에 숫자만 더함(앱 빌드).

## 3. 권하기 — "이렇게 해보세요" 하나

후보를 모아 하나를 고른다(순수 함수, `suggest.ts`를 14개 언어·장부 기준으로 넓힘). 모델 호출 없음, 문구는 틀에 채움.

| 순서 | 후보 | 행동(누르면) | 예 |
|---|---|---|---|
| 1 | 같은 실수 종류가 2주 안에 2번 이상 | 그 실수를 부르는 상황으로 대화 시작 | "어제 한 일을 3문장으로 말해보세요" |
| 2 | 막혔던 상황(장면) | 그 장면 다시 통화 | "카페 장면을 다시 해보세요. 지난번엔 사이즈 묻는 데서 막혔어요" |
| 3 | 배운 것인데 7일 넘게 안 씀 / 막혀서 배운 것 | 그 표현이 필요한 대화(튜터가 표현을 앎) | "'end up'을 오늘 대화에서 한 번 써보세요" |
| 4 | 알아듣기 약함(해석 자주 엶) | 영상 장면(색인 검색) 해석 없이 | "이 장면을 해석 없이 들어보세요" |
| 5 | 목표에서 아직 안 해본 상황 | 그 상황으로 통화(장면 있으면 장면) | "호텔 체크인도 해볼까요?" |
| 6 | 쓰기로 정리하고 싶을 때 | 지도 미션(할 일 연습) | "이 주제를 할 일로 연습해보세요" |

- 하나만 보여주고 "다른 것"을 누르면 다음 후보. 이유 한 줄을 같이("지난주 2번 헷갈렸어요").
- 목표(지도의 goal)는 5번 후보와 상황 제안의 방향.
- 같은 권하기를 3번 넘기면 하루 동안 뒤로.

### 권하기가 대화를 여는 방법 (지금 문제의 해결)

새 의도 `practice` (`appIntents.ts`):
```
practice: { tab: "chat" | "roleplay" | "video" | "map",
            goal: { why: string; situation?: string; phrases?: string[]; scenarioId?: string; mistakeKind?: string } }
```
- **통화:** `RoleplayTab`이 받음. `scenarioId`(또는 상황이 맞는 장면 — 카페 → `cafe-order`)가 있으면 그 장면 바로 시작,
  없으면 자유 통화를 그 상황으로 시작. 화면 위에 "써볼 표현" 칩(쓰면 체크).
- **채팅:** `ChatWindow`가 받음. 튜터 지시에 상황·써볼 표현·실수 종류를 넣어 **튜터가 먼저 그 상황으로 말을 건넴**(첫 문장을 입력창에 붙이지 않음).
  튜터 지시는 서버(바로 반영), 받는 코드는 앱(빌드 필요).
- **영상:** 지금의 장면 검색 그대로.
- 지금 지도 주제의 "연습하기" 카드도 이 의도로 바꿈 → 통화 카드가 장면으로, 채팅 카드가 상황 대화로 이어짐.

## 4. 어디에 보이나

- **채팅·통화 첫 화면:** "오늘 해볼 것" 카드 하나(권하기). 상황 제안 2~3개는 그 아래 작게.
- **대화가 끝났을 때:** 돌아보기에 "잘 쓴 표현 n개" + "다음엔 이걸 해보세요" 하나.
- **지도 탭 (새 첫 화면):**
  1. 지금 권하는 것(크게)
  2. 늘고 있는 것: 항목 5개, 항목마다 사실 한 줄 + 2주 추이 작은 막대(점수 축 없음)
  3. 세부(눌러서): 내 표현(지금 시트), 실수 종류, 상황별 기록, **목표와 주제 지도**(지금의 지도·미션은 여기로)
- 목표가 없는 학습자: 권하기는 데이터만으로, 상황 제안은 기본 상황 목록(`situations.ts`).

## 언어·화면

- 14개 학습 언어 모두. 대조는 `findExpression`·`wordSegments`(ja·zh·th, 한국어 조사). 장면이 없는 언어는 자유 통화로.
- 문구 14개 UI 언어, 틀 문구는 `copy.ts` + overlays. 아랍어 `dir="auto"`, `ms-`/`me-`. 시트는 `BodyLayer`.
- 사용법(?)은 그림 먼저(지도·채팅 첫 화면이 바뀌므로 다시 찍음).

## 개인정보

그대로: 학습자 문장은 저장하지 않음. 주별 능력 기록은 숫자만, 막혀서 배운 것은 튜터·도움말에서 나온 표현만.

## 단계

1. **권하기 + `practice` 의도** — 지금 문제(통화가 탭만 열림, 채팅에 문장만 붙음)를 먼저 풂. 지도 주제 카드도 이 의도로.
   서버: 권하기 API(`GET /api/learner/next?lang=`), 채팅·통화 튜터에 목표 넣기. 앱: 통화·채팅이 의도 받기, 첫 화면 카드.
2. **짚어주기 확장 + 막힘 기록** — 칭찬 말투, "지난번에도", 막혀서 배운 것 → 다시 써 주기.
3. **주별 능력 기록 + 지도 첫 화면 개편** — 측정 5항목, 세부로 내리기. 해석·다시 듣기 숫자 이벤트.
4. **대화 끝 돌아보기의 다음 할 일**.

1~2는 서버 변경이 크고 앱은 받는 쪽 화면만, 3은 앱 화면이 큼. 각 단계 끝에 운영 확인 + 언어 조합 3개.

## 정할 것 (구현 전에)

1. 단계 1부터 바로 시작할지. 추천: 1부터(지금 불편한 부분을 바로 풂).
2. 채팅에서 권하기를 누르면 튜터가 먼저 말을 거는 방식으로 할지. 추천: 먼저 말 걸기(학습자가 첫 문장을 고민하지 않게). 이 첫 턴은 채팅 차감 없음.
