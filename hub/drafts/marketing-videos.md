## 언어판·학습 조합 (사용자 결정 2026-10-24, `store-shots/promo/combos.mjs`)

| 앱 언어 | 배우는 언어 | 이유 |
|---|---|---|
| en | 한국어 | 해외의 한국어 수요 |
| es · ar · id · vi · th | 영어 | 사용자가 많은 언어(기본) |
| ko ↔ ja | 일본어 ↔ 한국어 | 서로 교류가 많은 조합 |

- 프랑스어·이탈리아어 등 나머지는 일단 뺀다. 운영에 무리가 없으면 8개 판을 처음부터 같이 시작(사용자).
- "한국인이 자주 틀리는" 같은 제목은 언어판마다 맞지 않아 공통 문구로.

## 채널·올리기

- 채널은 언어별로 따로(화면 속 앱 언어가 판마다 달라 한 영상으로 못 묶고, 섞으면 알고리즘이 흐려짐). 유튜브는 구글 계정 하나에 브랜드 채널 여러 개, 틱톡은 앱 하나에 계정 여러 개.
- 지금: 영상 파일을 만들어 보내면 사람이 폰에서 올린다.
- 다음(안): 영상 목록 페이지의 [올리기] → GitHub Actions가 업로드. 유튜브 API는 심사 전 비공개로만 올라감(스튜디오에서 공개 한 번), 틱톡은 앱의 임시 저장함으로 보내는 방식 — 시작할 때 조건 다시 확인. 채널 생성·연결 허락은 사람.

## 만들기

```
npm run build:capacitor
node --experimental-strip-types store-shots/promo/record-fix.mjs <locale>   # tmp/promo/fix/<locale>/raw.mp4 + events.json
node store-shots/promo/make.mjs fix <locale>                                 # → promo-fix-<locale>.mp4
```
- 교정이 맞는지 `events.json`의 `sent`·`bubbleText`를 읽고 확인한다. 틀린 교정은 쓰지 않는다(맞는 문장을 고치는 문제가 아직 있음).
- 아랍어·태국어는 글꼴(`fonts-noto-core`)이 없으면 네모로 나온다 — 작업 공간에 설치.
- 배경음 없음(저작권 없는 음원을 고르면 추가).
