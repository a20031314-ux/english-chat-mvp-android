## 핵심: 언어 학습 앱 (사용자 2026-11-03 "배우는 언어는 한국어 이런 고정 원칙은 지워줘. 언어학습 앱이라는 게 핵심")

- 판(채널)은 **앱 언어(시청자의 말)**로만 나눈다. 배우는 언어는 고정하지 않는다 — 14개 언어를 배우는 앱이라는 것이 핵심 메시지.
- 편마다 화면 속 학습 언어는 그 장면에 맞게 고르고, 여러 언어를 섞어 보여 줘도 된다(`PROMO_TARGET`, `combos.mjs`는 녹화 기본값일 뿐 원칙이 아님).
- 자막·끝 화면은 특정 언어가 아니라 "언어를 말하며 배운다"로(예: "Speak any language out loud"). 언어 이름은 화면에 실제로 보이는 언어를 가리킬 때만.
- 예전(2026-10-24) 판별 고정 조합(en→한국어, es·ar·id·vi·th→영어, ko↔ja)은 뺌.

## 채널·올리기

- 채널은 언어별로 따로(화면 속 앱 언어가 판마다 달라 한 영상으로 못 묶고, 섞으면 알고리즘이 흐려짐). 유튜브는 구글 계정 하나에 브랜드 채널 여러 개, 틱톡은 앱 하나에 계정 여러 개.
- 지금: 영상 파일을 만들어 보내면 사람이 폰에서 올린다.
- 다음(안): 영상 목록 페이지의 [올리기] → GitHub Actions가 업로드. 유튜브 API는 심사 전 비공개로만 올라감(스튜디오에서 공개 한 번), 틱톡은 앱의 임시 저장함으로 보내는 방식 — 시작할 때 조건 다시 확인. 채널 생성·연결 허락은 사람.

## 만들기

```
npm run build:capacitor
node --experimental-strip-types store-shots/promo/record-fix.mjs <locale>   # tmp/promo/fix/<locale>/raw.mp4 + events.json
node store-shots/promo/make.mjs fix <locale>                                 # → promo-fix-<locale>.mp4
```
- 교정이 맞는지 `events.json`의 `sent`·`bubbleText`를 읽고 확인한다. 틀린 교정은 쓰지 않는다(맞는 문장을 고치는 문제가 아직 있음).
- 아랍어·태국어는 글꼴(`fonts-noto-core`)이 없으면 네모로 나온다 — 작업 공간에 설치.
- 배경음 없음(저작권 없는 음원을 고르면 추가).

## 홍보 전 막아 둘 것 (같은 날 정리)

1. 지출 상한·크레딧 자동 충전·장애 알림(10-21 OpenAI·Upstash 장애로 채팅 전부 실패한 적 있음).
2. 맞는 문장을 고치는 비율 11% — 오류교정 편이 퍼지면 댓글 반박이 가장 아픈 곳.
3. 2.72 공개 뒤 촬영(영상과 앱이 같아 보이게). 기기 확인(마이크·통화·결제)은 qa inbox에 밀려 있음.
4. 국가: 한국·일본 + 반응 큰 곳(스페인어권·동남아). 광고 단가 낮은 나라는 무료 사용 손익을 따로 본다.
