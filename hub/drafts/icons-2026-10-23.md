# 사용자 아이콘·짤 묶음 (2026-10-23)

> 사용자 요청: "디시인사이드처럼 사용자들이 아이콘이나 짤을 만들어서 오픈소스로 풀게" → 결정 "CC0도 고를 수 있게, 움직이는 아이콘도 받고, 올리자마자 공개".
> 코드: `src/lib/rooms/icons.ts`(한도·모양) · `server/iconImage.ts`(sharp로 줄이기·프레임 뽑기) · `server/iconStore.ts`(KV·Blob) · `/api/icons` · `components/rooms/IconPacks.tsx` · 문구 `rooms/iconCopy.ts`(14개 언어).

## 정한 것

| 항목 | 값 |
|---|---|
| 라이선스 | 묶음마다 **CC BY 4.0**(출처 표시) 또는 **CC0**(조건 없음). 만들 때 고르고 바꾸지 않는다(받아 간 사람 조건이 바뀌지 않게). 만들 때 "내가 만들었거나 권리가 있음 + 공개 동의" 체크 필수(서버도 `agree:true` 확인) |
| 형식 | PNG·JPEG·WebP·GIF·움직이는 WebP. 원본 2MB·프레임 150까지 → 서버가 긴 쪽 256px **WebP(움직임 유지)**, 품질 80 → 600KB 넘으면 55로 한 번 더 → 그래도 크면 거절 |
| 공개 | **올리자마자 공개** — 첫 아이콘이 들어가면 "새로 올라온"·"인기" 목록에. 그림 주소 `/api/icons?f=<묶음>.<아이콘>`은 누구나(폰 하루·CDN 한 시간 캐시) |
| 검사 | 올릴 때 처음·가운데·끝 프레임(PNG 512px)을 OpenAI omni-moderation(무료)에 — 하나라도 걸리거나 검사를 못 하면 거절 |
| 자격·한도 | 로그인·가입 7일 뒤 · 묶음당 24개 · 계정당 묶음 20 · 하루 60개 · 받아 두기 60 · 이름 30자 · 한 마디 40자(학습 언어) |
| 보내기 | 1:1·단체방·게시판 댓글 입력칸 🙂 → 내 묶음 + 받아 둔 묶음에서 고르면 바로(아이콘만 한 줄). 서버가 묶음에서 크기·한 마디를 채움(`iconPick.ts`), 내려진 묶음은 `BAD_ICON` |
| 인기 | 쓰인 수 = 한 사람이 한 묶음을 하루 한 번만(만든 사람 빼고) — 한 사람 도배로 순위가 바뀌지 않게 |
| 신고·내리기 | 묶음 시트 "신고"(이유, 저작권 포함) → 운영자 신고함(`[아이콘]`, 줄 `icon-pack:<id>`) → `/ops` "아이콘 묶음 내리기/되돌리기": 목록·보내기·그림 모두 막힘 |
| 지우기 | 만든 사람: 아이콘 빼기·묶음 지우기(그림 파일까지). 계정 삭제 때 만든 묶음 전부(`forgetIcons`). 이미 보낸 메시지의 아이콘은 빈 칸(∅) |
| 저장 | KV `icon:v1:*`(`hub/data-map.md`), 그림 Vercel Blob private `icons/<묶음>/<아이콘>.webp`. 학습자 문장은 저장 안 함(한 마디는 만든 사람이 붙인 공개 글) |

## 비용

- 올리기: 검사 무료(프레임 최대 3번 호출), sharp 변환은 함수 시간 1초 안팎 → `opCost` `iconUpload` 가정 $0.00005.
- 보기: 256px WebP 대개 10~100KB(움직이는 것 최대 600KB). CDN 캐시라 같은 그림은 Blob을 다시 읽지 않음. Blob 저장 GB당 월 $0.023 — 아이콘 1만 개 × 평균 80KB ≈ 0.8GB ≈ 월 $0.02.
- 많이 쓰이면 주로 대역폭(Vercel Pro 포함량 1TB/월 안). 동영상(mp4)은 이번에 받지 않음.

## 남은 것 / 다음에 볼 것

- 프로필에 "만든 아이콘 묶음" 칸(`by` API는 있음), 게시판 글 본문에 아이콘, 말하는 방 댓글에 아이콘.
- 원작자 표시: 지금은 묶음 시트의 "만든 사람 {이름}"과 라이선스 링크. 앱 밖으로 내보내기(다운로드)는 없음 — 필요하면 다운로드 시 파일 이름·메타데이터에 출처.
- 검사는 성적·폭력·혐오만 — 저작권(유명 캐릭터 등)은 신고로만. 신고가 많아지면 묶음 단위 자동 숨김 기준을 정한다.
- 움직이는 WebP는 오래된 안드로이드 WebView(Android 8 이하 일부)에서 첫 프레임만 보일 수 있음 — 기기 확인 필요.
