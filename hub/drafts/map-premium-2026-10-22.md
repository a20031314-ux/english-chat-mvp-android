# My 지도 — 고가 모델로 그릴지 (2026-10-22)

- 요청: 사용자 "my(기존 학습지도)를 고가 ai모델로 구체화해서 제공할지 고려. 이전엔 학습요소가 애매하고 체계적이라는 느낌 없이 난잡했다".
- 방법: 같은 체크 세 조합(en 학습·ko 앱 초급 / ja·ko 어휘·여행 / es·en 회의)으로 운영 `/api/curriculum/generate`를 지금(gpt-4.1)·Haiku 5.5·Sonnet 5.5로 그림(점검 사용자, `x-sim-model-routes`). 점검 데이터 지움.
- 먼저 고친 것: Claude로 그리면 세 조합 모두 `MAP_FAILED` — 출력 한도 4000에서 끊김. 8000(할 일 3000)으로 올려 push(`dedd976`). high 등급을 Claude로 켰으면 지도가 전부 실패했을 것.

- 지금 지도가 난잡한 이유: 상황 하나를 네 칸(상황 A·문법 B·어휘 C·발음 D)으로 쪼개 같은 말을 네 번 함 — "카페 주문하기 / 정중하게 부탁하기 / 음료 단어 / 카페 주문 듣고 따라하기", "첫 만남 인사 / 기본 인사 표현 / 인사 표현 듣고 따라하기". 요약은 "~을 익힙니다"뿐, 무엇을 말할 수 있게 되는지 안 보임.
- Sonnet: 같은 틀인데 주제마다 구체적(「お願いできますか」「〜てもらえますか」, 乗り換え·改札·片道, "Can I have…?/Could I get…?", 과거형 "I went…"), 중복 주제가 없어지고 순서 설명이 있음(식사 → 교통 → 숙소 → 현지인 대화).
  Haiku도 지금보다 확실히 나음(어휘를 "가족"으로 묶음, 〜ていただけますか vs 〜ください), Sonnet보다 덜 구체적.
- 그래도 남는 것: 네 칸 틀 자체가 상황·문법·단어·소리를 따로 떼어 놓아 "체계"가 안 보임. 모델만 바꿔서는 안 풀림.

## 사용자 제안(2026-10-22 05:24) → 단계형 지도 설계 초안

> "수준별로 나눠서 '이 정도를 학습하면 여기까지 도달 가능하다'는 범위를 정한 뒤 앱 기능으로 학습, 학습됐는지는 기존 데이터 수집·방향 설정에 연결"

- **범위는 사람마다 새로 그리지 않고 언어별로 한 번 정해 둔다:** 학습 언어마다 단계 5개, 단계마다 도달 문장(할 수 있게 되는 것) 5~8개 + 상황 + 구문 + 핵심 표현 묶음 + 듣기·소리 하나. 고가 모델(Opus/Sonnet)로 쓰고 검토해 코드 데이터로 고정(`curriculum/engine/packs`처럼). 같은 언어면 모두 같은 뼈대 → 체계가 보이고, 예문 베끼기가 없고, 지도 그리기 비용이 거의 0.
- **사람마다 다른 것:** 체크(부족한 곳·위주·어디서)와 쌓인 기록으로 시작 단계와 단계 안 순서·비중만 고른다.
- **학습:** 범위 항목마다 앱 기능 바로가기 — 채팅 시작 문장, 통화 장면, 영상 장면 찾기(listenFor), 단어장, 할 일.
- **판단(이미 있는 것에 연결):** 표현 → 표현 장부 숙지(14개 언어), 구문 → 학습자 프로필(지금 영어만 39개, A1~C1), 자주 틀리는 것 → 약점, 말 이어가기·알아듣기·발음 → 자라는 중 6요소, 상황 → 할 일·통화 완료. 단계의 대부분이 숙지되면 다음 단계, 튜터 요약·오늘 해볼 것이 그 단계의 빈 곳을 겨냥.
- **걸리는 것:** ① "학습 수준(A1·B2)은 보여주지 않는다" 결정과 충돌 — 단계 번호·이름을 보일지 ② 구문 목록이 영어만 있어 13개 언어는 새로 써야 함(고가 모델 + 검토) ③ 이미 그린 지도는 그대로 두고 새 지도부터.
