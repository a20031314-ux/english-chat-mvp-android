## 4. 언어별로 따로 저장되는 것

- **서버:** 모두 `<사용자>:<언어>` — 지도·단계·대본 진척·노트·학습자 기록·이번 주 확인·팩. 공유 캐시(읽는 법·문제은행·문장구조 설명·꺼내 쓰기·단어)도 언어별. 의견만 언어 무관.
- **기기, 언어가 키에 있음:** 글자 먼저·읽는 법·학습 방식·퀴즈 기록·약한 곳·대본 묶음·단어 카드·채팅 초안 등.
- **기기, 한 키 안에 언어별:** 복습 카드 `reviewNotes.v1`, 대본 틀린 줄, 채팅·통화 목록(줄마다 언어 표시, 옛 줄은 en).
- **언어 무관(일부러 공유):** My 펼친 칸, 오늘 할 것 설정(분량·순서), 대본 방식, 단어장 보기, 아침 알림.
- **언어 무관인데 확인 필요:** `dailyPlan.today.v1`(오늘 묶음 하나 — 언어 바꾸면 새로 만듦), `dailyPlan.quizDone.v1`(날짜만 키, 열쇠가 언어 사이에 겹칠 수 있음 — 실제 겹침은 확인 안 함), 채팅 보관함 `savedItems`(줄에 언어가 있는지 확인 안 함).

## 5. 고르지 않은 곳 (고칠지 사용자가 정함)

1. **단어장·단어 퀴즈가 3개 언어만** — 11개 언어는 오늘 할 것에서 조용히 빠짐. 단어 은행 출처(CC BY-SA)를 언어마다 찾아야 함. 가장 큰 차이.
2. **th·hi 글자 안내 없음** — 글자 언어인데 0단계·읽는 법만 있고 글자 안내 탭이 없음.
3. **0단계 들어가는 길이 두 갈래** — 단계 화면은 글자 언어만, 다시 고르기(StageCheck)는 라틴 언어도 파닉스. 하나로 맞출지.
4. **말투 문제 ru·ar·hi·it·pt 없음**, 목록의 `de` 정리.
5. **읽는 법이 대본에만** — 문장구조 설명·퀴즈·단어장엔 병음·후리가나가 없음(ja 단어 은행엔 읽기 값이 있는데 화면에 쓰는 곳을 못 찾음).
6. **영어만 있는 분석** — 관용구 밑줄·기기 표현 단위·문법 기록.
7. **표현 대본 양 차이** — ko·ja 20개대, 나머지 2~5개. 틀 오답도 th 56·hi 54 vs fr 132.
8. **영어·한국어 중심 폴백** — 통화 지시 en/ko 전용 + 공통, 노트 고정 칸 이름·뜻풀이 en/ko만.
9. **앱 틀 방향** — `AppHome.tsx`가 앱 언어 방향에 학습 언어용 함수(`learningLanguageTextDir(locale)`)를 씀. 결과는 맞지만(ar) 이름이 어긋남.
10. **글꼴·입력 안내 없음** — 언어별 글꼴 지정이 없고, 빈칸 쓰기에 키보드(IME) 안내가 없음.
