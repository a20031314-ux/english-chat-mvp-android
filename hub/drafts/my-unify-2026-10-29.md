## 2단계 — 기록 하나(익힘 장부)

**한 줄 정의:** 학습 언어마다 **열쇠**(표현 `e|`, 문장구조 `f|`, 문법 칸 `g|단계:번호`, 낱말 `w|`) 하나에 **상태 하나**. 모든 화면의 숫자는 이 장부에서만 계산한다.

### 상태 (셋 + 하나)
- **안 배움** — 아직 만난 적 없음.
- **배우는 중** — 한 번이라도 만남(대본·퀴즈·시험·채팅).
- **익힘** — 서로 다른 날 두 번 이상 맞힘, 그중 한 번은 **말해서**(대본 말하기 방식·퀴즈 말하기·채팅·통화에서 스스로 씀), 그 뒤 틀린 적 없음.
- **흔들림** — 익힘이었는데 시험·퀴즈에서 틀렸거나 튜터가 고침 → 다시 볼 것에 들어가고, 다시 맞히면 익힘으로.

### 무엇이 상태를 바꾸나 (사건)
| 사건 | 효과 |
|---|---|
| 대본 통과(말하기 방식) | 그 대본 핵심 표현·문장구조·문법 — 말해서 맞힘 |
| 대본 통과(고르기·맞추기, 통과 기준 "모든 방식") | 알아봄(맞힘, 말하기 아님) |
| 대본 끝까지 했지만 못 넘음 | 배우는 중(흔적 남음 — "15분 한 게 0" 해결) |
| 퀴즈·시험 문제 | 맞음/틀림(말하기 문제는 말해서) |
| 채팅·통화에서 스스로 씀, 고칠 데 없음 | 말해서 맞힘(지금 "✓ 다시 썼어요"와 같은 판단) |
| 튜터가 고침(노트 카드) | 그 열쇠 틀림 |
| 헷갈려요 / 알아요 | 배우는 중 / 맞힘 한 번 |
| 다시 말해 보기(발음) | 발음 갈래 맞힘·틀림 |

### 숫자는 이것만
- **단계 진척** = 지금 단계 열쇠 중 익힘의 몫. 갈래(어휘·문법·표현·발음)는 열쇠의 갈래(`partOf`)로 나눠 같은 장부에서.
- **다음 단계 조건** = 네 갈래 70% (지금과 같은 기준, 재료만 하나로) → 단계 시험.
- **단계 시험을 넘으면** 그 단계에서 맞힌 열쇠는 익힘, 틀린 것은 흔들림. 사다리 "n단계"는 시험·조건으로만 오른다(고른 시작 단계는 출발점일 뿐).
- **실력 기록** = 시험마다 그때의 장부 갈래 몫도 함께 남겨, 시험 점수와 진척이 같은 축.
- **대본으로 익힌 것** = 장부에서 "대본에서 온 익힘" 수.

### 저장
- 서버 `mastery:v1:<사용자>:<언어>` — 열쇠마다 상태·맞힘/틀림 수·마지막 때·말해서 맞힌 날 수. 문장은 남기지 않음(열쇠만). data-map 한 줄, 계정 지우면 함께.
- 폰에만 있던 퀴즈 기록·대본 틀린 줄은 사건으로 서버에 보냄(열쇠·맞음만).
- **옮기기:** 처음 읽을 때 지금 저장소들(장부·stageScripts·notebook·growth·checkups)에서 한 번 만들어 둠. 옛 앱(2.77 이하)이 쓰는 API는 그대로 두고, 새 앱만 장부를 읽음.

### 서버 / 앱
- 서버(바로): 장부·사건 받기·옮기기·`/api/notebook parts`를 장부에서 계산(옛 앱 화면 숫자도 이걸로 맞춰짐).
- 앱(빌드): 사건 보내기, 화면 숫자를 장부 하나에서.

## 3단계 — My 세 층

```
My
├ 1층  [n단계 · 다음 단계까지 64%]  어휘 ▮▮▮▯ 문법 ▮▮▯▯ 표현 ▮▮▮▯ 발음 ▮▯▯▯   ← 숫자 하나 + 네 갈래(누르면 기록)
├ 2층  [▶ 오늘 학습 · 10분]                                                  ← 버튼 하나
│        다시 볼 것 퀴즈 → 오늘 대본 → 문장구조 → (때 되면) 이번 주 확인·단계 시험
│        끝 = "오늘 한 것" 한 장(익힘 +n, 흔들림 n) + [계속 공부]
│        오늘 목록은 버튼 아래 접힌 한 줄 "3개 중 1 ✓"
└ 3층  [기록 ▾]  실력 기록 · 망/그래프 · 지난번에 틀린 것 · 대본으로 익힌 것 · 단계 사다리 · 대본 목록 · 틀 연습
       ⚙ 분량(5·10·20분)·순서·아침 알림·통과 기준
```
- 지금 단계 보기 맨 위의 카드 여섯(지난번에 틀린 것·오늘 할 것·아침 알림·계속 공부·실력 기록·익힌 양)이 1·2층 두 줄로 줄어듦. 기능은 지우지 않고 3층으로.
- 다른 탭(채팅·통화)의 "✓ 다시 썼어요"도 같은 장부 상태로 — 익힘이 되는 순간 "익힘 ✓".
- **첫 실행:** 쓸 기능 고르기는 기본 모두 켬으로 건너뛰고 사용법(?) 안에만 → My → [시험으로 시작 | 1단계부터] → 바로 2층 버튼. 첫 대본까지 누름 5번 안팎이 목표(지금 약 20번).
