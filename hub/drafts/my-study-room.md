# 노트 (My) — 모두 같은 뼈대 + 담아 두기 → 자리 찾아 넣기 (설계안, 2026-10-19)

> 사용자 생각: "지도"라는 개념이 애매하다. 예전 전자공학 "브리지 노트"(목표→섹터 지도, 강의자료 쪽마다 보충·질문, 자료함·전체 검색)처럼
> My를 개인 학습 노트로 만들고, 사용자끼리 "난 이렇게 한다"로 공유.
> **사용자 결정(2026-10-19):** 이름은 **노트**. **난이도 없음.** **뼈대는 모두 같게.** 흐름은
> 뼈대 → 공부하다 "이거 넣고 싶다" 싶은 걸 담아 두기 → 들어갈 자리를 정해 그 칸이 업데이트.
> 상태: 설계안. 아래 "정할 것" 답을 받은 뒤 1단계부터.

## 1. 한 줄
지도는 사라지고, **모두에게 같은 목차(장 8개 × 칸 4개)** 가 생긴다. 사람마다 다른 건 목차가 아니라 **그 안에 쌓인 카드**다.
같은 목차라서 남의 노트를 그대로 펼쳐 보고 가져올 수 있다(공유가 쉬워지는 이유).

## 2. 뼈대 — 학습 언어마다 같은 목차

장 8개(모든 학습 언어 공통, 장 이름은 14개 UI 언어 고정 문구 — 모델이 만들지 않음):

| 장 | 무엇 | 예시 |
|---|---|---|
| 1. 나와 사람들 | 소개·가족·관계 | 자기소개, 직업, 친구 이야기 |
| 2. 하루 | 일상·집·시간 | 아침 루틴, 주말 |
| 3. 지난 일 | 경험·사건 | 어제 한 일, 여행 다녀온 이야기 |
| 4. 앞으로 | 계획·약속·바람 | 주말 계획, 약속 잡기 |
| 5. 생각과 느낌 | 의견·이유·감정 | 좋고 싫음, 동의·반대 |
| 6. 부탁과 해결 | 요청·문제·사과 | 길 묻기, 환불, 미안해요 |
| 7. 밖에서 | 가게·식당·교통·여행 | 주문, 체크인, 표 사기 |
| 8. 일과 공부 | 회의·메일·수업 | 회의 시작, 질문하기 |

장마다 칸 4개 — 지금 지도의 네 칸(A~D)을 장 안으로 옮긴 것:
**장면**(그 상황의 대화·장면) · **표현**(문형·문법·고친 문장) · **단어** · **듣기·발음**.
특별 쪽 3개: **담아 둔 것**(아직 자리 없는 것), **자주 틀리는 것**(지금 "자주 틀림" 그대로, 자동), **질문 모음**(답 안 받은 질문).

- 난이도·수준은 묻지도 보이지도 않는다. 할 일·예문 난이도는 지금처럼 쌓인 기록(학습자 요약의 "쉽게/조금 어렵게")으로만 맞춘다.
- 처음 체크(부족한 것·위주·주로 어디서)는 **목차를 바꾸지 않고** 장 순서와 "오늘 해볼 것"만 정한다(예: "여행" → 7장이 먼저).
  지금 `selfCheck.pitchFor`(초급/중급)는 뼈대에 쓰지 않는다.

## 3. 담기 — 지금 있는 자리마다 📌 하나

| 어디서 | 담기는 것 | 지금 있는 장치 |
|---|---|---|
| 채팅 | 튜터 말 한 줄, 내 말 + 고친 문장, 표현 카드 | 줄 메뉴, "표현 보기" 카드 |
| 통화 | 내 줄(+고친 문장/하려던 말), 막혔을 때 도움말, 캐릭터 말 | 끝난 대화·지난 대화 줄 |
| 오늘의 팩 | 돌아보기의 막힌 곳·써 본 표현 | 돌아보기 화면 |
| 영상 | 자막 한 장면(영상 id·초) | 문장 바, 저장 |
| 문장분석(모든 탭) | 고른 부분 + 질문과 답 | 지금 "지도에 넣기" 자리 → "노트에 담기"로 |
| 말하는 방·메시지 | 남의 줄 + 내가 물은 것("무슨 뜻이에요?")과 답, 쪽지 답 | 줄 인용(`lib/rooms/quote.ts`) |
| 단어장 | 단어 + 뜻 | 저장한 단어 |
| 노트 안 | 내 필기 한 줄, 사진(교재·손필기) | 의견 보내기의 사진 줄이기 코드 재사용 |

담을 때 **주석 한 줄**(질문: "이건 언제 써?", 메모)을 붙일 수 있다. 담은 것은 원래 자리로 가는 링크(그 대화·그 장면·그 방 줄)를 가진다.

## 4. 자리 찾기 — 장 하나 × 칸 하나

- **칸은 대부분 종류로 정해진다(모델 없이):** 단어 → 단어 칸, 고친 문장·문장분석 "왜 이런 형태야?" → 표현 칸, 영상 장면·"무슨 뜻이에요?" → 듣기 칸,
  대화 한 줄·팩 장면 → 장면 칸. 애매하면 장면 칸.
- **장은 AI가 고른다:** 8개 중 하나 + 한 줄 이유(모델 한 번, 싼 모델, 여러 개를 한 번에). 지금 `/api/curriculum/pick`이 표현을 주제에 넣는 판단을
  "8장 중 하나"로 바꾼 것이라 더 단순하고 싸다.
- 학습자는 담기 직후 "1장 · 표현에 넣을게요 — 이유"를 보고 **확인 / 다른 장** 한 번. 안 보고 넘기면 담아 둔 것에 남고, "한꺼번에 넣기"로 정리.
- 표현이 들어 있는 카드는 지금처럼 장부에 "고름" 표시, 그 장에 연습 할 일 하나(지금 "내가 고른 것"과 같은 규칙, 맨 앞).

## 5. 칸 안 — 카드가 쌓이면

- **카드:** 학습 언어 원문 · 내 주석 · (있으면) 답 · 원래 자리 링크 · 상태 점(그 표현이 숙지/배운 것/알아야 할 것 — 장부와 같은 판정).
- **답 받기:** 질문 주석이 있는 카드에 "답 받기"(AI, 그 장 맥락으로 UI 언어 답, 카드에 남음) 또는 "사람에게 묻기"(쪽지 — 지금 메시지 인용 그대로).
- **써보기:** 장 위 "이 장 연습" → 지금 "오늘 해볼 것"과 같은 연습 대화(튜터가 그 장 상황으로 먼저 말 걺, 써볼 표현 = 그 장의 배운 것). 채팅/통화 고르기.
- **할 일:** 장마다 할 일(지금 미션 그대로 — 할 일만, 힌트 3단계, 확인·교정). 장을 처음 열 때 3~5개, 담은 표현마다 하나씩 더.
- **이 장 정리:** 카드가 5개 넘게 늘면 "이 장 정리" 한 번(AI): 핵심 표현 5개·자주 물은 것·남은 질문을 장 맨 위 요약으로.
- **보는 방식(DESIGN.md 규칙):** 노트 안에서 목차 / 카드 모아보기 / 망(지금 "자라는 중") / 그래프 — 사용자가 고르고 기억.

## 7. 지금 있는 것과 어떻게 맞물리나

| 지금 기능 | 바뀐 뒤 |
|---|---|
| 체크로 시작 → 지도 그리기 | 체크는 남음(장 순서·오늘 해볼 것). 지도 그리기(모델 호출)는 없어짐 → 처음 비용 0 |
| 지도 주제·미션 | 장 안 할 일로. 이미 그린 지도의 주제·미션·진행은 가장 맞는 장으로 한 번 옮김(서버, 처음 열 때) |
| 내가 고른 것(지도에 넣기) | "노트에 담기"로 이름·자리만 바뀜, 할 일 만드는 규칙은 같음 |
| 자주 틀리는 것 | "자주 틀리는 것" 쪽 + 맞는 장 표현 칸에 할 일 |
| 내 표현(장부) | 그대로. 카드 상태 점과 "써보기"의 재료 |
| 자라는 중(망) | 그대로. "다음에 키울 곳"이 오늘 해볼 것의 한 후보 |
| 오늘 해볼 것 | 순서에 "답 안 받은 질문", "담아 둔 것 정리"가 추가 |
| 오늘의 팩 | 중심은 그대로(망). 나중에 "이 장으로 팩" 선택지 |
| 튜터 요약(brief) | 배운 표현 3개를 고를 때 담은 카드의 표현을 먼저 |
| 말하는 방·메시지 | 담기와 "사람에게 묻기"의 길 |
| 사용법(?)·새로워진 점 | My 단계 그림을 노트로 다시 찍음(RULES "버전을 자를 때마다 사용법도") |
| 옛 빌드(2.66·2.67) | 지도 화면 그대로 받음 — 서버의 지도 API는 남긴다 |

## 8. 저장·언어·비용

- **저장:** 노트 카드는 학습자 문장을 담는다 → "학습자 문장은 서버에 안 둔다"의 두 번째 예외(본인이 담은 것만). 로그인한 사람은 서버
  `notes:v1:<dataUserId>:<lang>`(장·칸·카드, 사진은 따로 키), 로그인 안 했으면 기기. 로그인하면 기기 것을 올릴지 묻는다.
- **언어:** 장·칸 이름은 고정 문구(14개 UI 언어). 카드 원문은 학습 언어 그대로, 주석·답은 쓴 그때의 UI 언어로 남고 UI를 바꿔도 그대로(지금 지도와 같은 원칙).
  학습 언어마다 노트 하나. 띄어쓰기 없는 언어의 표현 매칭은 `wordSegments.ts`.
- **비용(모델 호출):** 장 고르기(여러 개 한 번에, 싼 모델) · 답 받기 · 이 장 정리 · 할 일 만들기(지금 있음). 각각 `meterRequest` op와 `opCost.ts` 단가.
  지도 그리기가 빠지니 첫 사용 비용은 줄어든다.

## 9. 공유 ("난 이렇게 한다") — 마지막 단계
- 뼈대가 같아서 공유 단위가 분명하다: **장 하나 또는 노트 전체**에서 내가 고른 카드 + 장 요약 + 내 루틴 한 줄.
- 받은 사람은 "내 노트로 가져오기" → 카드가 같은 장·칸에 "가져온 카드"로 들어감(원래 주인 표시, 지우기 자유).
- 보이는 곳: 사람 탭 프로필 시트의 "노트" 칸, 같은 학습 언어끼리만. 로그인한 사람만 올리고, 신고·숨기기(지금 신고 흐름 재사용).

## 10. 단계
1. **노트 뼈대 + 담기 + 담아 둔 것 + 손으로 넣기**(AI 없음): My에 노트 보기, 채팅·통화·문장분석·영상·방·단어장에 📌, 카드 화면, 저장(서버/기기). 14개 언어.
2. **자리 찾기(AI 장 고르기) + 지도 옮기기 + 장 안 할 일**: 옛 지도·미션·자주 틀림이 장으로 들어가고, 지도 보기를 노트로 바꿈.
3. **답 받기 · 이 장 연습 · 이 장 정리 · 노트 검색**, 오늘 해볼 것 순서 추가, 사용법 그림.
4. **공유.**

## 11. 정할 것
1. 장 8개와 이름 — 위 표대로 갈지, 바꿀 장이 있는지.
2. 저장: 로그인은 서버·아니면 기기 (추천) / 모두 기기.
3. 자리 찾기: AI가 제안하고 확인 한 번 (추천) / 바로 넣고 나중에 옮기기.
4. AI 한도: 장 고르기는 차감 없음(싸고 묶어서), 답 받기·이 장 정리는 지금 "직접 질문" 한도에 포함 (추천).
5. 이미 그린 지도: 장으로 옮기고 지도 보기는 없앰 (추천) / 당분간 "예전 지도" 보기로 남김.
