- 요청: 사용자 "ai api 3개 추가했어. 그걸로 돌려보고 결과 알려줘"(Anthropic·ElevenLabs·AssemblyAI). 받아쓰기 둘은 10-21 다른 채팅이 비교 끝(`speech-models-2026-10-21.md`·log) → 아직 안 한 **채팅 교정을 실제 Anthropic API로**.
- 방법: 운영 서버, 가상 사용자 196명 × tiers 8칸(씨앗 7, 같은 문장), 하나는 기본 경로(`cmpgpt-20261022`), 하나는 `--model-routes '{"basic":"anthropic: claude-haiku-5-5"}'`(`cmphaiku-20261022`, simcheck- 사용자만 — 실제 사용자 변화 없음).

## Haiku가 약한 곳
1. **섞은 모국어 낱말을 그대로 둠** — "I went to the 시장 yesterday" → 고친 문장에 시장 그대로(답에서만 (friend) 식으로 알려 줌). 교정 지시가 Haiku에게는 약하게 먹음 → 프롬프트 손보기 필요.
2. **선생님께 명령조·반말을 덜 짚음**(프랑스어 donne-moi… 등, 둘 다 약하지만 Haiku가 더 놓침). 한국어는 `chat/verify` 위험 규칙이 잡지만 다른 언어는 아님.
3. 가벼운 실수 놓침(en boring→bored, ru люблю очень 어순).
4. **느림**: 중간 2.8배. 채팅에서 4~10초는 체감됨 — 원인(Anthropic 응답 자체·다시 쓰기 횟수·스트리밍 없음) 확인 필요.

## 판단(제안)
- 정확도는 Haiku가 확실히 위(틀린 걸 가르치는 일이 1/6). 비용도 어림으로 더 쌈(턴 0.67→0.49원, 실측 전).
- 바로 전환 전에: ① 섞은 낱말·말투 지시를 Haiku용으로 보강 후 같은 씨앗 재시험 ② 응답 시간 원인 보고 줄이기(목표 중간값 2.5초 안) ③ 그다음 `MODEL_ROUTES`로 chat만 전환.
