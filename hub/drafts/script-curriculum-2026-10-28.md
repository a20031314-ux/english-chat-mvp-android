# 대본 커리큘럼 1년 설계 (초안, 2026-10-28)

> 사용자와 나눈 방향 정리(2026-10-28 00:05~01:30 채팅). **결정 전 초안** — 아래 "정할 것"이 남아 있다.
> 이미 만든 것: 단계 대본 1~5(ko·ja·es), 무료 = 대본·대본 플랜 2,900원(`pricing-scripts-2026-10-28.md`), 오늘의 대본 A, 틀 바꿔 말하기 시범(ja 1~2), 노트 오늘의 학습. 이 문서는 그 위에 **아직 없는 것**을 적는다.

## 한 줄 요약

틀 중심 대본으로 배우고 → 자유 대화·사람 대화에서 쓰고 → 못 쓰면 **내가 틀린 문장으로** 짧게 다시 → 숙지 → **사람과의 대화가 더 빠른 지점**에서 사람 쪽으로 넘긴다.

## 1. 목표와 기간 (정직한 약속)

- 대략값: 일상 대화가 편해지는 수준(내부 기준 B1~B2)까지 학습 400~600시간(먼 언어 기준, 가까운 언어 조합은 더 짧음).
- 하루 30분 × 1년 ≈ 180시간 → 여행·일상 대화. 하루 1시간 ≈ 365시간 → 원어민과 일상 대화를 스스로 이어 감. 1.5~2시간 → 의견·이야기까지.
- **"원어민 수준"은 약속하지 않는다**(스토어·홍보 문구 포함, 과장 광고). 쓸 말: "원어민과 대화할 수 있을 때까지".
- 레벨 이름(A1·B2)은 내부 설계에만 — 화면에 안 보임(STATE 결정).

## 2. 대본은 "넘기는 지점"까지

대본의 목표 = 원어민 수준이 아니라 **사람과 대화해도 서로 괜찮은 수준까지 데려다 주기**. 그 전에 사람과 붙이면 학습자도, 상대 원어민도 지쳐 떠남 → 대본은 사람 기능의 질을 지키는 장치이기도 함.

넘기는 지점(대략 지금 3단계 끝, 하루 30분이면 4~6달):
1. 익숙한 주제(나·일·취미·하루)로 3~5분 혼자 이어 감
2. 되묻는 말을 씀(천천히요·다시 한 번요·무슨 뜻이에요?)
3. 상대가 조금 천천히 말하면 대부분 알아들음

단계별 비율:

| 단계 | 대본 | 나머지 |
|---|---|---|
| 1~2 | 주력(정해진 말) | 채팅 대본으로 기능 익히기 |
| 3 | 틀만 주고 "내 말로" | 짧은 AI 자유 대화 |
| — | **넘어가기 대본**(아래) | "사람과 대화해 보기" 열림 |
| 4~5 | 대본 대신 **사람 대화 과제** | 1:1·Room·영상·AI 자유 대화 |

- **넘어가기 대본**(AI가 사람 역할): 언어 교환 첫인사·자기소개, 되묻기·속도 늦춰 달라기, 고쳐 달라고 부탁하기, 상대 말 고쳐 주기, 화제 바꾸기, 자연스럽게 끝내기.
- **사람 대화 과제**(4~5단계): "이번 주 1:1에서 주말 이야기", "Room에서 한 번 손들기" — 끝나면 고친 내 줄이 노트로.
- 열리는 조건(숫자는 정할 것): 3단계 대본 모두 통과 + 내 말로 통과율 + AI 자유 통화 n분 막힘 없이 → My 단계 보기에 "사람과 대화해 보기", 내 언어를 배우는 원어민 우선(사람 탭 거르기 있음).
- 사업 면: AI 원가가 앞쪽 몇 달에 몰리고, 사람 대화는 원가가 거의 없음 → 오래 남는 구독자일수록 이익. 대본 플랜 = "넘어가기까지 데려다 주는 요금".

## 3. 틀 중심 (낱말을 다 외우게 하지 않음)

- 가르치는 단위 = **틀 + 바꿔 끼우는 자리**(`~했어요`, `~하고 싶어요`, `~해도 돼요?`). 틀 하나로 문장 수십 개.
- 대본 하나에 목표 틀 2~3개, 같은 틀이 뒤 대본에 다른 상황으로 다시 → 따로 복습 화면 없이 간격 반복.
- "내 말로" = 틀은 그대로, 자리만 내 이야기 → 판정은 틀을 맞게 썼는지.
- 자리에 넣을 낱말은 **필요할 때 생김**: 모르면 편한 말로 → 표현 보기 → 단어장.
- **공통 기능 목록**(과거 일 말하기·바람 말하기 등, 약 100~150개)은 14개 언어 공통, **틀은 언어별**(ko·ja 어미, en·es 동사 꼴·어순, zh·th 어순). 커리큘럼 = 공통 기능 → 언어별 틀 → 그 틀을 담은 대본 → 넘기는 지점.
- 이미 있음: `curriculum/frames.ts` + `frames/ja.ts`(ja 1~2단계 36개 시범). 남음: 공통 기능 id로 묶기, ko·es·en부터 다른 언어.
- 분량 감각: 넘기는 지점까지 언어당 대본 80~120개(지금 ko 40·ja 42·es 31) + 틀. 4~5단계는 상황 카드라 가벼움. 주력 언어(en·ko·ja·es)부터, 원어민 확인.

## 4. 채팅 대본 = 첫 사용자 튜토리얼 겸 1단계

문장분석·표현 보기·✎ 칩·🔎 My에서 찾기는 써 보기 전엔 존재를 모름 → **설명하지 않고 해 보게 하는 대본**.

- 튜터 줄(학습 언어) + 지시 한 줄(UI 언어) "‘…’라고 써 보세요" — 대본 내용이라 "화면 속 설명 금지" 규칙과 안 부딪힘.
- 단계가 오를수록 덜 보여 줌: 문장 전체(따라 쓰기) → 뜻만 → 상황만(내 말로).
- 막히면 힌트 3단계: 첫 낱말 → 앞부분 → 전체(미션·통화 대본과 같은 방식). 틀리면 평소 ✎ 칩 = 교정 기능 소개.
- 1단계 대본 하나 = 기능 하나: ① 편한 말로 써 보기 → 표현 보기 ② 틀리기 쉬운 질문 → ✎ 칩 ③ 튜터 줄에 모르는 낱말 → 줄 눌러 분석 ④ 🔎 My에서 찾기 → 노트에 넣기. 넘어가는 조건 = 그 동작을 했는지.
- 끝나면 대본을 My 그 단계에 저장, 줄을 누르면 듣기·번역·분석. 틀린 줄은 노트 오늘의 학습으로.
- 같은 상황을 채팅(쓰기) → 통화(말하기) 두 번 — 같은 틀을 두 번 씀.
- 원가: 튜터 줄 고정, 비교는 기기, 모델은 틀렸을 때만 → 거의 0.
- **부딪힘:** 2.76 무료는 채팅 0(대본 중심 요금). 채팅 대본을 무료에 열려면 "대본 안 채팅 줄은 채팅 횟수 밖"으로(대본 줄 하루 한도 `dailyScriptLines` 안에서).

## 5. 다시 권하기 — 내가 틀린 문장으로

배운 틀을 자유 대화에서 못 쓰면 짧게 다시. 노트 다음 단계로 계획해 둔 "지난번에도" 꼬리표·"자주 막히는 곳 → 연습"(STATE 노트 줄)이 이것.

신호:
1. **틀렸다**: 채팅·통화·사람 대화의 ✎ 교정이 배운 틀과 관련.
2. **피했다**: 배운 틀로 말할 걸 편한 말로 → 표현 보기 답이 배운 틀("배웠는데 생각 안 남"). 판정 정확도 확인 뒤 켬 — 처음엔 1만.

같은 틀에 일정 기간 신호 2번쯤 → My 대본 ● → ◐ "다시", 교정 칩 안에 버튼 "이 틀 다시 연습"(버튼 이름이라 규칙 안).

다시 연습 화면(4장면):
1. **내가 쓴 줄** — 언제·어디서(AI 대화·통화·1:1)
2. **이렇게 쓰면 돼요** — 바뀐 부분만 굵게(지금 교정 카드 부품)
3. **틀 한 줄**(UI 언어) + 같은 틀이 나온 대본 줄("대본에서: …") — 배운 것과 연결
4. **바로 써 보기** — 내 문장 다시 → 자리만 바꿔 1~2번 → 내 말로 하나. 여러 번 틀린 틀이면 틀린 줄 2~3개까지(= "지난번에도")

통과 → 다음 자유 대화에서 그 틀을 맞게 쓰면 숙지.

만들 것: 틀 id를 대본 줄·노트 카드에, 채팅 교정 호출에 그 언어 틀 목록을 주고 "관련 틀 id"를 같이 받기(같은 호출, 추가 비용 거의 없음 — 쉬운 틀은 기기에서 글자 비교), 틀별 기록(맞음·틀림·피함 횟수, 계정 — 틀 id와 횟수만이라 문장 저장 규칙과 맞음).

조심: 하루 권유 1~2번 상한, 연습한 틀은 며칠 다시 안 권함, **사람 대화 중엔 안 띄움**(기록만, 권유는 끝난 뒤 My·다음 AI 대화), 틀 판정 오류 → 엉뚱한 권유.
