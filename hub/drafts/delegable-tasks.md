# 다른 사람에게 넘길 수 있는 일

> 작성: 2026-10-18 · main `6bebf26` 기준. hub/(roles·inbox·drafts)에서 **사람이 해야 하고 Claude가 못 하는 일** 중 남에게 맡길 수 있는 것을 모음.
> 코드·허브 작업은 계속 역할 채팅(dev/qa/store)이 맡는다. 맡긴 일이 생기면 그 줄 끝에 `→ 맡은 사람, 날짜`를 적고, 끝나면 지우고 로그에 남긴다.

## 1. 바로 넘길 수 있는 것 (저장소·콘솔 권한 필요 없음)

### 원어민 문구 확인 — 효과 가장 큼
파일과 확인할 줄만 주면 된다. 결과는 고친 문장 목록으로 받아 dev 채팅이 반영(14개 언어 체크리스트는 `hub/RULES.md`).
- 사용법(?) 글 12개 언어(채팅·단어장·영상·My): Claude가 직접 씀, 원어민 확인 권장 — `src/lib/guide/content.ts`, `src/lib/guide/translations.json`
- 오늘의 팩 질문 문장(en·ja) — `hub/drafts/daily-pack.md`, 서버 팩 데이터
- 통화 맞장구 표(en·ja·es) 확인 + 나머지 11개 언어 표 새로 — `src/lib/roleplay/reactions.ts`
- 일본어 지도 미션 표현 중 조사로 끝나는 조각("今日の会議は" 등)
- 스토어 등록정보 초안(영어·한국어) — `hub/drafts/store-listing-2026-10-10.md`

### 기기 테스트 — 밀린 양이 제일 많음
- 대상: `hub/inbox.md`의 `→ qa` 줄들(20개 이상). 마이크·영상 재생·다음 날 복습·업데이트 안내처럼 웹에서 못 보는 것.
- 맡기는 법: 안드로이드 폰이 있는 사람을 Play **내부 테스트**에 추가 → inbox 줄을 그대로 체크리스트로 전달(언어 조합 ja/ko, en/ja, es/ar까지 적혀 있음).
- 받을 것: 항목별 통과/실패 + 스크린샷. qa 채팅이 `roles/qa.md` "최근 결과"에 옮기고 문제는 `qa → dev`로.
- 주의: 사용자 스크린샷 원본은 커밋하지 않는다(`hub/RULES.md` 데이터·보안).

## 2. 권한 일부를 주면 넘길 수 있는 것
- **스토어 등록정보·스크린샷 올리기:** Play Console에 "스토어 등록정보 관리"만 가진 사용자로 초대.
  맞춤 등록정보(한국·중국·일본·스페인·인도) 이미지 업로드, 2.67 "학습 지도 → 프로필"·"자막+번역"·요금 문구 정리.
- **RevenueCat 상품 연결**(`lite_monthly`·`plus_monthly` → `premium` 권한·current 오퍼링): 협업자 초대 가능. 다만 매출에 바로 걸려 본인 권장.

## 3. 넘기지 않는 것 (본인만)
- 서명 키·Signed Bundle 빌드·Play 업로드 (키가 새면 앱 업데이트가 막힐 수 있음)
- 요금·출시 결정, `premium_monthly` 8,900원 전환 날짜(`PREMIUM_DAILY_PLAN_FROM`)
- 의견함 반영/보류/안 함 결정 (`hub/feedback/README.md`)
- 키·토큰(OpenAI, 피드백 읽기 키), 사용자 데이터·의견 원문
