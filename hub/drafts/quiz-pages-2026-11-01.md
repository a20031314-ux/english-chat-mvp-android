# 소재 페이지 + 정기 시험 — 설계안 (2026-11-01)

> 사용자 대화(2026-11-01 14:42~14:46) 정리:
> - "문장 반복은 소재가 한정된 문법·표현 퀴즈 특성상 피하기 어렵다, 예문을 계속 생성할 순 없다"
> - "설명·예문을 고정해 두고, 다른 학습을 하다 모를 때 이동해서 확인, 거기에 적용 학습"
> - "퀴즈를 소재 페이지에 숨겨 넣고 선택적으로" → "자주 확인하는 소재를 모아 토익식 정기 시험"
> - "단어 모음 시험과 통합할지 분리할지 정해줘" → 분리 + 정기 시험에 어휘 파트
>
> 상태: **설계안, 코드 전.** 사용자 확인 뒤 단계별로 만든다. 퀴즈 알고리즘 문서 `hub/QUIZ.md`는 만들 때 같은 커밋에서 고친다.

## 0. 왜

- 문법·표현 퀴즈는 소재 수가 정해져 있어 같은 문장이 다시 나온다.
  - 전수 점검: 새 예문 2,200을 넣은 뒤에도 "같은 문제 또" 1,085, 그중 문법 탭 1,070.
  - 예문을 계속 새로 만드는 건 비용·품질 모두 끝이 없다.
- 반복 자체가 나쁜 게 아니라 **같은 날·연달아** 나오는 것, 그리고 **새로 배우는 걸 퀴즈로만** 하는 것이 문제다.
  - 간격을 두고(1·3·7일) 다시 떠올리는 건 기억에 가장 효과가 크다.
  - 설명을 다시 읽는 것만으로는 잘 안 남는다.
- 그래서 역할을 나눈다.
  - **배우기·확인** = 고정된 소재 페이지
  - **떠올리기** = 선택 퀴즈 + 주기적인 정기 시험
  - **쓰기** = 적용 학습

## 1. 전체 구조

```
들어오는 길                         소재 페이지 (고정)                      모아서 확인
통화 정리 고친 말·막힌 말 ─┐     ┌ 설명 (뜻·구조·쓰임)                 ┌ 정기 시험 (주 1회 또는 모인 소재 20개)
채팅 교정 ─────────────────┤     │ 예문 넷 (🔊, 고정)                  │  어휘 · 빈칸 · 틀린 곳 · 대화 응답(듣기) · 짧은 대화 빈칸 · 직접 쓰기
대본 틀린 줄·막힌 줄 ──────┼──→  │ 📝 퀴즈 (선택, 세 문제)       ──→   │  결과: 파트별 n/m · 지난번과 비교
Logbank 칩 ────────────────┤     │ ✍ 적용 (내 말로 한 문장)            └ 맞힘 → 익힘 / 틀림 → 다음 시험·"지난번에 틀린 것"
Quizbank 문법·표현 목록 ───┘     └ 이 소재가 나온 내 장면 (통화·채팅 줄)
                                                                        단어 시험 (어휘 탭, 지금 그대로 — 분리)
```

## 2. 소재 페이지

- **대상:** 문장구조(f|) · 단계 핵심 표현(e|) · 문법 칸(g|). 낱말(w|)은 지금 낱말 시트 그대로.
- **틀:** 지금 문장구조 수업 `FrameLesson`의 [설명 › 퀴즈 › 대화]를 넓혀, 소재마다 한 화면으로.
  - 설명: 뜻 · 구조(조각마다 하는 일) · 쓰임. 문장구조는 `/api/curriculum/frame-lesson` 공유 캐시를 그대로 쓰고, 표현·문법 칸도 같은 방식으로.
  - 예문 넷: 고정. 앱 데이터 + 새 예문(`curriculum/examples`). 🔊, 뜻은 누르면.
  - **📝 퀴즈 (선택):** 버튼을 눌러야 열린다. 세 문제(빈칸 쓰기 · 고르기 · 틀린 곳)로 끝. 셋 다 맞히면 다음 때까지 쉼. 복합 퀴즈·대화 조각 빈칸도 여기로 옮긴다.
  - **✍ 적용:** 앱 언어로 상황 한 줄("동료에게 마감이 빠듯하다고 말해 보세요")을 보고 이 소재로 한 문장을 쓰거나 말한다. 판정은 대본 "내 말로" 판단(`scriptJudge`: Haiku → 틀림이면 Sonnet)을 그대로 쓴다.
  - **이 소재가 나온 내 장면:** 이 폰의 통화·채팅에서 이 소재가 든 줄 두셋. 대화 조각 빈칸이 쓰는 기록과 같은 재료다.
- **한 번 만들어 모두가 같이 쓴다:** 설명·적용 상황은 학습 언어 × 소재 × 앱 언어마다 한 번 만든다. 보는 사람마다 만들지 않는다.

## 3. 들어오는 길 — "모를 때 이동해서 확인"

| 어디서 | 무엇을 누르면 | 지금 |
|---|---|---|
| 통화 정리(CallRecap) | 고친 말·💡·뜻 본 말 → 🧩 | 문장구조 수업으로 감(locateHandoff) — 표현·문법 칸도 그 페이지로 |
| AI 채팅 교정 카드 | "이 소재 보기" | 없음 — LineTools `extra`에 하나 |
| 대본(ScriptPlayer) 틀린 줄·막힌 줄 | 줄 아래 소재 칩 | 문장구조 칩만 — 페이지로 |
| Logbank 날마다 칩 | 문법·어휘·표현 칩 | 표현 자세히 — 소재 페이지로 |
| Quizbank 문법·표현 탭 | 소재 목록 줄 | 문제가 바로 나옴 — 목록으로 바꿈 |

- **무료 사용자도 길이 있어야 한다:** 무료는 대본만 쓸 수 있어 통화·채팅 길이 없다. 대본 틀린 줄 → 페이지, Logbank → 페이지가 무료의 주 경로다.

## 4. Quizbank 탭이 어떻게 바뀌나

- **어휘:** 지금 그대로 퀴즈. 처음 보는 낱말 · 수준 맞추기 · 단어 시험.
- **문법 · 표현:** 문제를 계속 내는 대신 **소재 목록**.
  - 지금 단계까지 배운 소재.
  - **때가 된 것(1·3·7…일, 지금 REST_DAYS)에 ● 표시**, 위로.
  - 줄을 누르면 소재 페이지.
- **지난번에 틀린 것:** 그대로 문제. 틀린 건 다시 떠올리게 한다.
- **오늘 할 것:** "다시 볼 것 n개" 한 줄. 누르면 때가 된 소재 페이지의 📝로 차례로. 강제는 아니지만 할 일은 보이게.

## 5. 정기 시험 (토익식)

- **언제:** 주 1회, 또는 "모은 소재"가 20개를 넘으면 Logbank 머리와 오늘 할 것에 📝 시험 줄. 지금 Logbank "이번 주 확인"(CheckupPlayer 12문제) 자리를 이것으로 키운다.
- **무엇을 모으나:** 많이 걸린 순으로 20~30개 + 익힌 것 몇 개(잊었는지 확인).
  - 소재 페이지를 연 횟수(모를 때 열어 봄 = 약한 곳, 이 폰에 기록)
  - 통화·채팅에서 고친 말의 소재
  - 대본에서 틀린 줄
  - 지난 시험에서 틀린 것
- **파트 (정해진 순서, 파트마다 문제 수 고정):**

| 파트 | 모양 | 재료 |
|---|---|---|
| 1 어휘 | 빈칸 쓰기·뜻 고르기 5문제 | 단어 시험에서 아직 못 익힌 낱말 중 오래된 것 + 소재 페이지 예문의 낱말 |
| 2 빈칸 | 문법·표현 빈칸 쓰기·고르기 | 모은 소재 |
| 3 틀린 곳 | 틀린 곳 찾아 고치기 | 모은 소재 + 내가 고침받은 줄 |
| 4 대화 응답 | 상대 줄을 듣고 알맞은 대답 고르기(듣기) | 대본·소재 페이지 예문 |
| 5 짧은 대화 | 대화 속 빈칸 여러 개(지금 복합 퀴즈) | 모은 소재 둘·셋이 든 문장 |
| 6 직접 쓰기 | 뜻 보고 문장 쓰기(적용) — 2~3문제 | 모은 소재 |

- **결과:** 파트별 맞힌 수 n/m · 지난번과 비교(늘어난 파트). A1·B2 같은 등급·점수 환산은 보여 주지 않는다(STATE "학습 수준은 보여 주지 않는다").
  - 맞힌 소재 → 익힘(지금 규칙: 한 번 맞히면 익힘, 잊을 때만 다시).
  - 틀린 것 → "지난번에 틀린 것" + 다음 시험.
- **예문 반복:** 주 1회라 같은 문장이 나와도 다시 떠올리기 자체가 목적이다. 문제은행에서 바꿔 줄 수 있으면 바꾼다.

## 6. 단어 시험과의 관계 — 분리 (결정)

- **분리하는 이유:** 단어 시험은 새 낱말 20개마다·틀림 8개마다 뜨는 **잦고 짧은** 시험이다. 틀린 낱말 30개를 넘으면 새 낱말을 쉬는 규칙과 묶여 있다. 정기 시험은 **주 1회 종합**이다. 합치면 단어 시험이 뜸해져 틀린 낱말이 쌓이거나, 종합 시험이 잦아져 부담이 된다.
- **잇는 곳:** 정기 시험 파트 1 어휘(5문제)만. 단어 시험 기록(`quizCircle.v1`)·주기는 그대로 두고, 정기 시험 어휘 결과도 같은 기록에 남긴다.

## 9. 만드는 순서 (안)

1. 소재 페이지 틀: 문장구조 수업을 표현·문법 칸으로 넓힘. 설명·예문·📝(세 문제)만. Quizbank 문법·표현 탭을 목록 + ● 로.
2. 들어오는 길: 대본 틀린 줄·Logbank 칩·통화 정리·채팅 교정 → 페이지.
3. ✍ 적용: 판정·한도, op 추가.
4. 정기 시험: Logbank 이번 주 확인 자리, 파트 1~6, 결과 화면.
5. 오늘 할 것 "다시 볼 것 n개".

각 단계마다 사용자 체감 점검(가상 사용자)·퀴즈 전수 점검을 다시 돌린다(RULES 11·"사용자 체감 점검").

## 10. 사용자에게 물어볼 것

1. 위 순서로 시작해도 되나 — 1·2를 먼저 한 빌드로 낼지, 1~4를 묶을지.
2. 적용 판정 무료 한도: 하루 3번(안).
3. Quizbank 문법·표현 탭을 목록으로 바꾸면 "문제를 바로 푸는" 흐름이 없어진다 — 괜찮나, 아니면 목록 맨 위에 "때가 된 것 바로 풀기" 한 줄을 둘까.
4. 정기 시험 주기: 주 1회 고정 / 모인 소재 20개 / 둘 중 먼저.
