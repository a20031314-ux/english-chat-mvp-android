# 설명은 Stagebank, 문제는 Quizbank — 설계안 (2026-11-01)

> **결론:** 설명·예문·적용은 Stagebank 한 곳에만 두고, Quizbank는 문제를 만들고 내는 데 집중한다.
> 문법·표현은 정기 종합 시험과 틀린 것 집중으로 바꾸고, 어휘는 지금 그대로 둔다. 소재 페이지는 따로 만들지 않는다.
>
> 사용자 대화(2026-11-01 14:42~14:55) 순서:
> 1. "문장 반복은 문법·표현 퀴즈 특성상 피하기 어렵다, 예문을 계속 생성할 순 없다"
> 2. "설명·예문 고정 + 모를 때 이동해서 확인 + 적용 학습"
> 3. "자주 확인한 소재로 토익식 정기 시험"
> 4. "단어 모음 시험과 통합할지 분리할지 정해줘" → 분리
> 5. "소재마다 문제 유형을 다양화해 난이도를 나누는 방식"
> 6. "종합 시험 + 틀린 부분만 집중 학습"
> 7. "소재 페이지를 굳이? 문법·표현은 단계 학습에서 다 접하니 그쪽을 구체화, Quizbank는 문제 제작에 집중" → "설계해줘"
>
> 상태: **설계안, 코드 전.** 사용자 확인 뒤 단계별로. 만들 때 같은 커밋에서 `hub/QUIZ.md`·PRODUCT "My"·STRUCTURE를 고친다.

## 0. 왜

- 문법·표현 퀴즈는 소재 수가 정해져 있다. 끝없이 내면 같은 문장이 돈다.
  - 새 예문 2,200을 넣은 뒤에도 "같은 문제 또"가 1,085, 그중 문법 탭이 1,070.
  - 예문을 계속 만드는 건 끝이 없다.
- 반복 자체가 나쁜 게 아니다. 문제는 두 가지다.
  - **매일·연달아** 나오는 것.
  - **설명이 문장구조에만 있어서** 표현·문법은 퀴즈로만 배우게 되는 것.
- 같은 설명을 두 곳에 두면 이름·내용이 갈라진다(RULES "같은 기능 = 같은 이름, 한 곳에만"). 그래서 역할을 나눈다.
  - **Stagebank:** 처음 배우고, 모를 때 와서 확인하고, 적용한다.
  - **Quizbank:** 떠올리게 한다 — 시험, 틀린 것 집중, 어휘.

## 1. 한 장 흐름

```
Stagebank (배우기 · 확인 · 적용)           Quizbank (문제)
 n단계 ─ 🧩 문장구조 수업 (있음)             어휘 탭 — 지금 그대로 (처음 보는 낱말 · 수준 맞추기 · 단어 시험)
       ─ 🔤 표현: 설명·예문 + 적용 (새로)    문법·표현 → 📝 정기 종합 시험 (주 1회 또는 배운 소재 쌓이면)
       ─ 문법 칸: 설명·예문 + 적용 (새로)               └ 틀린 것 집중 (지난 시험에서 틀린 소재만, 아래 칸부터)
       ─ 🎯 꺼내 쓰기 · 🎭 상황 (있음)       지난번에 틀린 것 — 집중과 합침
          ▲                                       │
          └──────── "설명 보기" ───────────────────┘
          ▲
 통화 정리 · 채팅 교정 · 대본 틀린 줄 · Logbank 칩 — "모를 때 이동해서 확인"
```

## 2. Stagebank 구체화 — 설명·예문·적용의 유일한 곳

- **지금:**
  - 문장구조는 수업이 있다: 설명(뜻·구조·쓰임·예문 넷) → 퀴즈 세 문제 → 대화 세 번.
  - 표현은 "🔤 표현" 대본 연습만 있고, 표현 하나하나의 설명은 없다(문장분석 시트의 표현 자세히가 비슷함).
  - 문법 칸은 이름만 보인다("배울 수 있는 것" 시트).
- **새로:** 표현·문법 칸 하나도 문장구조 수업과 같은 모양 하나로 연다.
  - **설명:**
    - 표현: 뜻 · 언제 쓰나 · 비슷한 말과 다른 점 · 말투(격식/반말).
    - 문법 칸: 규칙 한두 줄 · 꼴 바뀜 표(필요한 언어만) · 흔한 실수 하나.
    - 학습 언어 × 소재 × 앱 언어마다 서버가 한 번 만들어 모두 같이 쓴다. 지금 `/api/curriculum/frame-lesson` 공유 캐시와 같은 방식, 화면 문구는 copy 14개 언어.
  - **예문 넷:** 고정이다. 앱 데이터에 새 예문(`curriculum/examples`)을 더해 고른다. 🔊, 뜻은 누르면.
  - **적용:**
    - 앱 언어 상황 한 줄("동료에게 마감이 빠듯하다고 말해 보세요")을 보고 이 소재로 한 문장을 쓰거나 말한다.
    - 판정은 대본 "내 말로"(`scriptJudge` — Haiku, 틀림이면 Sonnet)를 그대로 쓴다.
    - 맞히면 "써 봄" 표시. 다음 단계 조건에 넣을지는 사용자가 정한다(10절).
  - **문장구조 수업의 퀴즈 세 문제:** 수업 안에 그대로 둔다. 처음 배울 때의 확인이다.
- **들어오는 화면:**
  - n단계 연습 방식 고르기의 🔤 표현 → 표현 목록 → 하나.
  - 문법 칸은 단계 화면의 문법 칸 줄(지금 "배울 수 있는 것"의 이름)을 누르면.
- **무료 사용자도 Stagebank는 쓴다.** 통화·채팅이 없는 무료 사용자의 "모를 때 확인" 길은 대본 틀린 줄·Logbank에서 여기로 오는 것이다.

## 3. 들어오는 길 — 모를 때 Stagebank 그 소재로

| 어디서 | 무엇을 누르면 | 지금 → 새로 |
|---|---|---|
| 통화 정리(CallRecap) | 고친 말·💡·뜻 본 말 → 🧩 | 문장구조 수업(locateHandoff) → 표현·문법 칸도 같은 곳 |
| AI 채팅 교정 카드 | "설명 보기" | 없음 → LineTools `extra` 하나 |
| 대본(ScriptPlayer) 틀린 줄·막힌 줄 | 소재 칩 | 문장구조 칩만 → 표현·문법 칩도 |
| Logbank 날마다 칩 | 문법·어휘·표현 칩 | 표현 자세히 시트 → 그 소재 설명 |
| Quizbank 틀린 문제 | "설명 보기" | 없음 → stagePeek(오늘 할 것에서 단계 화면을 여는 길)을 넓혀서 |

- **소재 → 자리 찾기:** 서버의 틀 칸 찾기(`FindInMy`·`locateHandoff`)를 표현·문법 칸까지 넓힌다.

## 4. Quizbank — 문제만

- **어휘 탭:** 지금 그대로. 처음 보는 낱말 · 수준 맞추기(쉬워요·적당해요·어려워요) · 단어 시험(새 낱말 20개마다, 틀린 낱말 30개 넘으면 새 낱말 쉼). 정기 시험과 **분리**(6절).
- **문법·표현:** 끝없이 푸는 탭 대신 두 가지.
  1. **📝 정기 종합 시험**(5절).
  2. **틀린 것 집중** — 지난 시험(과 통화·대본)에서 틀린 소재만.
     - 그 소재 문제를 사다리 아래 칸부터 2~3문제.
     - 맞히면 다음 시험까지 쉰다.
     - 틀린 문제 아래 "설명 보기" → Stagebank.
     - 지금 "지난번에 틀린 것" 탭이 이것이 된다.
- **오늘 할 것:** 틀린 것 집중이 남아 있으면 "다시 볼 것 n개" 한 줄. 시험 날이면 "📝 시험" 한 줄.
- **탭 이름(안):** [어휘 | 시험 | 다시 보기]. 지금의 [어휘 | 문법 | 표현 | 지난번에 틀린 것] 넷을 셋으로 — 같은 일 = 같은 이름. 이름은 copy에서 같은 일을 하는 기존 문구를 먼저 찾아 쓴다.

## 5. 정기 종합 시험

- **언제:**
  - 첫 시험은 배운 소재가 15~20개 쌓인 뒤. 처음 설치하자마자 시험 내지 않는다 — 점검에서 "첫 실행 시험"이 헷갈렸음.
  - 그 뒤는 주 1회 또는 모인 소재 20개 중 먼저 오는 쪽(10절).
  - Logbank의 "📝 이번 주 확인"(CheckupPlayer 12문제)을 이것으로 바꾼다.
- **무엇을:** 25문제 안팎.
  - **약 70%:** 배운 소재 중 걸린 것 — 틀린 것, 고침받은 것, 막힌 것, 설명을 열어 본 것.
  - **약 30%:** 맞혔던 것 중 잊을 때(1·3·7·14·30일)가 된 것.
- **소재마다 사다리 칸**(같은 소재도 시험마다 모양이 바뀐다 — 반복이 지루하지 않게):

| 칸 | 모양 | 채점 | 지금 만들어지는 소재(14개 언어, 3,298 중) |
|---|---|---|---|
| 1 | 빈칸 고르기 | 기기 | 2,471 |
| 2 | 순서 맞추기 | 기기 | 2,904 |
| 3 | 빈칸 쓰기 | 기기(글자 다르면 서버 다시 보기) | 2,519 — 중국어 0, 일본어 109/236 |
| 4 | 틀린 곳 고치기 | 기기 | 약 1,200(어림) — 문장구조만 확실히 틀린 꼴 목록이 있음 |

  - 처음 시험은 1칸. 맞히면 다음 시험에서 한 칸 위, 틀리면 한 칸 아래.
  - 4칸을 맞히면 익힘(지금 규칙 "한 번 맞히면 익힘, 잊을 때만 다시"와 맞춤).
  - 칸이 없는 소재는 다음 칸으로 건너뛴다.
  - 같은 시험 안에서 한 소재는 한 문제만(RULES 11 ④).
- **파트(정해진 순서):**
  1. 어휘 5문제 — 단어 시험에서 아직 못 익힌 낱말 중 오래된 것
  2. 알아보기 — 1·2칸 소재
  3. 떠올리기 — 3·4칸 소재
  4. 대화 응답 — 상대 줄 듣고 대답 고르기, 듣기, 대본 줄
  5. 짧은 대화 — 지금 복합 퀴즈·대화 조각 빈칸
- **결과:**
  - 파트별 맞힌 수 n/m · 지난번과 비교. 등급·점수 환산은 보여 주지 않는다(STATE).
  - 틀린 소재 → "다시 보기"(틀린 것 집중) + 다음 시험에 꼭.
  - 맞힌 것 → 칸 올림·익힘.
- **예문:** 소재마다 칸별로 한 문제를 고정해 두고(재료는 앱 데이터 + 새 예문 + 문제은행), 시험마다 다른 예문을 고를 수 있으면 고른다. 주 1회라 같은 문장이 다시 나와도 괜찮다.

## 6. 단어 시험 — 분리 (결정)

- **분리하는 이유:**
  - 단어 시험은 잦고 짧다: 새 낱말 20개·틀림 8개마다, 틀린 낱말 30개 넘으면 새 낱말 쉼.
  - 정기 시험은 주 1회 종합이다.
  - 합치면 단어 시험이 뜸해져 틀린 낱말이 쌓이거나, 종합 시험이 잦아진다.
- **잇는 곳:** 정기 시험 파트 1(어휘 5문제)만. 결과는 단어 시험 기록(`quizCircle.v1`)에도 남긴다.

## 7. 문제 만들기 — Quizbank가 집중할 일

- **빈 칸 채우기**(시험이 모든 소재에서 칸을 고를 수 있게):
  - **4칸:** 표현·문법 칸에도 "확실히 틀린 꼴" 데이터 — 지금 `frames/decoys/plain`은 문장구조만. 오답 표 정리와 같은 방식, 언어마다.
  - **3칸 — 중국어·일본어:**
    - 한자는 타자 대신 "어려운 고르기"(보기 다섯, 실수 꼴만), 또는 병음·히라가나 입력.
    - 중국어 3칸 0, 일본어 109/236.
  - **1칸 — 오답이 없는 소재:** 한 낱말 인사 등은 1칸 없이 2칸부터.
- **문제 품질:** 칸마다 퀴즈 전수 점검(`scripts/quiz-sweep/`) + 판정 표본을 그대로 쓴다. 시험 구성(파트·비율·칸 오르내림)도 전수 점검에 넣는다.
- **문제은행:** 시험 예문·오답을 키우는 데 계속 쓴다. 고정(`QBANK_FROZEN`) 시점은 사용자가 정한다.
- **그대로 넘어가는 것:** 오늘 만든 복합 퀴즈·대화 조각 빈칸 → 시험 파트 5.

## 9. 만드는 순서 (안)

1. **Stagebank 표현·문법 칸 설명·예문:** 문장구조 수업 틀을 넓힘, 단계 화면에서 열기. 적용은 아직.
2. **들어오는 길:** 통화 정리·대본 틀린 줄·Logbank·채팅 교정 → Stagebank 그 소재.
3. **Quizbank 문법·표현 → 시험 + 다시 보기:** 사다리 1~4칸, 첫 시험 조건, 결과 화면, Logbank 이번 주 확인 대체, 탭 셋.
4. **문제 빈 칸 채우기:** 4칸 데이터(표현·문법), 중국어·일본어 3칸.
5. **Stagebank 적용:** 판정·한도·op.

- 1·2는 화면이 늘기만 해서 먼저 낼 수 있다.
- 3은 Quizbank 탭 구성이 바뀌니 사용자 체감 점검(가상 사용자)과 퀴즈 전수 점검을 꼭 다시 돌린다.
- 매 단계 14개 언어 문구·띄어쓰기 없는 언어·아랍어 확인(RULES 1~4).

## 10. 사용자에게 물어볼 것

1. 순서 — 1·2를 한 빌드로 먼저 낼지, 3까지 묶을지.
2. 정기 시험 주기 — 주 1회 / 모인 소재 20개 / 둘 중 먼저(안).
3. Quizbank 탭 — [어휘 | 시험 | 다시 보기] 셋으로 줄이는 것(안).
4. Stagebank 적용 — 무료 하루 3번(안), "써 봄"을 다음 단계 조건에 넣을지.
5. 중국어·일본어 3칸 — 어려운 고르기 / 병음·히라가나 입력.
