## 2. 데이터 — 사건 장부 하나

지금 Logbank는 다섯 곳을 읽어 맞춘다(`dayLog.v1` · `quizDays.v1` · `callDays.v1` · `/api/notebook` logItems · 통화 기록 + `fillCheck.v1`). 새 장부 한 곳에 모두가 같이 쓴다.

```
logbank.v1.<학습 언어> = [ { k, src, r, m?, t } ... ]
 k   표제어 열쇠  w|… 단어 · e|… 표현 · g|… 문법 · l|… 글자 (지금 quiz 열쇠 그대로)
 src 출처        quiz · exam · call · people · dict · script
 r   결과        ok(맞음) · miss(틀림) · used(통화·대화에서 씀) · look(찾아봄)
 m   방식        write(빈칸 쓰기) · pick(고르기)   — 퀴즈만
 t   시각(초)
```

- **문장은 넣지 않는다**(RULES 데이터 규칙 그대로). 열쇠·결과·시각만.
- 출처별로 누가 쓰나: Quizbank·정기 시험 → ok/miss · 통화 정리(`recap.ts`)·`tutorFixes` → 고친 말의 열쇠 miss, 맞게 쓴 표현 used · 사람 대화 교정(`roomFix`) → miss · 📕 사전·표현 카드 열기 → look · 대본(남으면) → ok/miss.
- 1년 지난 줄은 하루 합계로 접는다(지금 logItems 1년과 같음).
- 처음엔 **이 폰만**(지금과 같음). 계정 저장은 5절 ⑤.

## 3. 상태 — 체크 셋 (사건에서 계산)

표제어마다 세 칸 중 하나. 11-03 규칙을 사건으로 풀면:

| 지금 칸 | 이런 사건이면 | 옮김 |
|---|---|---|
| 처음 봄 | 고르기 ok · look | 그대로(한 번 맞혀도 앎으로 안 감) |
| 처음 봄 | 쓰기 ok | 적용이 힘듦 |
| 적용이 힘듦 | 다른 날 쓰기 ok, 또는 **통화·사람 대화 used** | 앎 (1일 뒤 확인 시작) |
| 앎 | 1·3·7일 확인에서 miss, 또는 통화·사람 miss | 적용이 힘듦(처음 봄으로는 안 내림) |
| 사건 없음 | 사용자가 체크(처음 체크·샘플) | 고른 칸 |

- 지금 `KNOWN_DAYS` 1("한 번 맞히면 익힘")은 이 표가 대신한다 — 11-03에 적힌 대로 화면을 바꿀 때.
- **통화에서 씀 = 앎으로 올림**이 이 안의 새 점이다. "적용이 힘듦"의 반대가 실제로 써 보는 것이니, 통화·사람 학습이 퀴즈와 같은 무게로 셈에 들어간다. (정할 것 2)
- 퀴즈 순서(`hub/QUIZ.md`)가 이 칸을 읽는다: 처음 봄 → 적용이 힘듦 → 확인할 때가 된 앎. Logbank와 퀴즈가 같은 계산을 쓴다(11-04 "같은 눈금").

## 4. 화면 — 위에서부터 넷

### ① 오늘 카드 (B안 그대로, `no-today` 8절)

최대 셋, 근거 숫자 + 문만, 데이터가 바뀌면 ✓, 하루 고정. 재료가 2절 장부로 바뀌어 계산이 단순해진다: ① 확인할 것 = 확인일이 된 앎 수 ② 막힌 것 = 지난 7일 src call/people miss 중 퀴즈 ok 없는 열쇠 ③ 부족한 칸 = 4절 ②에서 적용이 힘듦이 가장 많은 품사·종류 ④ 써 보기 = 이번 주 앎이 됐는데 used 없는 표현·문법 → 📞 공부 통화 ⑤ 새로 배울 것.
오늘 할 것을 없애지 않는 동안(A/B 미정)은 이 칸을 숨긴다.

### ② 띠 — 육각형 안의 데이터를 그대로 띠로 (사용자 2026-11-06 "육각형 내부 데이터를 띠로")

육각형은 꼭짓점 여섯의 % 하나씩만 보이고, 그 안에 든 것(단계마다 채운 몫 `stages[]`, 어림 폭 `low~high`, 세부 칸 `cells`)은 꼭짓점을 눌러야 나온다. 띠는 **그 데이터를 바꾸지 않고 펼친 그림**이다 — `fill.ts` `computeFill`이 이미 내는 값을 그대로 쓴다.

```
낱말   알아봄  ▓▓▓▓▓|▓▓▓▓▒|▓▓▒░░|▒░░░░|░░░░░   41%
       씀      ▓▓▓▓▒|▓▓▒░░|▒░░░░|░░░░░|░░░░░   24%
문장   알아봄  ▓▓▓▓▒|▓▓▒░░|░░░░░|     |          28%
       씀      ▓▓▒░░|▒░░░░|░░░░░|     |          15%
듣기           ▓▓▓▒░|▒░░░░|      ·  ·            ─  (통화 2번 — 답 8 미만은 % 없음)
실전 대화      ▓▓▒░░|░░░░░|      ·  ·            ─
              1단계  2      3      4      5
 ▓ 채운 몫   ▒ 어림 폭(low~high)   ░ 잰 것 없음   빈칸 = 아직 안 만남
```

| 육각형 안 값 | 띠에서 |
|---|---|
| 꼭짓점 여섯(`AXES`) | 줄 여섯. 낱말·문장은 **알아봄(고르기)·씀(쓰기)** 두 줄이 한 묶음 — 11-04 "쓰기와 고르기는 한 칸에 섞지 않는다"와 같음 |
| `stages[0..4]` 단계마다 채운 몫 | 한 줄을 다섯 칸으로, 칸마다 채운 길이 = 그 몫. 알 확률 곡선(왼쪽 높고 오른쪽 낮음)이 모양으로 바로 보임 |
| `low`·`high` | 채운 끝에 옅은 꼬리(▒) — 답이 적을수록 길고, 모이면 짧아짐(`converged`면 꼬리 없음) |
| `fill` | 줄 끝 % 하나. 답 `n`이 8 미만이면 % 대신 ─ (`WEAK_MIN_N`) |
| `priorFill`(지금 단계 아래 미리 칠함) | **칠하지 않는다.** 그 사람이 한 번도 안 만난 단계 칸은 빈칸, 만났지만 답이 적은 칸은 ░. 육각형의 "처음부터 차 있음"이 띠에서는 사라짐(11-04 1절) |
| `cells`(품사·주제·문법 칸·틀린 꼴) | 줄을 누르면 그 꼭짓점의 세부 칸이 같은 모양의 작은 띠로 — 단계 → 품사 → 주제 순(11-04 2절). `weak` 칸은 띠 옆 ! 표시, 문장은 없음 |
| 육각형 한가운데 📈 실력 기록 | 띠 묶음 머리 오른쪽 아이콘 |

- **색:** 채운 몫은 Logbank 칸 색(하늘), 꼬리는 그 옅은 색, 세부 칸에서 익힘 ✓(체크 셋의 앎)만 익힘 색 — inbox 11-02 색 문제를 띠에서 정리.
- **보는 방식 고르기**(RULES 4): 띠 | 육각형. 기본 띠. 육각형은 같은 데이터의 다른 그림으로 남겨, 예전 화면이 좋은 사람이 고를 수 있게.
- **% 예외(STATE 11-02 "퍼센트는 보이되")** 그대로 — 줄마다 %, 레벨 이름 없음.

#### 띠 2단계 — 체크 셋으로 같은 띠를 다시 칠함

장부(2절)와 체크 셋(3절)이 생기면 **띠 틀은 그대로 두고** 칸 안 색만 바꾼다: 단계 칸마다 그 단계에서 만난 표제어를 `앎 ▓ | 적용이 힘듦 ▒ | 처음 봄 ░` 길이로. 1단계(어림 몫)에서 2단계(개수)로 넘어갈 때 사용자가 보는 그림은 같은 자리·같은 줄이라 화면이 흔들리지 않는다.
- 줄: 글자(0단계 선반, 글자가 다른 언어만) · 단어 · 표현 · 문법 — 알아봄/씀 두 줄은 2단계에서 "적용이 힘듦" 칸이 그 차이를 대신해 한 줄로 합칠 수 있음(정할 것 1).
- 듣기·실전 대화는 2단계에서도 통화 차례 셈(`callDays`·`turnTally`)이 그대로라 1단계 줄을 유지.

### ③ 2주 비교 (지금 것을 눈금만 바꿈)

`이번 2주: 앎 +18 · 적용이 힘듦 → 앎 9 · 다시 내려감 3`. 오른 것만 두 줄까지, 부족한 것은 적용이 힘듦이 가장 많은 칸 하나(답 8개 미만이면 안 냄 — `WEAK_MIN_N`). 권유 문장 없음. "학습방향" 머리는 ①이 있으면 없앤다(빈 머리 버그가 사라짐).

### ④ 날마다 (지금 막대·LogSheet 유지)

막대는 사건 수를 출처별로 쌓음(퀴즈·통화·사람·찾기). 그날을 누르면 지금 LogSheet 그대로 + "그날 앎이 된 것". ⏱ 학습 시간 기준 탭은 막대 아래 합계 한 줄로만.

## 7. 정할 것 (사용자)

1. **띠를 기본으로** — 1단계(육각형 데이터 그대로)를 먼저, 2단계(체크 셋 개수)는 장부가 쌓인 뒤. 권장: 예, 육각형은 보는 방식으로 남김. 함께 정할 것: 낱말·문장의 알아봄/씀 두 줄을 2단계에서 한 줄로 합칠지(권장: 합침 — "적용이 힘듦"이 그 차이).
2. **통화·사람 대화에서 "씀"을 앎으로 올리는 근거로** 셀지. 권장: 셈 — 통화가 퀴즈와 같은 무게가 돼야 "퀴즈·통화·사람이 중심"이 숫자에 보임. 대안: used는 표시만, 앎은 퀴즈 쓰기로만.
