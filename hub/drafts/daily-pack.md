# 일일 팩: 재고 → 이끌고 → 채우고 → 다시 재기 (초안, 2026-10-16)

> 사용자 결정(2026-10-16): 대본은 카테고리로 나누지 않고 **매일 한 팩**. 팩이 끝나면 **회고**, My·데이터에 **반영한 것을 알려줌**.
> 튜터 말은 **은행 문장 조합**으로(팩마다 합성하지 않음). 그리고 무엇보다
> **"학습자의 부족한 부분을 계속 측정하고, 학습 방향을 이끌어 가면서 채우는 흐름"**이어야 한다.
> 기반: My 탭 요소 망(`my-growth-network.md`), 학습자 요약(`learner/brief.ts`), 처음 체크(`learner/selfCheck.ts`), 권하기(`learner/next.ts`).
> 상태: **1차 구현됨(2026-10-16)** — 서버(바로 반영)·앱(2.67 빌드). 아래 "구현"이 실제와 다른 점.

## 한 바퀴

```
재기(턴마다 숫자) → 고르기(가장 덜 자란 요소 + 그 사람의 재료) → 팩(은행 질문 + 학습자 목표)
   ↑                                                                     ↓
다시 재기 ← 반영 고지(My에 실제로 바뀐 것만) ← 회고(잘 된 것·다시 볼 것)
```

- **재기는 팩 밖에서도 계속**: 채팅·자유 통화·지도 미션·영상 찾아보기가 모두 같은 요소 숫자를 올린다(망 초안의 카운터). 팩은 그중 가장 확실한 재료일 뿐.
- **이끌기 = 다음 팩을 무엇으로 채울지**: 하루 한 번 정하고 그날은 유지. 팩이 끝나면 숫자가 바뀌니 다음 날 방향도 바뀐다.
- **채우기 = 그 요소가 자랄 수밖에 없는 순간을 대화에 심기**. 카테고리는 학습자에게 보이지 않는다.

## 1. 재기 — 무엇을 세나

망 초안의 요소 6개를 그대로 쓴다(점수 아님, 쌓인 횟수, 줄지 않음). 팩이 더 잘 재는 것만 덧붙인다.

| 요소 | 평소에 세는 것 (망 초안) | 팩에서 더 정확해지는 것 |
|---|---|---|
| 말 이어가기 | 통화에서 한 번에, 4초 안에 시작한 말 | 짧게 바로 답하는 구간의 성공 수 |
| 정확도 | 교정 없이 통과한 줄 | 자주 틀리던 형태를 써야 하는 자리에서 맞게 쓴 수 |
| 표현 폭 | 처음 숙지된 표현 | 팩에 넣은 배운 표현을 도움 없이 쓴 수 |
| 알아듣기 | "들으면 앎"이 된 표현 | 해석을 열지 않고 답한 튜터 줄 수 |
| 자연스러움 | 고칠 게 없던 줄 | 같음 |
| 발음 | 다시 말해보기에서 모든 단어가 맞게 들림 (지금은 앱만 앎) | **따라 말하기 줄은 서버가 목표 문장을 알아서 서버만으로 셈** |

학습자 문장은 저장하지 않는다. 서버는 숫자와 표현(튜터·은행·장부에서 온 것)만.

## 2. 고르기 — 오늘 무엇으로 채우나

1. 재료가 있는 요소 중 단계가 가장 낮은 것 = **오늘의 중심** (망 초안 "다음에 키울 곳"과 같음, 하루 유지).
2. 둘째로 낮은 요소 하나를 **곁들임**으로(한 팩이 한 가지만 반복하지 않게).
3. 그 사람의 재료: 배운 것(숙지 전) 표현 2~3개, 2주 안 2번 넘게 나온 실수 종류 1개, 어제 막힌 자리, 처음 체크의 "어디서 쓸지"(상황 옷).
4. 재료가 비면(처음 사용자) 처음 체크에서 고른 부족한 부분 순서로.

## 3. 팩 — 은행 조합으로 짜기

- **5분 안팎, 학습자 차례 5~7번, 상황 하나**(예: 회사 점심).
- 튜터 줄은 **전부 은행 문장**: 장면을 여는 질문("What did you do last weekend?"), 무엇에도 붙는 되묻기("How was it there?"), 중립 맞장구("Oh, I see."). 모두에게 같은 문장이라 처음 한 번만 합성.
- 개인 맞춤은 **학습자 쪽 글자로만**: "연습 중" 띠에 써볼 표현·목표, 힌트. 소리가 없으니 합성 0.
- 중심 요소별로 심는 순간(예):
  - 말 이어가기 → 짧은 질문 3개 연달아, 무슨 답이든 다음으로
  - 정확도(과거형) → 지난 일을 묻는 질문 사슬
  - 표현 폭 → 그 표현이 자연스럽게 들어갈 질문 + 띠에 표현
  - 알아듣기 → 조금 긴 은행 질문, 해석 기본 접힘
  - 발음 → 따라 말할 은행 문장 한 줄
- 팩 짜기는 규칙으로 시작(은행 질문에 "여는 요소" 표시를 달아 고름). 순서가 어색하면 모델 1번(약 $0.002)으로 다듬기.
- 대본을 벗어난 말은 지금처럼 튜터가 받아서 대화로 이어 주고 다음 질문으로 데려온다(그 턴만 합성).

## 4. 회고 — 팩이 끝나면 한 화면

- 잘 된 것: "짧게 바로 답하기 4/5", "'end up'을 도움 없이 씀".
- 다시 볼 것: 막힌 차례 → 지금 있는 "왜 막혔는지 보기"·"다시 말해보기".
- 턴 결과로 계산(모델 호출 없음). 문장은 폰의 대화 기록에서 보여주고 서버로 보내지 않는다.

## 5. 반영 고지

- 회고 아래 "My에 반영했어요": **실제로 바뀐 것만** — "말 이어가기 +4", "표현 폭: 'end up' 숙지", "과거형 실수 이번 주 0번".
- 바뀐 게 없으면 지어내지 않는다: "오늘 연습이 쌓였어요(크기는 그대로)".
- 다음에 My를 열면 그 요소가 자라는 모습 + 새 잎에 "오늘 자람". 다음 날 "다음에 키울 곳"이 바뀌었으면 그 이유 한 줄("말 이어가기가 자라서 이번엔 알아듣기").
- 선택: 아침 "오늘의 팩이 준비됐어요" 폰 자체 알림(서버 푸시 없음).

## 단계

1. 요소 카운터(망 초안 1단계와 같이) — 재기가 먼저.
2. 은행 질문 늘리기(en·ja) + 팩 짜기 규칙 + 서버 API.
3. 앱: 서버 대본 통화, 무슨 답이든 단계, 팩 카드 → 2.67 또는 2.68.
4. 회고·반영 고지, 따라 말하기 서버 비교.
5. 다른 언어, 아침 알림.

## 사용자에게 정할 것

1. 팩 길이 5분 안팎(추천) / 10분.
2. 무료 하루 1팩·구독은 추가 팩(추천) / 구독자만.
3. "오늘 해볼 것" 카드를 팩으로 바꿈(추천) / 둘 다 둠.
4. 아침 알림: 넣음(기본 꺼짐, 켜면 시간 고르기 — 추천) / 안 넣음.
5. 망 초안의 정할 것 4개(문턱 등) — 1단계가 거기에 달려 있음.

## 구현 (2026-10-16, 설계와 다른 점)

- 길이: 사용자 결정 **약 7분 = 질문 12개**(4주제 × 3). 무료 하루 1팩, 포인트 안 씀(나머지 정할 것은 추천대로 두고 진행).
- **앱 대본 엔진을 바꾸지 않음.** 팩은 Just talk + practice 목표(`pack: 날짜`)로 돈다. 서버가 오늘의 질문 목록을 들고 있고(`pack:v1:{user}:{lang}:{day}`, 4일),
  매 턴 튜터는 교정·판단은 그대로, 말은 짧은 맞장구만 하고 다음 질문을 세 후보 중 번호로 고른다(`ask`). 말하는 것은 맞장구(표에 있으면 고정 문장) + 팩 질문(고정 문장).
  그래서 "무슨 답이든 다음으로" 단계·서버 대본 통화가 필요 없어졌고, 모든 답을 서버가 보니 재기도 서버에서 됨.
- 중심 고르기: My 망(`learner/growth.ts`, 다른 채팅이 같은 날 만듦)의 "다음에 키울 곳"과 그다음 덜 자란 요소. 망이 없으면 턴 수치·처음 체크.
- 반영 고지: 팩을 만들 때 망 요소 점수를 적어 두고, 끝날 때 늘어난 점수·단계 + 숙지된 표현. 같은 날 다른 활동 점수도 포함(기록을 보고하는 것).
- 운영 확인(테스트 사용자 claude-packcheck*-20261016): en 12/12 답·마지막에 녹음 작별, ja 진행, 반영 고지에 망 점수. 첫 실행에서 찾아 고친 것:
  튜터가 맞장구만 하고 질문을 안 고름 → 계획한 질문을 붙임, 맞장구가 긴 새 문장(매번 합성) → 2~5단어, 마지막에 새 질문 → 작별 문장,
  이전 문장 교정이 다음 줄에 붙음 → 겹치는 글자 30% 미만이면 버림(모든 통화).
- 아직: 따라 말하기(발음), 아침 알림, 구독 추가 팩, "오늘 해볼 것" 카드와 합칠지(지금은 둘 다 보임), es 등 다른 언어 질문.
