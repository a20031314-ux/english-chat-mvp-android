# AI 통화 기능 정리 (2026-10-30, main 2ae83c1 기준)

> 사용자 "통화탭 기능 정리해줘". 코드에서 지금 실제로 도는 것만. 통화는 **탭이 아니라** 어디서나 떠 있는 층(`CallHost`, 2026-10-23).
> 안에서 쓰는 이름 `roleplay`. 근거 파일은 괄호.

## 1. 어디서 열리나
- 대화 탭 AI 튜터 줄 📞(`AiTutorRow`) · AI 대화 머리 📞 · ⋮ "통화 기록"·"내 문장 말해보기"(`AppHome`)
- 사람 탭 AI 튜터 프로필 📞 통화·통화 기록(`AiTutorProfile`)
- 통화 기록 목록 📞(새 통화)·"이어서 하기"(`CallList`)
- 빈 AI 대화 "오늘 해볼 것" → 연습 목표 단 통화(`practice` 신호, `NextStepCard`)
- iOS 1차(사람 기능 꺼짐)만 하단 탭에 통화
- 켜지는 조건: `voiceCallAvailable()` + 그 언어에 통화 있음 + 쓸 기능 고르기에서 안 숨김. iOS는 진단 빌드 아니면 꺼짐(`platform.ts`). `?screen=roleplay`는 통화 대신 AI 대화.

## 2. 통화 중
- 머리: 제목 + 남은 시간("오늘 무료 통화 n분 남음 · 하루 d분" / "남은 통화 시간 약 n분") + [내 말](고칠 곳 있는 내 줄만 ↔ 전부) · [번역](튜터 줄 번역 펼침) · [중단]
- 말하기: 녹음 버튼 없음 — 튜터 줄이 끝나면 마이크 자동. 첫마디 12초, 한 턴 최대 20초, 0.9초 조용하면 차례 끝(`listen.ts`)
- 이어 말하기 기다림: 문장이 끊긴 듯하면 3.5초씩 최대 두 번 더, 점선 말풍선
- 표시: 내가 말하는 중 "•••", 튜터 생각 중 "…", 받아쓰기 확신 낮으면 "?"(누르면 설명)
- 고쳐 주기: 내 줄 아래 접힌 "고칠 곳이 있어요" → 이렇게 말할 수 있어요(better)·이렇게 말하려던 거죠?(meant, 🔊)·한마디
- 막힘: 그 줄에 "왜 막혔는지 보기" → 마이크 닫고 패널(이유·이렇게 말해 보기·따라 말해보기 낱말 대조), 닫으면 같은 턴으로(읽은 시간은 망설임에 안 침)
- 튜터 줄 아래 노란 도움말(tip), 줄 누르면 할 일 한 줄(통화 중엔 번역만)
- 연습 목표 통화: 위에 연습 띠, 쓴 표현 ✓
- 카메라 없음(영상은 사람 1:1·Room 쪽)

## 3. 끝난 뒤
- 저장: 줄마다 바로, **이 폰 localStorage에만 최근 20개**(`callStore`·`saved.ts`). 서버엔 통화 기록 없음
- 끝 화면: 닫기, 시간·포인트 떨어져 끝났으면 안내, 끝까지 한 통화만 전면 광고 후보(`callEnd`)
- 끝난 통화 안: 내 줄 전부·문장분석·듣기·다시 말해보기
- 통화 기록(`CallList`): 학습 언어별, 행마다 제목·시각 / 이어서 하기(안 끝난 것) / 돌아보기 / ×
- 돌아보기(`RoleplayPast`): 읽기 전용(고친 줄·번역·분석·다시 말해보기, "왜 막혔는지"는 없음)
- 이어서 하기: 저장된 줄에서 다시, 요금은 새 통화로 계산
- 서버로 가는 기록: 고친 줄 → 복습 카드(`fileFix`), 장부·약점·성장·지표

## 4. 모드
- **제공 중: Just talk(자유 대화) 하나, 14개 언어.** 첫인사·작별만 녹음, 나머지 합성. 작별 말이 들리면 끝
- 꺼짐: 대본형 상황극 영어 7개(`SCRIPTED_SCENES_OFFERED=false`, 카페·식당·길 찾기·옷 사이즈·호텔·택시·자기소개), 자유 대화 반응 줄 은행 en·ja(`BANK_OFFERED_IN_OPEN_TALK=false`)

## 5. 요금·시간 (`plans.ts`, `entitlementStore.ts`)
| 플랜 | 통화 | 채팅 |
|---|---|---|
| 무료(2.76+ 앱) | **없음**(0포인트) | 없음 |
| 무료(2.75 이하 앱) | 평생 체험 10P(약 50분) | 하루 7 |
| 대본 2,900원 | 사흘마다 5분 | 20 |
| 라이트 3,900원 | 하루 7분 | 30 |
| 플러스 5,500원 | 하루 10분 | 50 |
| 프리미엄 8,900원 | 하루 15분 | 100 |
- 감독 턴마다 흐른 시간만큼(턴 간격 최대 1분, 첫 턴 15초) — 하루 분 먼저, 모자라면 구매 포인트 소수(1P = 5분). 이월 없음, 사용자 시간대 자정에 다시
- 막히면 서버 402 `NO_POINTS` → 문구 띄우고 통화 끝
- 연습·다시 말해보기는 통화 시간 안 씀(대본 줄은 하루 대본 줄 한도)

## 6. 서버·모델 (실시간 세션 아님 — 턴마다 받아쓰기 → 글 모델 → 목소리)
| API | 하는 일 | 모델 |
|---|---|---|
| `roleplay/listen` | 받아쓰기·확신도 | Scribe v2, 실패 시 gpt-transcribe |
| `roleplay/turn` | 튜터 다음 줄·고친 줄·막힘 판단(스트리밍) | **OpenAI gpt-6-luna**(스트리밍이 OpenAI 길뿐) |
| `roleplay/context` | 오래된 줄 메모로 접기 | Haiku 5.5 |
| `roleplay/review` | 왜 막혔는지 | Sonnet 5.5 |
| `roleplay/practice` | 따라 말하기 대조 | Haiku(대본 줄 뜻 판단은 틀림일 때 Sonnet) |
| `tts` | 튜터 목소리 | gpt-realtime-2.1-mini, 실패 시 gpt-4o-mini-tts |

## 7. 남아 있지만 안 쓰는 것
- 오늘의 팩: `PackCard` 그리는 곳 없음(2.76에서 뺌). 통화 안 팩 분기·`/api/pack/*`·팩 턴 무료는 옛 앱(2.67~2.75)용으로 남음
- 대본형 상황극 7개·반응 줄 은행(위 4)
- 옛 빌드 호환: 5분 블록 정산·이월 시간 `callCarrySeconds`·헤더 분기
- `callStore.ts` 머리 주석이 옛 구조(🗒 카드·채팅 서랍)를 설명함 — 지금은 CallList만
- 비용 표 `roleplayCorrect` op — 부르는 곳 못 찾음(흔적으로 보임, 확인 전)

## 눈에 띈 점 (사용자에게)
1. **새 앱 무료 사용자에게 📞가 그대로 보이는데 서버가 402로 막는다** — 누르면 통화가 열렸다가 바로 "다 썼어요"로 끝날 가능성(클라이언트에서 숨기는 곳 못 찾음, 기기 확인 필요). 무료면 📞 대신 요금 안내로 보낼지.
2. 통화 기록이 **폰에만 20개** — 기기 바꾸면 사라짐.
3. 통화 튜터는 아직 OpenAI(gpt-6-luna) 스트리밍 — 0.6~0.9초 느려짐 남은 결정(dev.md), Claude 스트리밍 길은 미정.
4. 사용법(?) AI 통화 장 글·그림이 예전 통화 첫 화면 기준일 수 있음(dev.md "버전 자를 때 14개 언어 새로").
