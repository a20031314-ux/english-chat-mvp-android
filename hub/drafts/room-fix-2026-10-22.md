# 말하는 방 내 줄 교정 (2026-10-22)

- 사용자 요청: "일치한 문장, 혹은 일부 단어만 일치하지 않고 구조는 잘 받아적은 문장에 한정해서 틀린 건 짚어주되 확인은 선택적으로, 채팅 교정 로직 참고".
- 사용자 결정: 일치 판정은 **(나)** — 확신도 높은 줄은 한 모델로 통과, 어중간한 줄만 두 번째 받아쓰기로 견줌. 교정은 **말한 본인만**(공개 옵션은 이번에 안 넣음).
  방 자막 하루 한도는 **넘어도 자막 계속**(3번) — 한도는 교정 같은 덧붙임에만.

## 흐름

1. 받아쓰기(`/api/roleplay/listen`, 새 앱이 `fix:true`): 조각마다 확신도로 `high`(≥ `SURE_RULES` 0.97) / `check`(그 아래, "?" 위) / 표 없음("?" 줄·다시 받아쓴 줄·한도 넘음).
   표 = KV `usage:aihelp:fix:<사람>:<말>:<조각>`에 글 지문·믿음 정도만(글 아님), 10분.
2. 말이 끝나면 앱(`RoomView` `requestFix`): 모든 조각이 표가 있고, 배우는 언어로 한 말이고(`writtenInLearningLanguage`), 편한 말에 기대지 않았으면(`leansOnOwnLanguage` — 💡 힌트 몫) `/api/rooms/fix`에 조각 글(+ `check` 조각은 소리).
3. 서버(`/api/rooms/fix`): 표가 있고 지문이 같은 글만. `check` 조각은 두 번째 모델(`secondListen.ts` — Scribe v2, 키 없으면 다른 OpenAI 모델)로 받아써 `rooms/agreement.ts`:
   - match(낱말 모두 같음) → 교정 / structure(다른 낱말 20% 이하, 낱말 넷 이상) → 다르게 들은 낱말은 고치지 않고 교정 / differ → 교정 안 함.
4. 교정(`server/roomFix.ts`, llm `roomFix` → Haiku 5.5): 채팅 교정 기준 + 받아쓴 말 규칙(문장부호·대소문자는 받아쓰기 몫, 머뭇거림·말 고쳐 하기는 실수 아님, `unsure` 낱말 유지).
   후처리는 채팅과 같음(한국어 불규칙 활용·`shouldKeepLearnerLine`), 다르게 들은 낱말을 건드리면 버림(`touchesDisputed`).
5. 화면: 내 줄 아래 "✎ 고칠 곳이 있어요" 칩 → 누르면 고친 문장·설명. 채팅의 "눌러서 보기/바로 보기"(`chatCorrectionViewMode`) 그대로. 위험한 줄(`correctionRisk`)은 열 때 `/api/chat/verify`(`spoken:true`, `unsure`)가 한 번 더.

비용(어림): 내 말 한 마디에 교정 1번(약 0.15원, Haiku — 비용 표는 아직 mini 단가) + 어중간한 조각만 두 번째 받아쓰기(약 0.4~0.5원). `economics.json` room에 분당 교정 1.2번·두 번째 받아쓰기 0.6번.
스위치: Vercel `ROOM_FIX_SECOND=always`면 모든 조각을 두 번째 받아쓰기로((가)안). 점검 사용자는 `x-room-fix-second: always|borderline`.

## 기준 맞추기 (speechocean762 — 중국어권 성인 학습자 영어 읽기 200문장, 발음 낮음 70·중간 70·좋음 60, `scripts/room-fix-trial.mjs`)

읽은 글(원문)과 받아쓰기가 다른 줄의 비율. 원문 자체에 학습자 낭독 실수가 섞여 있어(읽은 글 ≠ 실제로 한 말) 실제 "잘못 들음"보다 높게 나온다.

| 고르는 법 | 통과 줄 | 원문과 다른 줄 |
|---|---|---|
| mini 확신도 ≥ 0.95 | 105 (53%) | 36% |
| mini 확신도 ≥ **0.97** | 76 (38%) | **28%** |
| mini 확신도 ≥ 0.99 | 49 (25%) | 27% |
| 두 모델(mini·Scribe v2) match | 90 (45%) | 28% |
| 두 모델 structure | 39 (20%) | 77% — 틀린 낱말이 모두 disputed로 잡힌 줄 17/30 |
| 두 모델 differ | 71 (36%) | 96% |

- 확신도만으로는 잘 안 갈린다(0.99에서도 27%). 그래도 0.97 위는 두 모델 match와 같은 수준이라 (나)의 바로 통과 기준을 0.97로.
- 두 모델이 똑같이 잘못 듣는 줄도 있다("let go" → "let wind", "kingdoms" → "condoms"). 이런 줄은 어느 방식으로도 못 거른다 — 교정이 엉뚱하게 나올 수 있어 열 때 확인 모델과 "고칠 것 없음" 거두기가 마지막 그물.
- 다른 줄 중 상당수는 학습자가 실제로 -ed를 빼고 말한 것("walked" → "walk")으로 보인다 — 이건 교정이 맞는 경우.
