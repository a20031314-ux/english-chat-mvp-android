# 통화 모드 나누기 — 글자·수업·자유대화, 숙제 한 바퀴, 자유대화의 채우기 (설계안, 2026-11-06)

> 사용자 2026-11-06: "통화기능을 구체화하고싶어. 영어가 어느정도 가능해서 자유대화>틀린것만 짚어주기 흐름이 좋지만 아예 모르는 언어들은 할게 모호해. 알파벳부터 가르쳐주는 튜터, 커리큘럼이 짜여있지만 겉으로는 자유대화같은(만들어진 책을 가지고 수업하는 강사처럼) 모드."
> 이어서: "초보자에게는 사용자의 언어로 대화하는걸로 시작할지도 정해야" → "앱내 기능을 소재로 숙제(퀴즈·복습·예습)" → "숙제를 카드로 내지말고 튜터가 퀴즈를 고르는 형태, 숙제푼걸 바탕으로 리뷰하는식으로 다음대화를 이어간후 이후 커리큘럼을 진행" → "자유대화는 숙제를 내지말되, 튜터가 학습자의 상황을 계속 파악하면서 부족한부분부터 채우는 흐름".
> 상태: **설계만.** 지금 통화(자유대화 / 공부, `director.ts`)는 그대로. 정할 것은 끝 절.
> 이어지는 설계: `languagebank-2026-11-03.md`(체크 셋), `letters-languagebank-2026-11-05.md`(글자 표제어), `no-today-2026-11-05.md`(오늘 할 것 없앰·B안), `logbank-2026-11-06.md`(사건 장부), `call-scripts-design-2026-11-01.md`(상황극 대본).

## 1. 한 줄로

통화를 **글자·소리 / 수업 / 자유대화** 셋으로 나누고, 기록을 보고 하나를 권한다. 수업은 겉은 수다, 안은 한 통화의 수업 계획이며 **튜터가 고른 퀴즈 한 판이 숙제 → 다음 통화는 숙제 리뷰로 시작 → 결과로 진도**. 자유대화는 숙제 없이, 통화 전 그림과 차례마다 재는 값으로 **부족한 것이 필요해지는 화제로 대화를 몰아** 채운다.

## 3. 모드 셋과 권하기

| 모드 | 누구에게 | 튜터가 하는 일 | 숙제 |
|---|---|---|---|
| 글자·소리 | 그 글자를 못 읽음(글자 표제어 대부분 처음 봄) | 글자 보여 주고 소리 → 따라 말하기(판정 안 함) → 듣고 누르기 → 그 글자 든 낱말 둘 | 오늘 글자 듣고 고르기 한 판 |
| 수업 | 1~2단계, 말이 거의 안 나옴 | 4절 | 튜터가 고른 퀴즈 한 판(5절) |
| 자유대화 | 말이 됨 | 지금 그대로 + 채우기(6절), 🎓 켬/끔 | 없음 |

- 통화를 열면 지금 자유대화 / 공부 고르기 자리에 셋. 기록으로 하나를 앞에(글자 처음 봄 많음 → 글자, 1~2단계 → 수업, 그 위 → 자유대화), 지난 선택 표시는 지금처럼. 설명 글 없이 이름과 튜터 그림만(RULES 화면 규칙).
- 지금 "공부"는 수업 모드로 흡수. 상황극(11-01 설계)은 넷째 후보(정할 것 1).

### 초보자 첫 언어 (권함 A)

- 글자·수업 모드는 **앱 언어로 시작**, 학습 언어는 배울 문장·글자·짧은 튜터 줄만. 넘기는 규칙은 기록으로: 그 틀을 두 번 맞히면 그 장면 튜터 줄을 학습 언어로, 막히면(🙉·침묵·틀림 둘) 한 칸 내려와 앱 언어 설명. 다음 통화는 지난번 끝난 칸부터.
- 자유대화는 학습 언어만(지금 그대로). PRODUCT 핵심 가치 3 "튜터는 학습 언어만"의 예외를 **글자·수업 모드에만** 둔다(정할 것 5).
- 확인할 기술: 섞어 말할 때 받아쓰기 언어 감지, Voxtral 학습 언어 목소리로 앱 언어 설명을 시킬 때 알아듣기(안 되면 설명 줄만 앱 언어 목소리).
- 화면: 아주 처음인 사람을 위해 위 칸 튜터 얼굴 자리에 글자·틀 카드가 잠깐 뜨는 칠판.

## 4. 수업 모드 — 통화 한 번

수업 계획(통화 시작 때 규칙으로 만듦, 모델 없음): 오늘의 문장구조 하나 + 그 틀에 넣을 낱말 셋. 고르는 순서는 체크 셋 — 처음 봄 → 보여 주기부터, 적용이 힘듦 → 끌어내기부터, 앎 → 건너뜀.

1. **숙제 리뷰(2~3분, 5절)** — 첫 통화면 안부.
2. **보여 주기** — 상황을 깔고 튜터가 그 틀로 직접 말함, 칠판에 틀 카드.
3. **끌어내기** — 그 틀이어야 답할 수 있는 질문.
4. **고치기** — 🎓 방식 그대로(짚기·고친 문장·다시 말하기 두 번).
5. **옮겨 쓰기** — 같은 틀, 다른 장면·낱말.
6. **숙제 고르기** — "오늘 「틀」 익혔어요. 숙제 골라 뒀어요."

감독 지시에 수업 계획과 지금 단계를 싣고, 감독이 `next`처럼 단계를 넘김. 모델 호출 수는 지금 공부 모드와 같음.

## 5. 숙제 한 바퀴 (수업·글자 모드만)

```
통화 끝 ── 튜터가 문제 10개 고름 ──▶ Quizbank 다음 한 판 = 숙제
   ▲                                       │ 결과(장부 사건: 맞음·틀림·안 함)
   │                                       ▼
진도: 다 맞힘 → 다음 수업 / 남음 → 그 틀 섞고 반만 ◀── 다음 통화 ① 숙제 리뷰
```

- **카드 없음.** 숙제는 따로 화면이 아니라 Quizbank가 다음에 낼 한 판. 통화 요약 줄에 [숙제 풀기 ›] 하나.
- **고르기(규칙, 모델 없음):** 약 4 = 이번 통화 고친 말·배운 틀, 약 3 = 다음 수업 틀·낱말(예습 — 처음 보는 것은 퀴즈 안에서 한 장 먼저), 약 3 = 1·3·7일 된 것. 같은 기록이면 같은 숙제. 튜터 모델은 알리는 말만.
- **저장:** 숙제 열쇠 목록 `callHomework.v1.<언어>`(이 폰, 낸 시각·통화 id). 결과는 장부에서 낸 시각 뒤 그 열쇠 사건. 학습자가 쓴 틀린 답은 이 폰에만, 다음 통화 요청 때만 보냄(`tutorFixes.v1`과 같은 방식, 서버 저장 안 함).
- **리뷰:** 틀린 문제 = 튜터가 그 문장을 말로 다시 시킴, 맞힌 문제 = 같은 틀 응용 질문 하나, 안 풂 = 통화 안에서 말로 같이.
- 새 숙제가 지난 숙제를 덮어씀(쌓이지 않음), 안 해도 잠금·벌 없음.
- B안(Logbank 오늘 카드)과 따로 간다 — 숙제 카드 자리 필요 없음.

## 6. 자유대화 — 숙제 없이, 부족한 것부터 채우기

겉은 지금 자유대화 그대로. 안에서는 **진단 → 겨냥 → 유도 → 확인**이 통화 전·중·후로 돈다. 가르치지 않고, 부족한 것이 **필요해지는 화제**로 대화를 몬다.

### 6-1. 통화 전 — 겨냥 목록 (규칙, 모델 없음)

새 순수 모듈 `roleplay/talkAims.ts`가 이 폰의 기록에서 최대 셋을 고른다:

| 순서 | 재료 | 예 |
|---|---|---|
| ① 지난 고침 중 아직 다시 못 맞힌 것 | `tutorFixes.v1` | 과거형 -ed 빠짐 |
| ② 장부 "적용이 힘듦" 표제어(알지만 말로 안 나옴) | `logbank.v1` | 「〜たことがある」 |
| ③ 말하기 꼭짓점 부족 칸 | `pickStudyCell` | 실전 대화 · 내가 이끌기 |
| ④ 지난 통화들에서 거의 안 나온 fn 갈래 | `callDays` fn 셈 | time(과거·계획)·reason |

같은 갈래는 하나만(셋이 다 시제가 되지 않게). 화제 운반체는 들은 삶(`tutorLife.v1`) — 시제 약점 + "다음 주 출장" → 출장 계획을 묻는다.

### 6-2. 통화 중 — 차례마다 지금 그림 갱신, 다음 차례 겨냥 하나

`talkAims.ts`의 `nextAim(state, mark)`가 학습자 줄의 TurnMark·better로 상태를 고치고 다음 튜터 차례에 줄 겨냥을 **하나 또는 없음**으로 고른다. 감독 요청에 `aim`(한 줄, 영어 — 모델용)으로 실림.

| 이 통화에서 보이는 것 | 튜터의 다음 수 (유도) |
|---|---|
| 겨냥한 fn이 아직 안 나옴 | 그것이 필요한 질문(time → "그때 뭐 했어요?", reason → "왜요?") |
| 같은 실수 꼴이 또 나옴 | 교정 대신 바른 꼴을 자기 말에 넣어 되받고(recast), 몇 차례 뒤 같은 꼴이 필요한 질문으로 한 번 더 기회 |
| lead "min" 연속 둘 | 고르기 질문("A요, B요?") → 다음엔 열린 질문, 튜터는 말 줄임 |
| lead "follow"만 계속(이끌기 부족 칸) | 튜터가 자기 이야기를 짧게 하고 질문 없이 멈춤(지금 1/3 규칙을 이 사람에겐 더 자주) |
| native true | 그 말의 학습 언어 표현을 튜터 말 속에 섞어 되받음 |
| heard off·🙉 | 겨냥 쉼, `difficulty.ts`가 말 단계 낮춤(지금 그대로) |
| 겨냥이 맞게 쓰임 | 그 겨냥 끝, 다음 겨냥으로(같은 통화 두 번 쓰면 "씀") |

지켜야 할 것:
- 학습자가 이끄는 차례(lead "lead")에는 겨냥을 싣지 않는다 — 그 화제를 따라간다.
- 같은 겨냥은 연달아 두 차례 싣지 않고(지금 REPERTOIRE_COOLDOWN과 같은 생각), 자연스럽게 안 들어가면 건너뜀.
- 튜터는 겨냥을 말하지 않는다("과거형 연습해 볼까요" 없음). 짚는 교정은 🎓를 켰을 때만(지금 그대로).
- 감독 측정에 칸 하나 더: `aim`: "used" | "wrong" | ""(그 차례 겨냥이 쓰였나). 원가는 지시 약 100토큰 더.

### 6-3. 통화 후 — 결과가 다음 통화로

- 겨냥마다 결과를 장부 사건으로: used → 씀, wrong → 틀림, 기회 줬는데 안 나옴 → 기록 없음. 다음 통화 겨냥 목록이 이걸로 바뀜(맞게 쓴 고침은 `tutorFixes`에서 빠짐 — 지금 규칙).
- 같은 겨냥을 세 통화 연속 못 채우면 통화 끝 튜터 한 마디로 수업 모드 한 번을 권함(버튼은 통화 요약 줄 [수업으로 ›] 하나, 안내 글 없음).
- 통화 정리(`CallRecap`)는 지금 그대로. 숙제·카드는 없음.
- 저장: 모두 이 폰(`talkAims` 상태는 통화 기록 안). 학습자 문장은 서버에 남기지 않는다.

## 7. 만드는 순서 (권함)

1. 자유대화 채우기 6절 — 화면 변화 없음, 감독 지시·측정 칸·`talkAims.ts`(순수, 테스트), 서버 바로 + 앱 빌드(앱이 aim을 보냄). 가상 사용자 통화로 겨냥이 쓰인 비율·튜터 말이 수업처럼 들리지 않는지 확인.
2. 수업 모드 4절 + 숙제 5절 — 통화 고르기 화면·칠판·Quizbank 숙제 판.
3. 글자 모드 — 모델 없이 순서·소리만이라 원가 0(무료 개방 후보).
장부(`logbank.v1`)가 2.80 브랜치에 있으므로 1부터 2.80 이후.

## 8. 정할 것

1. 모드 셋으로 할지, 상황극(11-01)을 넷째로 넣을지.
2. 수업 한 통화 분량: 문장구조 하나(권함) / 표제어 3~5 섞기.
3. 글자 모드를 무료로 열지.
4. 먼저 만들 것: 7절 순서(권함) / 수업 모드 먼저.
5. 초보자 첫 언어 A(앱 언어로 시작, 권함)·B(학습 언어, 막힐 때만)·C(사용자가 고름), A라면 "학습 언어만" 예외를 글자·수업 모드에만.
6. 숙제 판 맨 위에 튜터 얼굴 하나만 둘지 / 표시 없이.
7. 자유대화 채우기에서 recast(바른 꼴을 튜터 말에 섞기)를 🎓 끔일 때도 할지(권함: 함 — 짚지는 않으니 자유대화 느낌은 유지).
