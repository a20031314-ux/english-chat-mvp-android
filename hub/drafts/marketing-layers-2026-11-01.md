## 핵심 메시지 (사용자 2026-11-01 정함)

> "전체적인 큰 흐름은 **틀 > 양 > 적용**, 이게 **다 연결**되어 있다는 것, 그리고 **사용자의 약점을 계속 파악해서 효율적인 학습**을 만들어 준다는 것을 강조."

모든 스크린샷·영상은 이 셋 중 하나를 보여 준다. 셋 중 어디에도 안 걸리는 장면은 쓰지 않는다.

| 메시지 | 뜻 | 앱에서 실제로 일어나는 일(근거) |
|---|---|---|
| **① 틀 > 양 > 적용** | 문장 틀을 배우고 → 많이 풀어 채우고 → 대화에서 쓴다 | 틀 = Stagebank 문장구조 수업·꺼내 쓰기 / 양 = Quizbank(어휘·문법·표현, 처음 보는 낱말 계속) / 적용 = AI 대화·통화 |
| **② 다 연결** | 한 칸에서 한 것이 다음 칸으로 넘어간다 — 따로 노는 기능 모음이 아님 | 틀 → 양: 익힌 문장구조가 Quizbank 문법 문제로 / 양 → 적용: 튜터가 배운 표현을 대화에서 다시 쓰게(`reuse.ts`) / 적용 → 틀·양: 대화·통화에서 고친 줄이 Quizbank 문제로(`fileFix`), 통화 정리의 막힌 말 → 그 문장구조 수업(`CallRecap`) / 단계: 틀 익힘 + 꺼내 쓴 비율로 다음 단계 |
| **③ 약점을 계속 파악 → 효율** | 앱이 내가 틀린 곳을 계속 모아, 아는 건 빼고 모르는 것만 시킨다 | 한 번 맞히면 익힘 → 빠짐, 잊을 때쯤(1·3·7일)만 다시 / "지난번에 틀린 것" 탭 / 대화에서 틀린 줄이 문제로 / 오늘 할 것 "내 기록에 맞춰" / 단어 시험은 틀린 낱말 중심 |

**약속 한 줄(안):** "틀을 배우고, 양으로 채우고, 대화에서 써요. 셋이 이어져 있어서, 앱이 내 약점만 골라 다시 시켜요."
짧게(제목용): "틀 → 양 → 적용, 내 약점만 골라서."

## 0. 핵심 기능 / 세부 기능 구분 (사용자 2026-11-01 "핵심기능, 세부기능을 먼저 구분부터")

**기준:** 핵심 = 틀·양·적용의 한 칸이거나 칸과 칸을 잇는 것, 또는 약점을 찾아 되돌리는 것.
세부 = 핵심 기능 **안에서** 하는 방법·편의·기록, 또는 루프 밖의 따로 쓰는 기능. 세부는 마케팅에서 제목이 되지 않는다.

### 핵심

| 메시지 | 핵심 기능 | 사용자가 하는 일 | 앱 위치 |
|---|---|---|---|
| 틀 | **문장구조 수업** | 틀 하나를 설명 → 퀴즈 → 그 틀로 대답 | Stagebank 🧩 |
| 틀 | **꺼내 쓰기** | 뜻만 보고 배운 틀로 말함 → 바로 짚음 | Stagebank 🎯 |
| 양 | **Quizbank** | 어휘·문법·표현을 계속 풀어 채움 | Quizbank |
| 적용 | **AI 대화 — 내 줄 바로 아래 교정** | 대화하다 틀리면 그 줄 밑에 고친 문장 | 대화 → AI 튜터 |
| 적용 | **AI 통화** | 소리 내어 대화, 막혀도 기다려 줌 | AI 대화 📞 |
| 연결 | **고친 줄 → 문제로**, **통화 막힌 말 → 그 틀 수업** | 적용에서 틀린 것이 틀·양으로 돌아옴 | (자동) |
| 연결 | **단계** | 틀 익힘 + 꺼내 쓴 비율로 다음 단계 | Stagebank n단계 |
| 약점 | **틀린 것만 다시**(맞히면 빠짐·잊을 때 다시) | 아는 건 안 나오고 모르는 것만 | Quizbank·오늘 할 것 |
| 약점 | **오늘 할 것** | 오늘 분량을 내 기록에 맞춰 정해 줌 | Stagebank 맨 위 |

### 세부 (핵심 안에 들어감)

| 속한 핵심 | 세부 기능 |
|---|---|
| 오늘 할 것 | ⚙ 분량·n일 완성·순서·조합, 🔔 아침 알림, 대본 은행 장면, 오늘 배운 것 |
| 문장구조·꺼내 쓰기 | 상황·표현 대본, 연습 방식(따라 말하기·첫 글자·가리기·내 말로·고르기·맞추기), 0단계 글자·읽는 법 |
| 단계 | 📖 배울 수 있는 것, 내 진척 시트, 단계 시험, 실력 확인, 사다리(단계 바꾸기), 대화 예시 |
| Quizbank | 어휘·문법·표현 탭, 빈칸 쓰기·틀린 곳 고치기·복합 퀴즈, 📝 단어 시험, 📖 단어장·낱말 찾기, 이번 주 확인, 자라는 문제은행 |
| AI 대화 | 편한 말로 → 표현 보기 카드, 문장분석·빠른 질문·🔎 My에서 찾기, 듣기·번역, 내 말도 하는 튜터 옵션 |
| AI 통화 | 💡 힌트·"이렇게 말하려던 거죠?", 통화 기록·돌아보기 |
| 기록 | Logbank(날마다·주마다), 📈 실력 기록, 노트 |

### 루프 밖 (따로 쓰는 기능 — 정할 것 3)

영상 학습 · 사람(프로필·게시판·아이콘) · 1:1·단체방 · Room(게임 포함) · 친구 초대 · 의견 보내기 · 창구(Moyeo·Pingo·Spin)

### 그림은 앱 전체 화면이 아니어도 된다 (사용자 2026-11-01)

- 스크린샷·영상에 폰 화면 전체를 넣지 않는다. **그 기능을 보여 주는 부분만 잘라 크게**(교정 줄 하나, 퀴즈 한 문제, 점 줄) — 상단바·하단 탭·다른 칸은 빼서 세부 기능이 같이 비치지 않게.
- 한 장에 조각 여럿을 이어 붙이고(교정 줄 → 다음 날 그 문장이 퀴즈로), 화면에 없는 그림(틀·양·적용 고리, 화살표)을 더한다. **연결·약점은 조각 사이 화살표로 보여 주는 메시지**라 이 방식이 맞다. 조각 내용은 실제 앱에서 찍은 것만(지어낸 화면 금지, 핵심 가치 8).
- 지금 도구: `store-shots/flow/compose.mjs`가 crop 값으로 위쪽을 자름 → 조각 단위(요소 선택자로 잘라 확대)로 바꾸는 것이 다음 제작 때 할 일.

## 1. 지금 무엇이 문제인가

- 스토어 8장(10-30 학습 흐름 세트, `store-shots/flow/strings.mjs`): 1~5장은 흐름이지만 6~8장이 **장마다 화면 둘 = 세부 기능 6개**
  (하고 싶던 말 보기·묻기·AI 통화·영상 학습·Room·단체방)를 흐름 단계와 같은 크기로 보여 준다. 흐름은 4단계(정해 줌·말하기·퀴즈·대화)로, 연결·약점은 어느 장에도 없다.
- 홍보 쇼츠(`marketing-videos.md`): 편 = 기능 하나(오류교정·분석·채팅·통화·단체방). 편마다 따로 보면 "기능 많은 앱"으로 보이고,
  그 기능이 흐름 어디에 있는지, 다음 칸으로 어떻게 이어지는지는 어느 편에도 없다.

## 2. 층 (위가 크게, 아래로 갈수록 작게)

| 층 | 내용 | 어디에 |
|---|---|---|
| **L0 약속** | 약속 한 줄(위) | 스토어 1장 제목·짧은 설명·모든 영상 끝 화면 |
| **L1 흐름** | 틀 → 양 → 적용 고리(적용에서 틀·양으로 돌아오는 화살표까지) | 스토어 1장 그림, 대표 영상 |
| **L2 칸마다 대표 장면** | 틀 = 틀 하나를 배우고 그 틀로 말함 / 양 = 그 틀·낱말을 계속 풀어 채움 / 적용 = 대화 중 내 줄 바로 아래 고침 | 스토어 2~4장, 칸 영상 |
| **L3 연결·약점** | 대화에서 틀린 줄 → 다음 날 문제로 / 통화에서 막힌 말 → 그 틀 수업 / 맞힌 건 빠지고 틀린 것만 | 스토어 5~7장, 연결 영상 |
| **L4 세부·루프 밖** | 세부 기능 표 전부, 영상 학습·사람·Room… | 스토어 8장 한 장 또는 안 넣음(정할 것 1). 사용법(?)·새로워진 점·기능 쇼츠 소재 |

규칙: **한 장(한 편)에 한 층.** 아래 층 기능은 위 층 장면 안에 작게 비칠 수는 있어도 제목이 되지 않는다.
세부 기능이 늘어도 L0~L3는 바뀌지 않는다 — 새 기능은 L4에 들어가고, L4는 스크린샷 칸을 늘리지 않는다.
