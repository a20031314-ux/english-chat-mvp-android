## 0. 먼저: 핵심 기능 / 세부 기능 구분 (사용자 2026-11-01 "핵심기능, 세부기능을 먼저 구분부터")

**기준:** 핵심 = 학습 루프(배우기 → 채우기 → 써 보기)의 한 칸이거나 칸과 칸을 잇는 것 — 빼면 "매일 말하고, 틀린 것만 다시, 대화에서 꺼내 씀"이 성립하지 않는다.
세부 = 핵심 기능 **안에서** 하는 방법·편의·기록, 또는 루프 밖의 따로 쓰는 기능. 세부는 마케팅에서 제목이 되지 않는다.

|---|---|---|---|

| 배우기 | **문장구조 수업** | 틀 하나를 설명 → 퀴즈 → 그 틀로 대답 | Stagebank 🧩 |

### 루프 밖 (따로 쓰는 기능 — 정할 것 5)

영상 학습 · 사람(프로필·게시판·아이콘) · 1:1·단체방 · Room(게임 포함) · 친구 초대 · 의견 보내기 · 창구(Moyeo·Pingo·Spin)

### 그림은 앱 전체 화면이 아니어도 된다 (사용자 2026-11-01)

- 스크린샷·영상에 폰 화면 전체를 넣지 않는다. **그 기능을 보여 주는 부분만 잘라 크게**(교정 줄 하나, 퀴즈 한 문제, 점 줄) — 상단바·하단 탭·다른 칸은 빼서 세부 기능이 같이 비치지 않게.
- 한 장에 조각 여럿을 이어 붙이거나(교정 줄 → 다음 날 그 문장이 퀴즈로), 화면에 없는 그림(세 층 막대·화살표)을 더해도 된다. 조각의 내용은 실제 앱에서 찍은 것(지어낸 화면 금지, 핵심 가치 8).
- 지금 도구: `store-shots/flow/compose.mjs`가 crop 값으로 위쪽을 자름 → 조각 단위(요소 선택자로 잘라 확대)로 바꾸는 것이 다음 제작 때 할 일.

## 1. 지금 무엇이 문제인가

- 스토어 8장(10-30 학습 흐름 세트, `store-shots/flow/strings.mjs`): 1~5장은 흐름이지만 6~8장이 **장마다 화면 둘 = 세부 기능 6개**
  (하고 싶던 말 보기·묻기·AI 통화·영상 학습·Room·단체방)를 흐름 단계와 같은 크기로 보여 준다. 흐름 4단계(정해 줌·말하기·퀴즈·대화)도
  핵심 가치의 세 층(배우기 → 채우기 → 써 보기)과 어긋나 있다.
- 홍보 쇼츠(`marketing-videos.md`): 편 = 기능 하나(오류교정·분석·채팅·통화·단체방). 편마다 따로 보면 "기능 많은 앱"으로 보이고,
  그 기능이 하루 흐름 어디에 있는지, 그래서 왜 실력이 느는지는 어느 편에도 없다.
- **핵심 가치 한 줄**이 정해져 있지 않다 — 그래서 무엇을 크게 둘지 기준이 없다.

## 2. 층 (위가 크게, 아래로 갈수록 작게)

| 층 | 내용 | 어디에 |
|---|---|---|
| **L0 약속** | 한 줄. 안: "매일 정해 주는 대로 소리 내어 말하고, 틀린 것만 다시 풀다 보면 대화에서 꺼내 쓰게 된다" | 스토어 1장 제목·짧은 설명·모든 영상 끝 화면 |
| **L1 흐름** | 세 층 = **배우기**(Stagebank 대본·문장구조) → **채우기**(Quizbank, 틀린 것만 다시) → **써 보기**(AI 대화·통화) | 스토어 1장 그림, 대표 영상 |
| **L2 층마다 대표 장면 1개** | 배우기 = 내 줄을 말하면 바로 짚음 / 채우기 = 지난번 틀린 것 이번엔 ✓ / 써 보기 = 대화 중 내 줄 바로 아래 고침 | 스토어 2~4장, 층 영상 |
| **L3 차별점(왜 다른 앱이 아니라)** | ① 레벨 대신 데이터 — 익힌 것 숫자·배울 수 있는 것(📖), ② 막혀도 편한 말로 → 대화가 안 끊김 | 스토어 5~6장, 기능 쇼츠의 훅 |
| **L4 넓이** | 사람과(Room·단체방·1:1) — 써 보기 층의 확장 | 스토어 7장 하나 |
| **L5 세부 기능** | 표현 카드·묻기·문장분석·영상 학습·통화 세부·노트·Logbank·게임·아이콘·초대… | 스토어엔 **8장 한 장에 작은 아이콘 묶음으로만**, 또는 안 넣음. 사용법(?)·새로워진 점·기능 쇼츠 소재 |

규칙: **한 장(한 편)에 한 층.** 아래 층 기능은 위 층 장면 안에 작게 비칠 수는 있어도 제목이 되지 않는다.
세부 기능이 늘어도 L0~L2는 바뀌지 않는다 — 새 기능은 L5에 들어가고, L5는 스크린샷 칸을 늘리지 않는다.

## 3. 스토어 8장 (안)

| 장 | 층 | 큰 제목(ko 안) | 화면 |
|---|---|---|---|
| 1 | L0+L1 | 약속 한 줄 + 세 층 그림 | 세 층 화면을 작게 나란히 + 화살표 |
| 2 | L2 배우기 | 내 줄을 말하면 바로 짚어 줘요 | 대본 말하기(★·더 자연스러운 말) |
| 3 | L2 채우기 | 틀린 것만 다시, 이번엔 ✓ | Quizbank 문제 → ✓ |
| 4 | L2 써 보기 | 배운 걸 대화에서, 고침은 내 줄 바로 아래 | AI 대화 교정 |
| 5 | L3 데이터 | 레벨 대신, 익힌 만큼 숫자로 | 단계 진척·배울 수 있는 것 📖 |
| 6 | L3 막혀도 | 막히면 편한 말로 — 대화는 계속 | 편한 말 → 튜터가 학습 언어로 |
| 7 | L4 사람 | 같은 언어 배우는 사람들과 | Room 또는 단체방 화면 하나 |
| 8 | L5 | 더 할 수 있는 것 | 통화·영상·노트·문장분석… 아이콘+이름 격자(화면 캡처 없음) |

- 지금 세트와 차이: 세부 화면 6개 → 1장으로 접고, 비운 자리에 **데이터(5)·막혀도(6)** 차별점. 흐름은 4단계 → 세 층(오늘 할 것 정해 줌은 배우기 안에).
- 모든 장 위에 지금처럼 **흐름 막대**(배우기·채우기·써 보기 중 지금 어디)를 두어, 2~7장도 "흐름 속 어디"인지 보이게. 8장은 막대 없음.
- 맞춤 등록정보(나라·배우는 언어별)도 같은 8칸 — 글과 언어 조합만 바뀜.

## 4. 홍보 영상 (안)

| 종류 | 층 | 길이 | 내용 | 비율 |
|---|---|---|---|---|
| **대표 영상** 1편 | L0+L1 | 30~45초 | 하루 흐름 한 바퀴: 대본 말함 → 틀림 → 다음 날 퀴즈로 ✓ → 대화에서 그 말을 씀 | 채널 고정·Play 홍보 영상 |
| **층 영상** 3편 | L2 | 15초 | 층마다 대표 장면, 끝 1초에 "다음엔 → (다음 층)" | 처음 2주 우선 |
| **기능 쇼츠** | L3·L5 | 12~18초 | 지금 방식(오류교정·했구나·편한 말로) — 훅 소재 | 층 영상 뒤, 유입 실험용 |

- **모든 편 공통 끝 화면(2초):** L0 약속 한 줄 + 세 층 막대(이 편의 기능이 어느 층인지 불 켜짐) + 스토어 버튼. 기능 쇼츠로 들어온 사람도 끝에서 흐름을 본다.
- 기능 쇼츠는 L5 기능을 "새 기능 소개"로 쓰지 않고, 훅(질문) → 그 기능 → 끝 화면 흐름으로 이어지게.
- 사용자 간 편은 지금처럼 사람이 모인 뒤(L4).

## 정할 것

1. **L0 약속 한 줄** — 위 안 그대로 / 고쳐서 / 다른 방향(예: "말하기가 막히는 사람을 위한 매일 말하기 루틴").
2. 8장: 세부 기능을 **아이콘 묶음 1장**으로 남길지, **아예 뺄지**(뺀다면 그 자리에 무엇).
3. 차별점 둘(데이터·막혀도)이 맞는지 — 다른 후보: 모든 언어 조합, 먼저 해보고 고쳐 줌.
4. 영상: 대표 영상 1 + 층 영상 3을 기능 쇼츠보다 먼저 만들지.
5. **루프 밖 기능**(영상 학습·사람·Room·단체방)을 마케팅에서 어떻게 — 써 보기 층의 확장으로 7장 한 장 / 아예 빼고 따로 시리즈 / 앱 소개에서 뺌.
6. 경계 셋: **편한 말로 → 표현 보기**(지금 세부, 예전엔 차별점 후보), **AI 통화**(핵심으로 둠 — 대본 플랜·무료는 제한), **단계**(핵심 잇기로 둠 — 레벨 숫자는 안 보여 줌)가 맞는지.
