# 제휴 상품 카드(쿠팡 + 해외) — 설계안 (2026-10-20)

> 사용자: "쿠팡 광고 같은 걸 대화 내용이나 게시판 게시물을 바탕으로" → "문장 단위가 아니라 게시물·룸·대화 단위로" → "1:1·단체방은 키워드로만?" → "담아줘".
> **보류(사용자 2026-10-20 "일단 보류로 기록, 다른 게 더 있으면 찾아 두고 추가 타이밍에 알려줘").** 구현 없음. 아래 "꺼낼 때"의 조건이 보이면 그 채팅이 사용자에게 먼저 알린다.
> 숫자는 정리 글 기준 가정 — 가입 때 각 약관으로 다시 확인.

## 꺼낼 때 (이 중 하나가 보이면 사용자에게 알림)

| 조건 | 어디서 보나 | 그때 꺼낼 것 |
|---|---|---|
| 학습 주제 카드 자리가 생김(팩·통화 돌아보기, 미션에 여행·공항·호텔 장면) | 그 기능을 만드는 dev 채팅 | 여행 제휴(Klook·Agoda·Airalo) — 나라 상관없이 주제에 맞음, 상품 API 불필요 |
| 한국어 UI 무료 사용자가 한 달 1,000명 이상 | 사용자·서버 사용량(`scripts/cost-report.mjs`) | 쿠팡 1단계(게시판·학습 주제) |
| 한 나라가 설치의 10% 이상이거나 한 달 사용자 500명 이상 | Play Console 국가별 설치(사용자가 알려 줌) | 그 나라 표의 프로그램 |
| AdMob 실제 eCPM이 가정의 "낮음" 근처라 무료가 적자 | AdMob 보고서 → `ads.ts` `AD_REVENUE_USD`, `hub/economics.md` | 수익 보강으로 여행 제휴부터 앞당김 |
| 게시판 글이 하루 수십 개 이상 | 서버 게시판 | 게시판 상품 카드 |

메시지(1:1·단체방)는 위 조건과 상관없이 1단계 결과를 본 뒤에만(아래 3단계).

## 원칙

- **공개된 것과 우리가 이미 아는 주제로만 먼저.** 게시물(공개 글)·Room(방 제목)·학습 주제(오늘의 팩·통화 장면·미션). 학습자 문장은 읽지 않는다.
- **단위마다 한 번만:** 키워드는 게시물을 쓸 때·방을 만들 때 한 번 뽑아 저장, 학습 주제는 이미 아는 값. 문장마다 AI를 부르지 않는다.
- **한국어 UI·무료·안드로이드만** (쿠팡은 한국 전용, 구독자는 광고 없음 — `billing/ads.ts` `adsApply`와 같은 기준). 다른 언어 UI는 AdMob만.
- **대가성 문구를 카드마다:** "쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."
- **적게:** 키워드가 확실할 때만, 한 화면에 카드 1개까지. 대화·통화·방 안처럼 무언가 하는 중에는 없음.
- 1:1·단체방 메시지는 **마지막 단계, 옵트인으로만**(아래 3단계).

## 단계

### 1단계 — 게시판 + 학습 주제 (먼저 시험)

| 자리 | 키워드 출처 | 언제 뽑나 | 카드 위치 |
|---|---|---|---|
| 게시판 | 글 본문(공개) | 글을 쓸 때 한 번(작은 모델 호출 약 0.7원 또는 단어 목록), 글과 같이 저장 | 글을 열었을 때 본문·댓글 사이 1개 |
| 학습 주제 | 오늘의 팩·통화 장면·미션 주제(이미 아는 값) | 없음(주제 → 분류 표) | 팩·통화가 끝난 돌아보기 아래 1개 |
| Room | 방 제목·언어(공개) | 방을 만들 때 한 번 | 공개 방에서 나온 뒤 로비 위 1개(전면 광고가 뜬 날은 생략) |

- 키워드 → **분류**(여행용품·이어폰·노트북·교재 …, 수십 개 고정 표)로 바꾸고, 분류마다 쿠팡 검색 결과를 서버에 하루 캐시. 카드에는 분류의 상품 1개.
- 서버: 분류 → 상품 API(쿠팡 파트너스 검색·딥링크, 키는 Vercel 환경 변수), 모델 호출은 `meterRequest`+`opCost.ts`, 새 KV 키는 `scripts/data-map.json`.
- 앱(빌드 필요): 상품 카드 컴포넌트(이미지·이름·가격·대가성 문구·"광고"), 링크는 외부 브라우저로.
- 처리방침: 공개 글·방 제목·학습 주제로 상품을 고른다는 한 줄. 학습자 문장·메시지는 쓰지 않는다고 명시.
- 측정: 노출·클릭은 우리 서버에서, 구매·수수료는 쿠팡 파트너스 보고서. 2~4주 보고 계속할지.

### 2단계 — 1단계 결과로 판단

- 클릭률·수수료가 네이티브 광고 자리 수익(노출 1번 약 1.4~5.6원)보다 낫거나 덤으로 의미 있으면 유지, 아니면 끔(서버 값 하나로).

### 3단계 — 1:1·단체방 메시지 (옵트인, 마지막)

- **기본 꺼짐.** 설정에서 "대화 주제에 맞는 추천 보기"를 켠 사람만.
- **기기 안에서만 맞춤:** 앱에 넣은 고정 단어 목록과 메시지를 폰에서 비교, AI 없음. 서버·쿠팡에는 **메시지 글자도 단어도 보내지 않고 분류 번호만**.
- **자리는 대화 밖:** 대화창 안이 아니라 대화를 닫고 나온 목록 쪽 카드 1개.
- 처리방침·동의 문구는 전문가 확인 후. 개인정보보호법상 별도 동의 영역으로 보고 기본 꺼짐을 지킨다.
- 위험: "내 메시지로 광고"라는 인식(Gmail은 메일 내용 기반 광고를 2017년에 그만둠, 카카오톡도 안 함). 켜는 사람이 적어 수익은 작음 — 1단계에서 구매가 실제로 나올 때만 검토.

## 한국 밖: 나라별 제휴 프로그램 (2026-10-20 조사, 사용자 "한국 제외 타 국가 광고 상품도")

> 수수료·조건은 정리 글 기준이라 가입 때 각 약관으로 다시 확인. **나라는 UI 언어가 아니라 기기 지역(Play 국가)으로 고른다** — 스페인어 UI가 스페인인지 멕시코인지 다르다.

| 프로그램 | 맞는 UI 언어·지역 | 수수료(대략) | 상품 API | 메모 |
|---|---|---|---|---|
| **Amazon Associates** | en(미·영 등), es(스페인·멕시코), fr, it, ja, hi(인도), pt(브라질), ar(UAE·사우디) | 분야별 약 1~10% | 있음 — PA-API 5는 지원 종료, 후속 **Creators API** | 나라마다 따로 가입. API는 보통 판매 실적이 있어야 열림(확인 필요). 가장 넓게 덮음 |
| **Rakuten(楽天)** | ja | 2~4%(일부 가게 최대 20%), 월 상한 있음 | 楽天 Web Service 상품 검색 | 일본은 아마존과 둘 중 하나 또는 둘 다 |
| **Shopee 제휴** | id, th, vi(+ 필리핀·말레이·대만) | 분야별(패션·뷰티 높음) | 제휴망(Involve Asia 등) 딥링크 | 동남아는 아마존보다 Shopee·Lazada가 큼 |
| **AliExpress Portals** | 전 세계(ru, ar, pt, es 등 아마존이 약한 곳) | 0~9%, 평균 약 4%, 1건 $50 상한 | 있음 | 쿠키 1~3일로 짧음 |
| **Klook**(여행) | 전 세계, 특히 아시아 | 기본 약 2~5%(행사 때 최대 8%), 쿠키 30일 | 링크 중심 | 학습 주제(공항·호텔·여행) 카드와 잘 맞음 |
| **Mercado Livre** | pt(브라질) — 다른 중남미는 따로 확인 | 분야별 약 2~8%(패션·뷰티 높음, 휴대폰 낮음) | 제휴 포털 링크 | 브라질 CPF·Mercado Pago 정산 — 한국 사업자가 받을 수 있는지 확인 필요 |
| **Noon** | ar(UAE·사우디·이집트) | 약 2~10%, 쿠키 약 30일 | 제휴망(ArabClicks 등) | 중동은 아마존(.ae·.sa)과 둘 중 |
| **Lazada** | id, th(+ 말레이·싱가포르·필리핀) | 분야·신규 고객·행사별 | 제휴망(Involve Asia) | Shopee와 같은 망에서 같이 |
| 더 볼 곳 | hi → Flipkart(제휴 운영 여부 확인), zh(대만·홍콩) → Shopee TW | — | — | 그 지역 사용자가 생기면 |

### 여행 — 학습 주제(공항·호텔·여행 장면)와 맞는 것

| 프로그램 | 수수료(대략) | 쿠키 | 메모 |
|---|---|---|---|
| **Klook** | 약 2~5%(행사 때 최대 8%) | 30일(호텔 7일) | 체험·교통·와이파이, 아시아 강함 |
| **Agoda** | 예약가의 약 4~7%(숙박 완료 뒤) | 약 30일 | 딥링크·검색 위젯·API, 아시아 숙소 |
| **Airalo**(eSIM) | 판매가의 12% | 30일 | 200개국 이상 — "해외 가서 쓸 말" 장면과 가장 잘 맞음, 금액은 작음 |

### 언어 학습 쪽 (조심)

| 프로그램 | 수수료(대략) | 메모 |
|---|---|---|
| italki / Preply(사람 튜터) | 첫 수업 결제당 $10 이상 / 첫 수업의 일부 | **우리 "사람" 기능과 겹치는 경쟁 서비스** — 사용자를 내보내는 셈이라 비추천 |
| Babbel·Rosetta Stone·Lingoda | 건당 $30~75 또는 7% | 같은 이유로 비추천. 넣는다면 우리가 없는 것(시험 대비 교재 등)만 |
| Coursera | 강좌 20%~ | 학습자 층은 맞지만 언어 학습과 거리 있음 |

**제안 순서(해외):** 1) 여행(Klook·Agoda·Airalo) — 학습 주제(여행 장면)에 나라 상관없이 바로 맞고 상품 API가 필요 없음.
2) Amazon(Creators API) — en·es·fr·it·ja·hi·pt 대부분을 덮음, API 조건(실적)이 풀리면.
3) Shopee — id·th·vi 사용자가 늘면. 나머지는 실제 사용자 분포(Play 국가별 설치)를 보고.

**구조:** 서버에 "분류 → 나라별 프로그램 → 상품" 표 하나. 앱은 분류 번호와 나라만 보내고 카드를 받는다(쿠팡과 같은 카드).
대가성 문구는 나라별 규정에 맞게(미국 FTC "As an Amazon Associate I earn from qualifying purchases" 등) 14개 언어로.

**현실:** 제휴는 사서야 돈이 되므로 노출당 수익이 AdMob 네이티브보다 낮을 수 있다. AdMob(이미 전 세계)은 그대로 두고 덤으로 시험.

## 사람이 할 일

1. 쿠팡 파트너스 가입·최종 승인. 해외는 먼저 Klook 제휴(직접 또는 제휴망), 그다음 Amazon Associates(사용자가 많은 나라부터).
2. 약관에서 확인: 앱 안 노출 허용 여부, 검색 API를 쓸 수 있는 조건(승인·실적), 이미지·가격 표시 규칙.
3. 1단계를 할지, 카드 위치(위 표) 확정.

## 정할 것

- 1단계 범위(게시판만 먼저 / 게시판 + 학습 주제 / 셋 다).
- 게시판 키워드: 작은 모델(정확, 글 하나 약 0.7원) vs 고정 단어 목록(0원, 놓침 많음).
- 3단계를 아예 안 할지, 1단계 결과를 보고 다시 물을지.
