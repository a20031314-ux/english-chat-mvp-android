# 사용자 프로필 구체화 (초안, 2026-10-23)

> 사용자 요청: "사용자 프로필 구체화 전략". 상태: 설계안, 사용자 결정 뒤 구현.
> 기준: main `6006b8f`. 관련: `checklist-start-and-learner-brief.md`(단계 3·4 남음), `team-workspace.md`, PRODUCT.md "My"·"사람 탭".

## 지금 (두 프로필이 따로 놂)

| | 공개 프로필 (`server/accountStore.ts`) | 학습자 프로필 (보이지 않음) |
|---|---|---|
| 담긴 것 | 닉네임 20자·사진·자기소개 200자·숨김 | 체크(`selfCheck`: 부족한 부분·위주·쓸 곳·시작 단계), 구문 상태(`learner/profile.ts`), 표현 장부, 턴 측정, 실수 경향 |
| 언어 | 앱 언어 ⇄ 학습 언어(앱 설정 그대로) | 학습 언어별 따로 |
| 누가 씀 | 사람 목록·Room·메시지 | 튜터(`learner/brief.ts`), 지도, 오늘 해볼 것 |
| 문제 | 고를 근거가 자기소개 한 칸뿐. 앱 언어 = 모국어로 간주(영어 UI 쓰는 한국인이 "영어 원어민"처럼 보임). 거르기 3개 | 사용자는 못 봄(고칠 길 없음). 튜터가 "나"를 몰라 매번 같은 질문. 사람 쪽과 단절 |

## 방향: 한 번 입력 → 세 곳에서 씀

```
나에 대한 사실(칩, id만) ──┬─► 공개 프로필 카드·시트·거르기·정렬
                          ├─► 튜터 brief 한 줄(대화 소재)
                          └─► 지도·오늘 해볼 것 상황 소재(selfCheck.use 확장)
쌓인 학습 데이터 ─────────────► "튜터가 알고 있는 것"(본인만, 끄기)
```

### A. 나에 대한 사실 — 고정 칩, id만 저장
- **언어:** 모국어 1 + 할 수 있는 언어 최대 3(수준 없음), 배우는 언어는 지금처럼 앱 설정. → 사람 목록 언어 표시·"내 언어를 배우는 사람" 거르기를 앱 언어 대신 모국어로.
- **관심사:** 고정 목록 약 24개(음악·여행·게임·요리·운동·영화·드라마·책·IT·패션·반려동물·사진 …) 최대 5개.
- **하는 일:** 학생·직장인·프리랜서·쉬는 중·기타(선택).
- **대화 방식:** 글 / 통화 / 영상, 편한 시간대(자동 시간대 + 아침·낮·저녁·밤).
- 고정 칩이라: 14개 언어 틀 문구로 번역 끝, 검색·거르기 쉬움, 자유 글 검열 불필요, 학습자 문장 저장 금지 원칙과 맞음.

### B. 공개 프로필 확장 (레벨·점수는 계속 안 보임)
- 카드: 사진·닉네임·모국어 → 배우는 언어·관심사 칩 3개·"겹치는 관심사 n" 표시.
- 시트: + 목표 한 줄(체크의 쓸 곳·위주에서 틀 문구로 자동, 예 "여행에서 말이 바로 나오게"), 대화 방식, 활동(연속일·연 방 수 — 수준 아님).
- 사람 목록: 거르기에 "관심사 겹침"·"통화 좋아함", 정렬 = 최근 접속 + 언어 맞교환 + 관심사 겹침 점수. 메이트 추천의 재료.
- **자동 칩(입력 없이):** 노트 주제(장 8 × 주제 3, `notesPlace`)에서 많이 다룬 주제 3개를 "자주 이야기하는 주제"로 — 본인이 켤 때만 공개.

### C. 학습자 프로필 보이게 (체크 초안 단계 4)
- My에 "튜터가 알고 있는 것": 자주 헷갈리는 것·배운 표현 다시 쓰는 중·쉽게/조금 어렵게·내 관심사, 항목별 끄기·전체 끄기·체크 다시 하기.
- 끄면 brief에서 빠짐(권하기는 그대로). 신뢰 + 잘못된 데이터 고칠 길.

## 단계

1. **서버만(바로 반영):** `AccountRecord.profile`에 `langs`·`interests`·`work`·`meet` 추가(없으면 빈 값, 옛 앱 안 깨짐), `/api/account` 검증, `/api/social` people에 실어 보내고 겹침 정렬, brief에 관심사 한 줄("이 사람은 X·Y를 좋아함 — 소재로, 묻지 말고"). `data-map.json`·처리방침 en/ko.
2. **앱(2.72 빌드):** 편집 시트 칩, 로그인 직후 한 화면(건너뛰기 가능, 부연설명 없이 칩만), 카드·시트 표시, 거르기 2개. 14개 언어. Play 데이터 보안: 다른 회원에게 보이는 관심사·언어.
3. **앱:** "튜터가 알고 있는 것" + 끄기, 체크 초안 단계 3 신호(해석 열람·통화 helped).
4. **나중:** 자동 칩(노트 주제), 메이트·방 추천.

## 정할 것 (추천)

1. 관심사·하는 일을 **고정 칩**으로(추천) vs 자유 입력.
2. 모국어·할 수 있는 언어를 따로 받을지 — 추천: 받음(지금 앱 언어를 모국어로 보는 오류 해소).
3. 학습 쪽에서 공개할 것 — 추천: 목표 한 줄만 기본 공개, 자주 다루는 주제는 기본 끔, 실수·표현은 공개 안 함.
4. 로그인 직후 칩 화면 넣을지 — 추천: 넣음(건너뛰기 가능). 안 넣으면 편집 시트에만.
5. 튜터에 관심사를 쓸지 — 추천: 씀(본인 것만, "튜터가 알고 있는 것"에서 끄기).
