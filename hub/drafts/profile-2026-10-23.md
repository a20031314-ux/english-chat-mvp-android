# 사용자 프로필 설계 (2026-10-23, 정리본)

> 사용자 요청: 프로필 구체화 → 공개 범위 → 성실한 사용자 유인 → 의견 반영 보상(보류). 상태: **결정 끝(사용자 "추천대로" 2026-10-23), 1단계 서버 끝** — 2단계 앱부터.
> 기준 main `daccc1c`. 관련: `checklist-start-and-learner-brief.md`(단계 3·4), PRODUCT.md "My"·"사람 탭", `hub/feedback/README.md`.

## 원칙

1. **프로필은 하나.** 학습 프로필을 따로 공개하지 않고, 학습 데이터에서 고른 칸만 공개 프로필에 붙인다. 칸마다 "표시 안 함".
2. **남에게 해 준 것은 공개, 내 학습 상태는 숨김.** 약점이 보이면 틀릴까 봐 말을 덜 하게 되고, 핵심 가치("틀려도 말하게")가 깨진다. 레벨 비공개 원칙과 같다.
3. **보상은 돈이 아니라 기능상의 이점(노출).** 포인트는 원가가 보낸 사람 수에 비례해 터지고 품앗이 남용을 부른다(아래 "보류").
4. **칩·숫자·id만 저장.** 자유 글은 지금 자기소개뿐. 학습자 문장은 서버에 저장하지 않는다.

## 프로필 구성

### ① 나에 대한 사실 (항상 공개, 고정 칩)
- **언어:** 모국어 1 + 할 수 있는 언어 최대 3(수준 없음). 배우는 언어는 앱 설정. → 사람 카드·"내 언어를 배우는 사람" 거르기를 앱 언어 대신 모국어로.
- **관심사:** 고정 목록 약 24개 중 최대 5개(음악·여행·게임·요리·운동·영화·드라마·책·IT·패션·반려동물·사진 …).
- **하는 일:** 학생·직장인·프리랜서·쉬는 중·기타(선택).
- **대화 방식:** 글 / 통화 / 영상, 편한 시간대(시간대 자동 + 아침·낮·저녁·밤).
- 같은 칩을 **튜터 요약에 한 줄**(대화 소재로, 묻지 말고)과 **지도·오늘 해볼 것의 상황 소재**로도 쓴다 — 한 번 입력, 세 곳.

### ② 학습 칸 (골라서 공개)

| 칸 | 내용 | 처음 |
|---|---|---|
| 🙌 도움 준 답 | 받은 "도움됐어요" 수(언어별) | 켬 |
| 🔥 꾸준함 | 이번 주 대화한 날·연속일 | 켬 |
| 🎯 목표 한 줄 | 체크 답에서 자동 문장(틀 문구) | 켬 |
| 🛠 함께 만든 사람 | 반영된 의견 수 | 켬 |
| 💬 자주 이야기하는 주제 | 노트 주제 상위 3 | 끔 |
| ✨ 요즘 익힌 표현 | 숙지 표현 중 본인이 고른 3개 | 끔 |

- **스위치조차 없는 것:** 실수 종류·약점·교정 비율·레벨·문장·질문한 수(답한 수만 공개).
- 편집 시트 **"프로필에 보일 것"** 한 묶음: 칸 이름 + 스위치만(안내 글 없음). 기존 "사람 목록에 내 프로필 보이지 않기"도 여기로.

### ③ 튜터가 알고 있는 것 (본인만)
- My에: 자주 헷갈리는 것·다시 써 주는 표현·쉽게/조금 어렵게·내 관심사. 항목별·전체 끄기(끄면 튜터 요약에서 빠짐), 체크 다시 하기.
- 잘못된 데이터를 고칠 길이자 신뢰. 체크 초안 단계 4와 같은 것.

## 기여와 보상: 노출

### "도움됐어요"
- 일반 좋아요가 아니라 **질문한 사람만** 그 답에 누름: Room ❓ 답하기, 쪽지로 묻기의 답, 게시판 댓글.
- 남용 막기: 같은 두 사람 하루 1번, 서로만 주고받는 쌍은 덜 셈, 가입 7일 뒤부터, 차단·신고 관계 제외.

### 기여 점수 → 노출 가산
- 기여 점수 = 최근 30일 "도움됐어요" + 반영된 의견(가중) — 오래된 것은 빠져서 지금 활발한 사람이 올라온다.
- **사람 목록:** 지금 최근 접속 순 → 접속 시각에 기여 점수만큼 가산(예: 점수 구간마다 몇 시간 앞당김, 상한 있음) + 언어 맞교환·관심사 겹침. 접속 안 한 사람이 위로 오지는 않게(14일 창 그대로).
- **게시판:** 기여자의 새 글은 첫 몇 시간 목록 위쪽 노출 가산(상한·하루 글 수 한도 그대로). 고정 글처럼 계속 머물지는 않음.
- 표시: 프로필 🙌·🛠 칸, 이정표 배지 10·50·100(사실만, 등급 이름 없음).
- 원가 없음(정렬만). 숫자는 계정별 집계만, 누가 누구에게 눌렀는지는 중복 막기용으로 짧게 보관.

### 보류: 의견 반영 포인트 보상 (사용자 2026-10-23)
- 검토: 반영된 의견을 보낸 사람에게 포인트. 1포인트 = 통화 5분·원가 약 55원, 같은 의견 100명 × 20포인트면 카드 하나 원가 약 11만 원. 수정안(처음 3명 10·나머지 2·카드 100·한 달 30)도 냈으나,
- **결정: 보류.** 대부분 간단한 의견이라 포인트보다 **프로필·게시물 노출 증가 같은 기능상의 이점**이 낫다 → 위 🛠 칸 + 기여 점수에 반영된 의견을 넣는 것으로 대신. 포인트는 꺼내지 않는다.

## 단계

1. **서버(바로 반영):** `AccountRecord.profile`에 `langs`·`interests`·`work`·`meet`·`show`(칸별 표시) 추가(없으면 기본값, 옛 앱 안 깨짐), `/api/account/profile` 검증,
   "도움됐어요" 저장·집계(`/api/social` 등), 반영 의견 수(의견함 "반영" 처리 때 `feedbackFixStore`에서 보낸 계정마다 +1), 기여 점수,
   `/api/social` people에 칸·점수 싣고 정렬 가산, 게시판 정렬 가산, 튜터 요약에 관심사 한 줄. `data-map.json`·처리방침 en/ko.
2. **앱(다음 빌드):** 편집 시트 칩·"프로필에 보일 것", 로그인 직후 칩 화면(건너뛰기), 카드·시트에 칸 표시, 답 아래 "도움됐어요" 버튼, 거르기 2개(관심사 겹침·통화 좋아함). 14개 언어. Play 데이터 보안: 다른 회원에게 보이는 언어·관심사·기여 수.
3. **앱:** "튜터가 알고 있는 것" + 끄기, 체크 초안 단계 3 신호.
4. **나중:** 노트 주제 자동 칩, 메이트·방 추천.

## 결정 (사용자 2026-10-23 "추천대로" — 모두 추천안)

1. 관심사·하는 일을 고정 칩으로(추천) vs 자유 입력.
2. 모국어·할 수 있는 언어를 앱 언어와 따로 받을지(추천: 받음).
3. 학습 칸의 처음 켜짐 값이 위 표대로 괜찮은지.
4. 로그인 직후 칩 화면(추천: 넣음, 건너뛰기 가능).
5. 튜터가 관심사를 쓸지(추천: 씀, 끌 수 있게).
6. 노출 가산 크기 — 사람 목록 최대 몇 시간 앞당김, 게시판 몇 시간(추천: 처음엔 작게, 사람 목록 최대 6시간·게시판 3시간, 운영 보며 조정).
