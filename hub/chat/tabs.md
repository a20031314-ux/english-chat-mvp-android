# 탭 번호 — 채팅 자리와 양도

> 채팅은 **번호가 붙은 자리(탭)**에서 일한다. 채팅이 길어지면 그 탭의 인계 노트를 남기고 끊고(**양도**), 새 채팅이 **"N번 받기"**로 이어받는다(사용자 2026-11-01).
> 인계 노트는 탭마다 한 장 `hub/chat/handoff/<번호>.md`(덮어씀). 자세한 기록은 `hub/chat/log/`, 역할 규칙은 `hub/work/roles/`.

| 번호 | 이름 | 맡는 곳 | 역할 파일 |
|---|---|---|---|
| 1 | 메인 | 공통(앱 틀·시트·계정·요금·광고) + 여러 탭에 걸친 정리·버전 자르기 전 통합 확인 | `hub/work/roles/dev.md` |
| 2 | My | My 탭(Logbank·Quizbank·Languagebank, `lib/curriculum`·`studyMap`) | `hub/work/roles/dev.md` |
| 3 | AI | AI 채팅·통화·영상 학습 | `hub/work/roles/dev.md` |
| 4 | 사람 | 대화(1:1·단체방)·사람·Room·랜덤·초대 | `hub/work/roles/dev.md` |
| 5 | 점검 | 가상 사용자·브라우저 확인·점검 결과 나눠 주기 | `hub/work/roles/qa.md` |
| 6 | 스토어 | 출시 노트·등록정보·버전 | `hub/work/roles/store.md` |

- **탭 → 영역은 `hub/chat/tabs.json`**(전체구조 `scripts/structure.json` 영역을 묶음). 적용 범위 찾기·확인 요청이 이 표로 받는 탭을 정한다. 파일 소유는 나누지 않았다 — 다른 탭 영역을 고쳐야 하면 고치고, 그 탭에 확인 요청을 만든다(아래).
- 처음 여는 채팅도 하고 싶은 일을 말하면 된다. 맞는 탭 번호를 골라 그 번호로 일하고, 끝날 때 그 번호로 양도한다.

## 탭끼리 확인 요청 (사용자 2026-11-09 — 알리기만 하지 않고 답을 받는다)

- **고치기 전:** `node scripts/scope.mjs <파일|기능 id|문구 키>` — 그 코드가 닿는 탭·화면 파일·같은 이름을 따로 정의한 곳. 기능 장부 "쓰는 탭" 칸이 둘 이상이면 여러 탭 기능이다.
- **고친 뒤(끝내기 전):** `node scripts/asks.mjs apply --from <내 탭> --base <시작 커밋> --what "무엇이 어떻게 바뀌었나"` → 닿는 다른 탭마다 요청 하나(볼 화면 파일 + 볼 것). 끝내기 훅이 다른 탭에 닿는 변경에 이것이 없으면 막는다.
- **받는 탭:** 시작 훅이 열린 요청을 넣고 `/take N`이 그 탭 요청부터 처리 — 볼 곳에서 새 동작인지·옛 동작이 남았는지 확인 → 필요하면 고침 → `asks.mjs answer <id> --by <탭> --status 맞음|고침|해당없음 --note "…"`.
- **옛 코드:** 바꾼 것이 옛 방식을 대신했는데 옛 코드가 남으면 지우거나 `asks.mjs delete`로 **사용자에게** 묻는다(받는 쪽 user — 어느 채팅이든 시작할 때 사용자에게 묻고 답을 적음). log에 `- 옛 것: …` 한 줄(끝내기 훅이 봄), 새로 남은 죽은 코드는 `scripts/leftovers.mjs --check`(훅·CI)가 잡는다.
- 모아 보기: `hub/chat/ASKS.md`(자동)·허브 페이지 "확인 요청" 칸.

## 언제 양도하나

- **대화가 한 번 압축되면**(긴 채팅 — 세부가 줄기 시작함) 지금 하던 일 단위가 끝나는 곳에서 양도한다. 끝내기 훅이 한 번 알려 준다(`.claude/hooks/hub.mjs`).
- 사용자가 "양도"·"끊어"라고 할 때, 하던 일과 전혀 다른 큰 일로 넘어갈 때.
- 일 중간(커밋 전·테스트 실패 중)에는 끊지 않는다 — 커밋할 수 있는 곳까지 마치거나, 못 마친 것을 노트 "하던 일"에 정확히 적는다.

## 흐름

1. **양도**(`/pass N`, 끊는 채팅): `hub/chat/handoff/N.md`를 새로 쓰고(형식은 `.claude/skills/pass/SKILL.md`), 역할 파일 열린 일·log 한 항목과 같이 커밋·push → 사용자에게 한 줄 "**N번 양도함 — 새 채팅에서 'N번 받기'**".
2. **받기**(`/take N` 또는 "N번 받기", 새 채팅): `git pull` → `hub/chat/handoff/N.md` + 역할 파일 + inbox 그 역할 줄 + **그 탭에 온 확인 요청**(`asks.mjs list --to N`) → 노트의 "받음" 줄을 고쳐 커밋 → 사용자에게 두세 줄(어디까지 왔나·바로 이어갈 것·답할 확인 요청·결정 대기).
