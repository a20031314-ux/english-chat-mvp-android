# 사용자가 짜는 지도: 대화 구간 돌아보기 → 지도 반영 (초안, 2026-10-15)

> 사용자 요청: "지도 설계를 사용자의 자유에 좀 더 맡기고 싶다. 대화 학습을 하다가 구간을 끊고, 여기서 아는 부분·모르는 부분·
> 대화 전반적으로 어려웠던 부분을 사용자가 기록하거나 체크하면 반영되는 흐름."
> 지난 계획의 3단계(숙지 기반 지도 넓히기)를 이 흐름으로 대신한다: 지도가 넓어지는 계기가 시스템 판단만이 아니라 사용자의 표시.
> 상태: 설계안. 사용자 확인 후 구현.

## 흐름

1. **구간 끊기** — 채팅·통화 중 언제든 "여기까지 돌아보기". 기본 구간은 지난 돌아보기 이후의 대화(없으면 처음부터), 시작 줄을 끌어서 줄일 수 있음.
   통화는 끝난 뒤나 일시정지 상태에서(마이크가 열려 있을 때는 안 띄움).
2. **표시하기** — 구간의 줄들이 한 화면에. 문장분석처럼 단어·표현을 눌러 고르고 두 가지로 표시:
   - **알아요** (✓)
   - **모르겠어요** (?) — 튜터 말에서 못 알아들은 것, 내가 말하고 싶었는데 못 한 것 모두.
   그리고 구간 전체에 대해:
   - **어려웠던 점** 칩(여러 개): 말이 빨랐어요 · 단어를 몰랐어요 · 문장을 못 만들겠어요 · 시작을 못 하겠어요 · 이 주제 자체가 낯설어요
   - **메모** 한 줄(선택, 편한 말로).
3. **반영 미리보기** — "지도에 이렇게 넣을게요" 목록을 보여주고 사용자가 체크한 것만 반영:
   - 모르겠어요 표현 → 맞는 주제의 "알아야 할 것" 할 일로 추가 (자주 틀림과 같은 방식, "내가 고른 것" 표시)
   - 어려웠던 점 + 메모 + 대화 상황 → 새 주제 제안 ("카페에서 빠른 주문 알아듣기") 또는 기존 주제 보강
   - 알아요 표현 → 그 표현의 할 일을 지도에서 뒤로(또는 숨기기). 숙지로 치지는 않음(아래).
4. **지도에서 보이기** — 사용자가 넣은 할 일·주제에 "내가 고른 것" 표시. 추천 순서에서 자주 틀림과 같은 급으로 앞에.
   지도 주제는 사용자가 숨기기·순서 고정도 가능(자유도).

## 기존 장치와의 관계

| 표시 | 장부(표현 기록) | 지도 |
|---|---|---|
| 모르겠어요 | "만남" + 사용자가 모른다고 함 표시 | 할 일 추가(지도 미션 생성기 재사용, 약점 미션과 같은 경로) |
| 알아요 | "안다고 표시함" 표시. 상태는 그대로 — 숙지는 계속 "도움 없이 꺼내 씀"으로만 | 그 표현 할 일을 뒤로 / 숨김, 나중에 "써보기"로 확인 기회 |
| 어려웠던 점·메모 | 저장(사용자 글은 기기에만, 서버엔 칩 종류만 — 개인정보 원칙) | 주제 제안의 재료, 지도 다시 그리기·넓히기에 반영 |

- 모델 호출: 반영 미리보기를 만들 때 1회(할 일 문구·주제 제안 생성). 표시만 하고 반영 안 하면 0회.
- 메모는 사용자가 쓴 글이라 기기에만 둔다. 서버로는 "주제 제안을 만들 때 한 번" 보내고 저장하지 않음(문장 분석 질문과 같은 원칙).

## 화면

- 채팅: 입력창 위 작은 버튼 "돌아보기". 통화: 일시정지·끝난 화면에 "이 구간 돌아보기".
- 돌아보기 시트: 줄 목록(단어 눌러 ✓/?), 어려웠던 점 칩, 메모, 아래 "지도에 반영 미리보기".
- 지도: "내가 고른 것" 칩, 주제 길게 눌러 숨기기·고정.
- 14개 언어, 띄어쓰기 없는 언어는 기존 단어 나누기(wordSegments)로 고르기.

## 단계

1. 돌아보기 시트(채팅) + 장부 표시(알아요/모르겠어요) — 반영 없이 기록만.
2. 반영 미리보기 + 지도 할 일 추가·뒤로 보내기.
3. 주제 제안(어려웠던 점·메모·상황) + 지도에 새 주제 추가, 숨기기·고정.
4. 통화에도 같은 시트.

## 사용자에게 정할 것

1. 구간 끊기: 추천 — 지난 돌아보기 이후 자동 + 시작 줄 조정. (또는 처음·끝 줄을 매번 직접 고르기)
2. 반영 방식: 추천 — 미리보기에서 체크한 것만 반영. (또는 표시하는 즉시 자동 반영)
3. "알아요"의 의미: 추천 — 숙지로 치지 않고 할 일을 뒤로 보내기만(숙지는 꺼내 쓴 것만). (또는 알아요 = 숙지)
4. 보류: 오늘의 스크립트(구독자용)는 이 흐름 뒤로.
