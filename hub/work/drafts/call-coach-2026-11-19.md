# 통화 한 구조 + 코치(제3튜터, 자막) 설계 (2026-11-19 — 아직 코드 아님)

사용자: "통화탭을 한 구조로 다시 합칠지 설계해줘. 대신 수업모드는 제3튜터로 자막으로 띄우던가"

## 1. 왜 합치나

- **둘의 차이가 교정 방식 하나뿐이다.** 수업에서 틀(2026-11-18)을 빼고 나니 수업 = 자유대화 + 튜터가 말로 짚기(짚기 → 바른 문장 → 다시 말해 보기) + 숙제 + 요즘 배운 말 화제가 됐다. 자유대화는 같은 교정을 내 얼굴 아래 카드로 조용히 보여 준다.
- **사용자·점검 둘 다 차이를 못 느꼈다.** U47 "통화탭의 옵션이 별 차이가 없다"는 11-12에 다시 보였다. 11-08 통화 점검에서 "그냥 대화 vs 수업 차이"는 3.0이었고, 세 인물 모두 "수업 시작이 자유대화와 같다"고 적었다.
- **말로 짚으면 대화가 끊긴다.** 수업 튜터는 틀린 차례마다 대화를 멈추고 세 마디로 교정한다. 대화 상대와 선생님을 한 사람이 동시에 맡는 셈이다. 같은 질문 반복, "들렸어요?" 반복, 다른 말을 했는데 또 시키기 같은 흔들림이 거기서 나왔다(log 11-18 세 항목).
- **코드가 두 갈래다.** `RoleplayScreen`의 `coachOn` 분기가 열 곳 남짓이고, 감독 `coachRules`·`redo`·`retry`, 침묵 시간 둘(`LESSON_NO_SPEECH_MS` 7초·`TALK_NO_SPEECH_MS` 18초), 설명창 세 줄 묶음 둘, 통화 기록 칩 둘로 나뉘어 있다.

## 2. 한 구조

통화 화면 하나에 셋이 있다.

| 누구 | 무엇을 | 어디에 |
|---|---|---|
| **튜터**(지금 고른 튜터) | 대화만 한다. 짚지도 다시 시키지도 않는다. 게임이면 게임 진행만. | 위 얼굴 · 목소리 · 💬 자막 |
| **코치**(제3튜터) | 내 말을 듣고 고친다. 짚기 한 줄 · 바른 문장 · 다시 말해 보기. | 튜터와 나 사이의 **자막 띠**(작은 얼굴 + 이름), 소리 없음 |
| **나** | 말한다. 코치 띠는 봐도 되고 그냥 넘겨도 된다. | 아래 얼굴 |

- **모드는 "튜터가 무엇을 하나"만 바꾼다:** 대화 · 🎲 스무고개 · 🧑‍🏫 가르치기. 코치는 세 모드 모두에 같은 층으로 있다.
- 문 넷(📞 자유대화 · 🎓 수업 · 🎲 게임 · 🧑‍🏫 가르치기)이 **문 셋**이 된다(아래 7-1에서 정함). 🎓 문과 "수업"이라는 이름은 없어진다.

## 3. 코치 띠

```
┌ 튜터 얼굴 · 💬 "Oh nice! What did you eat there?"
│
├ 🧑‍🏫 Mina  시제가 달라요              ← note(앱 언어)
│          I went to a café yesterday.  🔊  ← better/meant(학습 언어, 고친 곳만 칠함)
│          🎤 다시                       ← 누르지 않아도 됨
│
└ 내 얼굴
```

- **언제 뜨나:** 감독 답에 `better`·`meant`가 있을 때(틀림), `offer`일 때(어색함 — 띠 색을 옅게). 지금 자유대화 카드(`CoachCardView quiet`)와 같은 자리이고, 그 카드가 코치 띠가 된다.
- **다시 말해 보기는 시키지 않고 건넨다.**
  - 다음 차례에 내가 바른 문장을 따라 말하면(지금 있는 `triedRedo`가 판단 — 기다리던 문장 낱말의 절반 이상) 앱이 낱말 대조로 채점한다(`compareToTarget`, 모델 없음). 띠에 ✓, 틀리면 바뀐 곳만 칠해 한 번 더. 두 번째에도 틀리면 띠를 접는다.
  - 다른 말을 하면 띠는 접히고 대화가 그대로 이어진다(11-18 고친 규칙을 화면 쪽으로 옮김).
  - 🎤 다시: 차례와 상관없이 그 문장만 말해 보는 버튼(`Attempt` 한 줄 말해 보기 — 이미 있음). 튜터는 기다린다.
- **튜터 쪽:** 따라 말한 차례면 튜터는 그것을 새 말로 받지 않고, 짧게 받은 뒤 하던 이야기를 이어 간다(지금 `retry: pass` 길).
- **소리:** 띠는 소리 없이. 🔊를 누르면 바른 문장만 소리로(튜터 목소리, 이미 쓰는 /api/tts — 첫 번째는 캐시).
- **화면 규칙:** 띠 안에는 짚기 한 줄 · 문장 · 버튼만 둔다(RULES 4 "화면엔 이름·숫자·상태만"). 띠가 왜 뜨는지 같은 설명은 모드 ⓘ 설명창에만.
- **아랍어 앱:** 띠 바깥은 RTL, 학습 언어 문장은 `dir="auto"`. 띄어쓰기 없는 학습 언어는 칠하기를 `wordSegments`로.

## 4. 코치는 누구인가 (7-2에서 정함)

| 안 | 내용 | 좋은 점 / 걸리는 점 |
|---|---|---|
| **가. 같은 언어 짝 튜터(추천)** | 언어마다 튜터가 둘(남·여, 28명) — 고르지 않은 쪽이 코치 | 얼굴·이름·소개가 이미 있다(`tutorAbout.ts`). 사람 탭 "AI 튜터 둘"과 이야기가 맞는다. 단, 그 튜터와도 통화하면 역할이 바뀐다 |
| 나. 따로 코치 하나 | 모든 언어에 같은 코치 캐릭터 | 역할이 늘 분명하다. 얼굴·이름·14개 언어 소개를 새로 만들어야 한다 |
| 다. 얼굴 없는 띠 | 📝 아이콘만 | 가장 가볍다. "제3튜터" 느낌은 없다 |

## 5. 수업에만 있던 것은 어디로

| 수업에 있던 것 | 한 구조에서 |
|---|---|
| 요즘 배운 말 화제(`recentLearned`) | **모든 대화 통화**의 감독 재료로. 처음 코치 띠 하나에 "오늘 써 볼 말" 칩 둘~셋 — 대화에서 쓰면 ✓(감독 `aim: used` 이미 있음). U47·점검의 "수업 시작이 자유대화와 같다"가 여기서 풀린다 |
| 말로 짚기 세 마디(`coachRules`) | 지움. 감독은 "say = 대화만, 교정은 note·better·meant·offer에"로. 튜터 말이 짧아져 목소리 비용·차례 지연이 준다 |
| 다시 말해 보기(`retry` ask·pass·miss) | 코치 띠 + 앱 채점(위 3절). 감독의 `retry`는 "따라 말한 차례인가" 표시로만 남긴다 |
| 숙제 [퀴즈 \| 대화] | 코치가 하나라도 짚은 통화면 끝 화면에 숙제(`homeworkQuiz.ts` 그대로 — 짚은 말·장면 조각) |
| 침묵 7초 + 튜터가 "들렸어요?" | 하나로: 침묵이 길면 코치 띠에 💡(시작 한 조각). 튜터는 묻지 않는다 — U48 "들렸어요? 반복"이 사라진다 |
| 수업 설명창 세 줄(`callInfoLesson1~3`) | 지움. 대화 설명창에 코치 한 줄 |

**게임에서 코치는 이렇게 한다:**
- 🎲 스무고개: 내 질문이 틀리면 코치 띠만 뜨고, 게임 흐름(튜터 예/아니오)은 안 멈춘다.
- 🧑‍🏫 가르치기: 튜터의 앱 언어 실수는 내가 고친다(지금 그대로). 내 학습 언어 설명의 실수는 코치가 고친다. 두 교정이 다른 자리에 보여서 헷갈리지 않는다.

## 6. 모델·비용

- **감독을 부르는 횟수는 그대로다.** 코치가 쓰는 `note`·`better`·`meant`·`smoother`·`offer`는 지금도 같은 감독 답 JSON에 있다. 코치 때문에 모델을 더 부르지 않는다.
- **목소리는 준다.** 수업에서 말로 하던 짚기와 바른 문장을 튜터가 더는 소리 내지 않는다. 코치는 소리가 없고, 🔊를 누를 때만 소리가 난다.
- **채점에는 모델이 없다.** 다시 말해 보기 채점은 앱 낱말 대조(`compareToTarget`·`triedRedo`)로 한다.
- `opCost`·`modelCalls`에 새 op는 없다. 통화 1분 단가는 수업 기준이면 조금 내려간다 — 만들 때 `npm run sim:economics`로 확인한다.

## 7. 정할 것 (사용자)

1. **문을 몇 개로:** **셋 [📞 대화 · 🎲 게임 · 🧑‍🏫 가르치기](추천)** — 문은 "무엇을"만 고르고 코치는 늘 있다 / 하나 📞 — 게임·가르치기는 통화 안에서 고르기(층위 규칙 "무엇과 어떻게를 같은 층에 두지 않는다"에는 셋이 맞다).
2. **코치는 누구:** 4절 가(짝 튜터, 추천) · 나 · 다.
3. **코치를 끌 수 있게 할지:** 없음(추천 — 띠는 넘기면 접히니 방해가 적다) / 통화 머리 ⋮에 "코치 끄기".
4. **언제:** **2.80 전에(추천)** — 🎓 문은 아직 Play에 나간 적이 없다(2.80이 처음). 2.80에 문 넷으로 내보내고 나서 다시 바꾸면 사용자가 두 번 헷갈린다.

## 10. 순서 (정해지면)

1. 감독 지시: say는 대화만, 교정은 필드로. 운영 en/ko·ja/ko·es/ar로 짚기 비율이 지금 수업과 같은지 본다.
2. 코치 띠: `CoachCardView` 넓히기 + 다시 말해 보기 채점 + 🔊. `/dev/call-preview`에 띠 상태를 더한다.
3. 문 셋·통화 기록 칩·설명창·옛 것 지우기.
4. 요즘 배운 말 칩·숙제를 모든 대화 통화에.
5. 사용법 장면 다시 찍기, 새로워진 점 94에 한 장.
6. 기기 확인: 띠가 말하는 중에 방해되지 않는지, 🎤 다시 마이크 전환, 소리 겹침.
