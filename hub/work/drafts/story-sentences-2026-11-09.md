# 이야기 → 문장 나눔 시험 (스페인어 5단계, 2026-11-09)

> 사용자 "앱 안의 단어·문법·표현을 종합해 문단(이야기)을 만들고 문장을 나눠 주는 방식" → "한번 만들어줘". 이 채팅(탭 2)이 직접 씀.

## 방법
1. 예문 없는 5단계 낱말 33개를 주제(음식·건강·집·쇼핑·시간)로 묶음 + 5단계 문법·표현.
2. 같은 낱말 묶음으로 이야기 둘(A 루시아 독감 22문장 · B 파블로 저녁 25문장) — 문장마다 혼자 읽어도 뜻이 통하게(대명사 대신 이름).
3. `scripts/story/analyze.ts`: 문장마다 낱말 빈칸(pieceAt) · 문법(탭 3 `sentence-index/es-rules.mjs`) · 표현 · 문장구조(framesInLine) → 낱말마다 다른 이야기에서 예문 둘(문장 하나는 낱말 셋까지) → `word-sentences.ts --merge es … --src made`.
4. 원본 `scripts/story/es/5a-lucia-pablo.tsv`.

## 결과
- 문장 47 → 낱말 33개 모두 예문 둘(66칸), 빈칸 실패 0, merge 뺌 0. 단어마다 쓰면 66문장 → 47문장(0.71배).
- 문장 하나당 잡힌 대상 평균 3.6(낱말·문법·표현·문장구조). 5단계 문법 3칸(si hubiera · quería 누그러뜨리기 · lo que 강조 · o sea), 표현 3(me saca de quicio · a lo mejor · o sea), 문장구조 4.
- 문법 규칙 잡음: "명사의 성·수"·"규칙 -ar 현재형"이 넓게 잡힘(탭 3 보고와 같음) — 문법 예문으로 쓸 땐 5단계 칸만 고르는 게 안전.

## 남은 것
- 낱말만이 아니라 문법·표현 칸 예문으로도 넣으려면 탭 3 문장 색인과 저장 꼴을 맞춰야 함(inbox → 탭 3).
- 이야기 자체(읽기 자료)를 앱에서 쓸지는 사용자 결정.
- 스페인어 남은 3,575낱말을 이 방식으로: 이야기 하나(25문장)에 낱말 15~17개 → 약 220이야기.
