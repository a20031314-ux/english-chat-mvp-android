# 표현 장부 설계 (초안, 2026-10-15)

> 사용자 요청: "학습한 걸 확인하고 축적을 측정". 탭 연결(2단계)과 지도 넓히기(3단계)는 이 장부 위에서 돈다.
> 상태: 설계안. 사용자 확인 후 구현.

## 왜 필요한가

배운 것이 탭마다 따로 있다.

| 지금 있는 기록 | 어디 | 무엇 |
|---|---|---|
| 지도 미션 결과 | 서버 | 지도 표현의 숙지·배운 것·알아야 할 것 |
| 이해도(comprehension) | 서버 | 튜터 말에서 찾아본 표현: 찾아봄 → 설명 들음 → 이해함 → 사용함 |
| 자주 틀리는 것 | 서버 | 실수 종류(문장 X) |
| 영어 구문 프로필 | 서버 | 영어만, 구문별 맞음/틀림 |
| 단어장 | 기기 | 저장한 단어 |
| 영상 저장 | 기기 | 저장한 자막 문장 |

같은 표현을 영상에서 보고, 단어장에 넣고, 채팅에서 써도 서로 모른다. "이 언어로 무엇을 꺼내 쓸 수 있게 됐나"를 한곳에서 볼 수 없다.

## 무엇을 만드나

학습 언어마다 **표현 장부** 하나. 이해도 기록을 넓혀서 만든다(새 저장소를 따로 두지 않음).

### 표현 하나에 담는 것

| 필드 | 예 |
|---|---|
| 표현 | `end up` (학습 언어, 60자까지, 학습자 문장 X) |
| 상태 | 만남 → 배운 것 → 숙지 (+ "들으면 앎" 표시) |
| 처음 만난 곳 | 영상 · 「Friends S1」 0:42 / 채팅 / 통화 / 단어장 / 지도 |
| 만난 곳들 | 최근 5개 (탭 + 영상이면 영상 id·초) |
| 꺼내 쓴 기록 | 최근 5개 (언제, 어디서: 채팅·통화·미션·복습) |
| 지도 연결 | 지도 주제·미션 id (있으면) |

### 상태 규칙 (지도와 같은 규칙)

- **만남**: 찾아봄, 분석함, 질문함, 저장함, 지도에서 할 일을 받음.
- **배운 것**: 힌트·교정으로 해냄, 설명을 듣고 저장함.
- **숙지**: 도움 없이 맞게 꺼내 씀 — 미션 무힌트 통과, 또는 8시간 넘게 지나서 채팅·통화에서 교정에 살아남게 씀.
- 숙지 뒤 틀리게 쓰면 배운 것으로.
- "들으면 앎"(튜터 말에 두 번 나왔는데 다시 안 찾아봄)은 상태가 아니라 표시. 숙지는 꺼내 쓸 때만.

### 측정 (레벨은 여전히 안 보여줌)

- **숙지한 표현 수**: 주별 누적 그래프(최근 26주).
- **유지율**: 숙지한 표현 중 최근 30일에 다시 맞게 쓴 비율.
- **어디서 배웠나**: 탭별 비율 (영상 40% · 채팅 35% …) — 2단계 탭 연결의 바탕.
- 주마다 한 줄씩 저장(숙지·배운 것·만남 수), 지난 기록을 다시 계산하지 않음.

## 이벤트 (어디서 장부에 들어오나)

| 이벤트 | 지금 | 바꿀 것 |
|---|---|---|
| 찾아봄·분석·질문 | 있음 (탭 정보 없음) | 어느 탭인지, 영상이면 영상 id·초 같이 |
| 단어장 저장 | 있음 | 탭 정보 |
| 영상 자막 저장 | 기기에만 | 장부로도 보냄 (표현만) |
| 채팅에서 씀 | 지도 표현만 확인 | 장부 전체와 대조 |
| 통화에서 씀 | 지도 표현만 확인 | 장부 전체와 대조 |
| 미션 결과 | 지도 쪽에만 | 장부에 같이 반영 |

모델 호출 추가 없음. 대조는 지금 쓰는 `findExpression`(띄어쓰기 없는 언어·한국어 조사 처리).

## 화면

지도 탭 위쪽 "부족한 부분" 패널 자리를 **"내 표현"**으로 넓힌다.

- 한 줄 요약: `숙지 42 · 배운 것 18 · 만난 것 73` + 이번 주 +5
- 누르면 시트: 주별 누적 그래프, 유지율, 탭별 비율, 표현 목록(상태·탭으로 거르기). 표현을 누르면 만난 곳(영상이면 그 장면으로), 꺼내 쓴 곳.
- 학습 언어를 바꾸면 그 언어의 장부(1번 "언어별 분리 명확화"와 같이).

## 개인정보

지금 원칙 그대로: 학습자가 쓴 문장은 저장하지 않고, 표현(튜터 말·자막·단어장에서 온 것)과 시각·탭만. 기기에만 있던 단어장·영상 저장을 서버 장부에 올리는 것은 새로운 일이라 사용자 결정 필요(아래).

## 단계

1. **장부 데이터**: 이해도 기록 확장(v2) + 미션 결과 합치기 + 이벤트에 탭 정보 + 채팅·통화 대조 + 주별 기록. API `GET /api/learner/ledger?lang=`.
2. **화면**: 지도 탭 "내 표현" 요약과 시트, 14개 언어.
3. (다음 단계) 탭 연결 표시, 지도 넓히기.

## 사용자에게 정할 것

1. 기기에만 있는 단어장·영상 저장 표현을 장부(서버)에 올릴지. 추천: 올림(표현만, 문장 X). 기존 저장분도 한 번 올림.
2. 숙지 규칙을 지도와 똑같이 할지. 추천: 같게 (도움 없이 + 8시간 간격).
3. "내 표현"을 지도 탭 안에 둘지, 따로 탭을 만들지. 추천: 지도 탭 안 (탭 5개 유지).
