# 섞어 말하기 통화 (설계, 2026-11-08 — 아직 코드 아님)

사용자: "초보 사용자를 위해 … 사용자의 언어로 대화하는 기능" · "핵심은 중간에 영어 대화로 이동 가능해야 해. 우리 영어로 말해볼까? OK why not! → 대화 진행 → 또 막히면 다시 섞어서."

가르치기(튜터가 내 모국어를 배우는 역)의 거울. 튜터는 앱 언어로 천천히 말하며 학습 언어 조각을 끼우고, 학습자는 섞어서 대답.

## 한 통화 안의 두 상태

| 상태 | 튜터 | 학습자 |
|---|---|---|
| 섞기 | 앱 언어 + 조각 하나(두 번 들려줌), 쓰면 조각을 키움(낱말 → 덩어리 → 한 문장) | 섞어서, 앱 언어만이어도 됨 |
| 학습 언어 | 자유대화처럼 학습 언어만, 그 단계 낱말 | 학습 언어 |

- **섞기 → 학습 언어:** ① 튜터 제안 — 조각을 잘 쓴 차례가 이어지면 학습 언어로 "우리 영어로 해 볼까?" → 예면 넘어감 ② 학습자가 언제든 말로("영어로 해요") ③ 머리 칩 [섞기 | English] 손으로.
- **학습 언어 → 섞기(막힐 때):** 3초 침묵 두 번 · 🙉 두 번째 · 앱 언어로만 대답 · 감독 stuck — 튜터가 앱 언어로 "괜찮아요, 섞어서 해요" 하고 **같은 화제**로 이어 감. 칩으로도.
- 상태는 앱이 들고 차례마다 감독에게 넘김(스무고개 답처럼 — 판 가운데 흔들리지 않게). 감독 답에 `"mix": "on" | "off"`(바꿀 때만).
- 받아쓰기는 두 상태 모두 [학습 언어, 앱 언어] 두 언어(listen의 languages, Room이 이미 씀) — 학습 언어 상태에서 앱 언어로 말한 것도 알아들어 섞기로 돌아가는 신호가 됨.

## 그 밖
- 채점: 학습 언어 조각만 낱말 대조(replay.ts pieceSaid, 모델 없음). 앱 언어는 고치지 않음. 학습 언어 상태는 자유대화와 같은 고친 말 카드.
- 자막: 섞기 줄은 앱 언어, 조각만 칠함(누르면 소리). 아랍어 앱은 `dir="auto"`, 띄어쓰기 없는 학습 언어 조각은 wordSegments.
- 기록: 쓴 조각 → 장부 활용, 끝 화면 "쓴 말 n개 · 학습 언어로 n차례"(늘어나는 게 보이게), 숙제 퀴즈는 지금 것.
- 다음 통화: 지난 조각부터, 지난번에 학습 언어로 넘어간 차례 수에 맞춰 더 일찍 제안.

## 튜터 설정(정함, 사용자 2026-11-08)
- 튜터 = 학습 언어 원어민인데 앱 언어도 대화는 되는 사람(원어민급 아님). 목소리는 지금 튜터 그대로(억양이 캐릭터와 맞음).
- 같은 캐릭터가 두 쪽에: 초급 섞어 말하기는 그 앱 언어로 도와주고, 고급 가르치기는 튜터의 앱 언어 실수가 재료 — 앱 언어 문장 하나에 실수 하나 → 학습자가 학습 언어로 "you can say …" 고쳐 주고 설명(코드 반영 2026-11-08, callGames.ts teach).

2. 조각: 그 단계 낱말·표현 은행(추천) / 튜터가 흐름대로.
