# 대화 화면 하나로: AI 채팅·통화를 사람 대화 문법으로 (초안, 2026-10-23)

> 사용자: "AI와 채팅·통화와 사용자 간 상호작용이 기능 자체는 똑같은데 AI 학습 쪽이 좀 조잡해. 통합 또는 정리 전략 구상해줘."
> 상태: **만듦(2026-10-23, 사용자 "2,3단계까지 해줘", 앱 다음 빌드 — 웹은 push로 바로).** 정할 것 2~5는 초안대로(통화 첫 화면 없앰·줄 버튼 접기·통화 교정 ✎ 칩·세션 없앰). 근거는 네 화면 나란히 조사(ChatWindow·Roleplay*·RoomDm/RoomGroups·RoomView/RoomParts, 2026-10-23).

## 지금 무엇이 조잡한가 (조사 결과)

| | AI 채팅 | AI 통화 | 1:1·단체방 | 사람 통화(Room) |
|---|---|---|---|---|
| 첫 화면 누를 곳 | 약 8 | **9~12** + 지난 통화마다 2 | 7~8 | 25~30(방이라 많음) |
| 한 턴마다 늘어나는 누를 곳 | **5~10**(레일 2·🔊 2·✎·해석·⚑·표현 칩 최대 5) | 줄마다 3~6 | 0(말풍선 자체가 누르는 곳) | 0 |
| 내 줄 교정 | ✎ 칩 → 말풍선 안 | **자동으로 펼침** 2종 + 메모 | DM: 말풍선 누르면 / 단체방: **없음** | ✎ 칩 → 따로 카드 |
| 상대 줄 번역 | 말풍선 아래 "해석" 버튼 | 위 "해석" 토글 + 점선 누르기 | 말풍선 누르기 | 줄 누르기 |
| 문장 분석 | 이름 없는 세로 레일 | 끝난 뒤 "분석" 알약 | 없음 | 없음 |
| 기록 | ⋮ → 채팅 기록 서랍 | 첫 화면 아래 "지난 대화" | 대화 목록 + 대화 안 🗒 통화 기록 카드 | → 그 대화의 카드 |
| 끝내기 | ⋮ → 세션 종료 | 중단 / 닫기 / 돌아보기 | ← 뒤로 | 나가기 / 방 닫기 |
| 화면 속 설명 글 | 입력칸 "…로 써보세요", 오늘 해볼 것의 이유 줄 | "편하게 아무 얘기나…", 팩 문구 여럿, 개인정보 안내, 이월 안내 | 거의 없음 | 없음 |

- 사람 쪽은 **줄 하나 = 누르는 곳 하나**(누르면 번역 → ❓·↩·✉, 길게 누르면 삭제), 입력칸 하나(📷·🙂·학습 언어로·보내기). 같은 일을 하는 AI 쪽은 줄마다 버튼이 붙고 이름이 제각각.
- 말 다름: 해석/번역, 이어서 하기/이어서 대화, 써볼 표현/써 볼 표현, 닫기/중단/뒤로/나가기.
- 안 쓰는 화면 코드: `ArchivePanel.tsx`(그려지는 곳 없음).

## 원칙

1. **사람 대화의 문법이 기본, AI는 그 위에 더하기만.** AI 튜터는 대화 목록의 한 사람이고, 열면 1:1과 같은 대화 화면.
2. **줄에는 버튼을 달지 않는다.** 줄을 누르면 그 줄의 할 일이 한 줄로 열린다(번역·듣기·분석·묻기·답하기·…). 줄 아래 상시로 남는 건 ✎ 칩(고칠 곳 있음)과 "표현 보기"(편한 말로 쓴 줄)뿐.
3. **교정은 어디서나 같은 칩.** 채팅·통화·1:1·단체방·Room 모두 내 줄 아래 "✎ 고칠 곳이 있어요" → 누르면 그 자리에 고친 문장. 눌러서 보기/바로 보기 설정 하나가 전부에 적용.
4. **세션·첫 화면 대신 하나의 대화.** AI 튜터와의 대화는 1:1처럼 계속 이어지고, 통화는 그 대화 안에 🗒 통화 기록 카드로 남는다(돌아보기도 그 카드에서).
5. **학습 데이터는 그대로 쌓고, 화면에서만 덜어낸다.** 교정·표현 장부·자라는 중 기록은 지금처럼 매 턴. 줄마다 붙던 표현 칩은 My와 줄 누르기 안으로.

## 그림

```
대화 목록   AI 튜터 ─ 오늘 카드(오늘의 팩 · 오늘 해볼 것 하나로) · 단체방 · 1:1          ← 첫 화면 카드가 여기로

대화 화면 (AI 튜터·1:1·단체방 같은 틀)
  머리    ←  이름  📞  ⋮(새 대화·고친 문장 보기 방식·신고)
  줄      상대 줄 누르기 → [번역 · 🔊 · 분석 · ❓ 묻기* · ↩ 답하기]      *AI면 튜터에게 바로 물음
          내 줄 아래 ✎ 고칠 곳이 있어요 / 표현 보기   ·   길게 누르기 → 삭제 · 신고
          🗒 통화 기록 카드 → 펼치기 · 돌아보기(막힌 곳·다시 말해보기)
  입력칸  📷 · 🙂 · [입력] · 학습 언어로 · 보내기          (AI는 빈 대화에서만 "먼저 말하기")

통화 화면 (AI 통화·1:1 통화 같은 틀)
  머리    이름 · 남은 시간(AI) · 번역 켜기 · 끝내기
  줄      받아쓴 줄(같은 줄 문법) · 내 줄 ✎ 칩
  아래    마이크 · (팩이면 n/12)
  끝나면  대화로 돌아가 🗒 통화 기록 카드가 맨 아래에
```

- **AI 통화 첫 화면을 없앤다:** 📞를 누르면 1:1처럼 바로 통화. 오늘의 팩은 대화 목록 AI 튜터 아래 "오늘" 카드(시작하기)로, 남은 무료 시간은 통화 머리의 상태로,
  개인정보 안내는 처리방침·iOS AI 동의로(규칙: 정책 문구는 화면에 두지 않음), "내 문장 말해보기"는 문장분석 시트·노트의 "말해보기"로, "지난 대화"는 대화 안 통화 기록 카드로.
- **AI 채팅의 세션 종료를 없앤다:** 1:1처럼 하나로 이어짐. 지난 대화 서랍 대신 ⋮ "새 대화"(이전 것은 위로 스크롤·날짜 구분선). 기록 저장 방식(기기 localStorage)은 그대로.
- **사람 쪽도 얻는 것:** 줄 누르기 안의 🔊·분석이 1:1·단체방·Room 줄에도 생기고, 단체방 내 줄에도 ✎ 교정(지금 없음).

## 잃는 것·조심할 것

- 줄 아래 표현 칩("○○에서 만난 표현", "숙지로 올라갔어요")이 안 보이면 "쌓이는 느낌"이 줄 수 있다 → 숙지로 올라간 순간만 줄 아래 한 번(상태라 규칙상 허용), 나머지는 줄 누르기·My.
- 통화 교정을 접으면 말하는 중에 고친 문장을 덜 본다 → 통화도 "바로 보기" 설정을 따르게(기본값을 통화만 바로 보기로 둘지 결정).
- 오늘의 팩이 통화 첫 화면에서 빠지면 눈에 덜 띌 수 있다 → 대화 목록 맨 위 카드(AI 튜터 바로 아래). 다 하면 접힘.
- 세션을 없애면 오래된 대화가 길어진다 → 튜터 문맥은 지금처럼 최근 몇 턴만 보내고, 화면은 날짜 구분선.
- 손이 많이 가는 곳: `ChatWindow.tsx`(2,136줄)·`RoleplayScreen.tsx`(1,167줄). 2단계는 화면을 바꾸지 않고 부품만 옮기는 커밋과 화면을 바꾸는 커밋을 나눈다.

## 정할 것

1. 방향: **통합(2·3단계까지)** / **정리만(1단계)**.
2. AI 통화 첫 화면을 없애고 📞 바로 시작 + 오늘 카드는 대화 목록으로 — 괜찮은지.
3. 줄 위 버튼(🔊·해석·분석·신고)을 줄 누르기 안으로 접기 — 괜찮은지.
4. 통화 교정: 지금처럼 자동으로 펼침 / ✎ 칩(채팅 설정을 따름).
5. AI 채팅의 "세션"을 없애고 1:1처럼 하나로 이어지게 — 괜찮은지.
