# 노트 = 언어별 뼈대 + 짚은 장면 (2026-10-23)

사용자 흐름: My 목록이 쭉 나열되고 기준이 모호함 → "학습 중 또 틀리면 저번에 틀린 표현임을, 막힐 때 여기가 부족하다고" → "짚은 부분을 My에 설명과 기록" →
"언어별 기본 뼈대(필수 문법·어휘·알파벳)를 두고 기록을 노트식으로 그 칸에, 사용자가 편집해 키우고 AI는 어디에 넣을지만" →
"뼈대도 단계적으로, 수준이 오르면 추가 내용과 함께 리팩토링해 다음 단계로" → "만들어줘"(저장은 계정 B).

## 정한 것
- 뼈대는 **손으로 쓴 고정 자료**: 글자·소리 = `curriculum/scripts`(언어별 묶음), 문법 = `curriculum/stages`(언어마다 5단계 × 7~8개), 어휘·표현 = 예전 노트 목차(`notes/outline.ts`).
- 문법은 **지금 단계까지**(시작 단계 고르기 `selfCheck.stage`, 없으면 1단계). 앞 단계는 "이전 부분"에 접음. 레벨 이름·숫자 없음.
- 카드 = 튜터가 고친 줄: 내가 쓴 줄(✗) → 고친 줄(✓) + 한 줄 설명(앱 언어) + 어디서·언제. 같은 틀림→고침은 한 장(시각만 새로).
- AI(`notes` 작업 = Haiku)는 **칸 고르기 + 한 줄 설명**만. 맞는 칸이 없으면 "아직 자리 없음" + 새 칸 이름 제안(사용자가 "만들기"). 하루 60장까지 모델, 넘으면 자리 없음으로.
- 사용자 편집: 칸 이름 바꾸기(뼈대 칸은 원래 이름으로 되돌리기 = 빈 이름), 내가 만든 칸 더하기·지우기(카드는 자리 없음으로), 카드 옮기기(이후 AI가 안 옮김)·메모·지우기, 칸 메모.
- 저장: `notebook:v1:<id>:<언어>`(계정·학습 id 지우면 함께). 학습자 문장 저장 예외(RULES "데이터·보안"), 처리방침 en·ko에 한 줄.
- 화면: My → 노트 맨 위 [글자·소리 · 문법 · 내가 만든 칸 · (아직 자리 없음)] + 숫자(짚인 수), 그 아래 "어휘·표현" 예전 목차. 칸 목록은 짚인 수 많은 순 → 많은 칸이 곧 "여기에 집중". 설명 글 없음.

## 단계
1. **(2026-10-23 만듦)** 뼈대·카드·AI 칸 고르기·편집 — 채팅 교정·통화 고친 줄에서.
2. `↻ 지난번에도` 꼬리표(교정 카드, 같은 칸에 카드가 이미 있으면) · `자주 막히는 곳 → 연습`(통화 막힘·편한 말 질문 때 2주 2번 이상 칸) — 누르면 그 칸이 열림.
3. 단계 올리기: 지금 단계 칸의 혼자 쓰기 비율·짚인 수 감소·목표 대화 → "다음 부분 열기" → 미리 보기(새 칸, 익힌 칸 합치기 + AI 요약 한 줄, 아직 자주 틀리는 칸은 그대로 위로) → 승인 → 되돌리기. 사용자가 만든 칸·메모·옮긴 카드는 안 건드림.

## 남은 것(1단계)
- 1:1·단체방·Room "다듬어 보기" 고친 줄은 아직 카드로 안 들어감.
- 확인 모델(chatVerify)이 교정을 바꿔도 카드는 처음 교정 그대로.
- 예전 노트의 표현·단어·질문은 어휘·표현 목차에 그대로(문법 칸으로 옮기지 않음).
- 사용법(?) 노트 칸 글·그림, 새로워진 점 — 버전 자를 때.
