# 노트 (My) — 브리지 노트를 언어 학습으로 (설계안, 2026-10-19)

> 사용자 생각: "지도"라는 개념이 애매하다. 예전에 만든 전자공학 **브리지 노트**처럼 My를 학습 노트로.
> 브리지 노트: 목표를 넣으면 **커리큘럼(섹터 지도·추천 순서)과 레슨 내용까지 생성**, 레슨의 아무 부분이나 골라
> **질문하기 → 답이 그 자리에 주석으로**, 쉬운 설명 추가, **메모(필기)**, 강의자료 첨부, **나무위키 같은 전체 검색**
> (주제·노트·질문·메모·슬라이드 + "AI에게 어디를 읽을지 묻기").
> **사용자 결정(2026-10-19):** 이름은 **노트**, **난이도 없음**, **뼈대는 모두 같게**. 공부하다 "이거 넣고 싶다"를 담아 두면 맞는 자리에 들어가 업데이트.
> 상태: 설계안. "정할 것" 답을 받은 뒤 1단계부터.

## 0. 통합안 (사용자 2026-10-19: "기존 지도·망/그래프·데이터 수집·단어장을 통합해서 노트 프레임워크로 만들어도 된다")
새 교재를 먼저 만들지 않고, **이미 있는 것들을 노트라는 틀 하나에 다시 담는다.** 1단계에 새 AI 생성이 없다.

| 노트의 자리 | 채우는 것(지금 있는 것) |
|---|---|
| 표지 | 망·그래프(자라는 중) — "이 노트가 얼마나 자랐나" |
| 목차(장 8 × 주제) | 고정 목차. 이미 그린 지도의 주제·미션·진행은 맞는 주제로 옮김 |
| 주제 쪽 | 그 주제의 할 일(미션) · 숙지/배운 것/알아야 할 것 표현(장부) · 자주 틀리는 것 · 영상 장면(대사 색인) · 그 주제로 연습(채팅·통화) |
| 표현 문서(위키) | 장부의 표현 + **단어장 단어**(단어장이 표현 문서로 합쳐짐) — 뜻·처음 만난 곳·상태·쓴 곳·나오는 장면·써보기 |
| 내 주석 | 문장분석 질문·답(지금 이해도 기록), 알아요/모르겠어요, 메모 |
| 담아 둔 것 | 지금 "지도에 넣기"·단어 저장이 들어오는 곳 |
| 검색 | 위 전부를 기기에서 |

그다음 단계에서 주제 쪽에 **공유 생성 레슨**(아래 2장 — 장면·핵심 표현·문형·단어)을 얹는다. 즉 데이터로 먼저 채우고, 비는 곳을 레슨이 메운다.
단어장 탭은 노트의 "단어·표현 문서" 보기로 들어가고, 하단 탭에서는 빠질 수 있다(정할 것 6).

## 1. 한 줄
노트는 **처음부터 내용이 차 있는 교재**다. 목차와 레슨은 학습 언어마다 모두에게 같고(한 번 만들어 모두가 씀),
그 위에 **내 주석(질문·답·쉬운 설명·메모)과 내가 담아 온 것**이 쌓여 나만의 노트가 된다. 모든 것은 위키처럼 검색되고 서로 링크된다.

## 2. 뼈대 = 목차 + 레슨 (비어 있지 않음)

### 목차 — 모두 같음
장 8개 × 장마다 주제 3~5개 = 주제 약 30개. 장·주제 이름은 14개 UI 언어 고정(목차 자체는 모델이 만들지 않음).

| 장 | 주제 예 |
|---|---|
| 1. 나와 사람들 | 자기소개 · 가족과 친구 · 하는 일 |
| 2. 하루 | 아침부터 밤까지 · 집에서 · 시간과 날짜 |
| 3. 지난 일 | 어제 한 일 · 다녀온 곳 · 있었던 일 이야기하기 |
| 4. 앞으로 | 계획 · 약속 잡기 · 바라는 것 |
| 5. 생각과 느낌 | 좋고 싫음 · 이유 말하기 · 동의와 반대 |
| 6. 부탁과 해결 | 부탁하기 · 문제 말하기 · 사과와 감사 |
| 7. 밖에서 | 가게·식당 · 길과 교통 · 숙소·여행 |
| 8. 일과 공부 | 회의와 대화 · 메일·메시지 · 질문하기 |

### 레슨 — 주제마다 한 쪽, 학습 언어 × UI 언어로 한 번 생성해 모두가 공유
1. **먼저 해보기** — 할 일 하나(지금 미션: 할 일만, 힌트 3단계, 확인·교정). 핵심 가치 1번 "먼저 해보게" 때문에 레슨 맨 위.
2. **장면** — 짧은 대화(6~8줄, 학습 언어, 줄마다 듣기 — 공유 TTS 캐시).
3. **핵심 표현** 5~8개 — 표현 · 언제 쓰나(UI 언어) · 예문 둘.
4. **문형** 1~2개 — 짧은 설명 + 바꿔 말하기.
5. **단어** 8~12개.
6. **실제로 들어보기** — 그 표현이 나오는 영상 장면(지금 영상 대사 색인).
7. **할 일 더** — 미션 3~5개(지금 그대로).

- 생성은 처음 누군가 그 (학습 언어, UI 언어, 주제)를 열 때 한 번, 서버에 저장해 다음 사람부터 바로(지금 영상 자막 번역 공유와 같은 방식).
  14×14×30 = 5,880쪽이 최대지만 실제로 열리는 조합만 만든다. 자주 쓰는 조합(ko→en, ja→en …)은 미리 만들어 둘 수 있다.
- 난이도 없음: 레슨은 하나. 사람마다 맞추는 건 **"쉬운 설명 추가"(주석)** 와 할 일·튜터의 쉽게/조금 어렵게(지금 학습자 요약)로만.
- 레슨이 틀리면 고칠 길: 줄마다 신고(지금 AI 답변 신고) → 다음 생성 때 반영, 운영자가 의견함처럼 보고 "다시 만들기".

### 처음 체크
목차를 바꾸지 않고 **어디부터 볼지**(추천 순서)와 "오늘 해볼 것"만 정한다. 예: "여행" → 7장이 맨 앞. 지금 `selfCheck.pitchFor`(초급/중급)는 쓰지 않는다.

## 3. 내 주석 — 레슨 위에 쌓는 것 (브리지 노트의 선택 막대 그대로)
레슨의 아무 부분(점을 끌어 고르기 — 지금 문장분석의 고르기 재사용)을 고르면:
- **질문하기** → 답이 그 부분에 노란 표시로 붙음(누르면 질문·답). 빠른 질문 3개(무슨 뜻? / 왜 이런 형태? / 비슷한 표현?)도 그대로.
- **쉬운 설명 추가** → 그 부분 아래에 더 쉬운 설명(내 노트에만).
- **메모** → 내 필기(글, 사진 첨부 가능).
- **알아요 / 모르겠어요** → 장부 표시(지금 그대로).
주석은 **나만의 것**(공유하기 전까지). 레슨 본문이 다시 만들어져도 주석은 고른 글자를 찾아 다시 붙고, 못 찾으면 그 주제 아래 "떨어진 주석"으로.

## 4. 담기 — 다른 탭에서 "이거 넣고 싶다"
채팅·통화(내 줄+고친 문장, 튜터 말, 도움말)·오늘의 팩 돌아보기·영상 장면·문장분석 답·말하는 방과 메시지(남의 줄+물은 것과 답)·단어장에 📌.
- **자리 찾기:** 주제 약 30개 중 맞는 곳을 AI가 고르고 한 줄 이유(지금 `/api/curriculum/pick`을 "고정 목차 중 하나"로 단순화, 여러 개를 한 번에).
  학습자는 "확인 / 다른 주제" 한 번. 안 정한 것은 노트 맨 위 **담아 둔 것**에.
- 들어가면 그 레슨의 **맞는 단락 옆**에 카드로 붙는다(단어 → 단어, 고친 문장 → 문형·표현, 영상·방 줄 → 장면·실제로 들어보기). 원래 자리로 가는 링크 포함.
- 표현이 들어 있으면 장부에 "고름", 그 주제에 할 일 하나(지금 "내가 고른 것" 규칙).

## 5. 검색 — 나무위키처럼
- 노트 맨 위 검색칸 하나. 결과를 묶어서: **레슨**(주제·단락) · **표현 문서** · **내 주석**(질문·답·메모) · **담아 온 것** · **영상 장면**. 거르기 칩(브리지 노트 `spFilters`).
- **표현 문서:** 표현마다 자동으로 한 쪽 — 뜻·예문(레슨에서) · 나오는 레슨 · 내 주석 · 처음 만난 곳·상태(장부) · 영상 장면 · 비슷한 표현.
  레슨 본문의 핵심 표현·단어는 그 문서로 가는 링크(위키 내부 링크). 내가 처음 찾은 표현도 문서가 생긴다.
- **"AI에게 어디를 읽을지 묻기"**(브리지 노트 그대로): "부탁할 때 정중하게 하려면?" → 읽을 레슨·단락 3곳과 이유, 누르면 그 자리로. 모델 한 번.
- 검색 자체는 기기에서(레슨·주석·장부 사본 텍스트), 모델 없음.

## 8. 저장·언어·비용
- **공유 레슨:** 서버 `lesson:v1:<학습언어>:<UI언어>:<주제id>`(지우지 않음, 판 번호). 학습자 데이터 아님.
- **내 것(주석·메모·담은 카드·사진):** 학습자 문장이 들어가므로 "학습자 문장은 서버에 안 둔다"의 예외(본인이 남긴 것만).
  로그인한 사람은 서버 `notes:v1:<dataUserId>:<학습언어>`, 아니면 기기. 로그인하면 기기 것을 올릴지 묻는다.
- **언어:** 레슨 본문은 학습 언어 + UI 언어 설명. UI 언어를 바꾸면 그 UI 언어 판 레슨(없으면 생성), 내 주석은 쓴 언어 그대로.
  띄어쓰기 없는 언어의 고르기·링크·검색은 `wordSegments.ts`. 아랍어 앱은 레슨 본문 `dir="auto"`.
- **비용:** 레슨 생성(조합당 한 번) · 질문하기(지금 직접 질문 한도) · 쉬운 설명(같은 한도) · 자리 찾기(묶어서, 차감 없음 추천) · 어디를 읽을지(같은 한도).
  모두 `meterRequest` op + `opCost.ts`. 지도 그리기가 빠져 첫 사용 비용은 줄고, 레슨은 사람이 늘수록 1인당 0에 가까워진다.

## 9. 공유 ("난 이렇게 한다") — 마지막 단계
- 레슨이 모두 같아서, 공유하는 건 **그 위에 얹은 내 것**: 고른 주석·메모·담아 온 카드 + 내 루틴 한 줄. 주제 하나 또는 노트 전체.
- 받은 사람이 같은 레슨을 열면 **남의 주석 겹쳐 보기**(켜고 끔) → "내 노트로 가져오기". 같은 학습 언어끼리, 로그인한 사람만, 신고·숨기기.
- 나중에 많이 가져간 주석은 "많이 단 질문"으로 레슨 옆에 보여 줄 수도 있다(위키의 토론처럼).

## 10. 단계 (통합안 기준)
1. **노트 틀 + 통합**(새 AI 생성 없음): My의 지도 보기 자리를 노트로. 표지(망·그래프), 고정 목차, 옛 지도 주제·미션 옮기기, 주제 쪽(할 일·표현·자주 틀림·영상 장면·연습),
   표현 문서(장부 + 단어장 합침), 문장분석 질문을 주석으로, 기기 검색. 14개 언어 고정 문구.
2. **내 주석 늘리기 + 담기**: 레슨·주제 쪽 어디든 질문하기·쉬운 설명·메모(사진), 다른 탭 📌 → 자리 찾기.
3. **공유 생성 레슨**을 주제 쪽에 얹기(장면·핵심 표현·문형·단어), "AI에게 어디를 읽을지 묻기", 사용법 그림.
4. **공유**(주석 겹쳐 보기·가져오기·신고).

## 11. 정할 것
1. 장 8개·주제 약 30개 — 위 표대로 갈지, 바꿀 것.
2. 레슨 구성(먼저 해보기 → 장면 → 표현 → 문형 → 단어 → 들어보기 → 할 일) — 빼거나 더할 것.
3. 내 것 저장: 로그인은 서버·아니면 기기 (추천) / 모두 기기.
4. 레슨 생성: 열 때 생성 + 자주 쓰는 조합은 미리 (추천) / 모두 미리.
