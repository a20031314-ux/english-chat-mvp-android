# 보이스룸 + 워크스페이스: 사용자 간 학습 (틀, 2026-10-18)

> 사용자 아이디어(2026-10-18 대화). 아직 틀만 — 범위·우선순위·구현은 사용자 확인 후.
> 상태: **시험판 있음(2026-10-18)** — 숨은 입구, 1:1~8명, 자막·번역까지. 아래 "시험판"과 "정할 것".

## 문제

- 기존 언어교환 앱은 비슷한 수준의 두 사람을 전제로 함. 여러 언어를 잘하는 사람은 적고,
  초보는 대화에 못 끼고 눈치 보며 맞장구만 침.
- 그래서 보이스룸 안에 **학습용 워크스페이스**를 넣어, 초보도 방에 있는 것 자체가 학습이 되게 한다.

## 목표: 유창한 대화가 아니라 "참여 → 학습" 4단계

1. **내용 파악** — 실시간 자막, 단어 누르면 뜻.
2. **맥락 파악** — "지금 무슨 얘기 중" 한 줄 요약을 주기적으로.
3. **발화** — 맥락에 맞는 짧은 문장 2~3개 추천 → 골라서 말하기(맞장구 → 점점 길게).
   "도와줘": 편한 말로 쓰면 학습 언어 문장 제안.
4. **누적 학습** — 방에서 나온 표현·내가 한 말·교정된 문장을 세션 뒤 복습으로(지도·표현 장부와 연결).

## 방 구조

- **메이트 방(1:1)** — 목표 언어가 서로 반대인 사람끼리 정기적으로. 시간 반반 언어 바꾸기 기본값.
- **팀 방(3~5명)** — 수준이 섞인 팀, 상급자/원어민이 리더 역할.
- **워크스페이스 공통** — 오늘의 미션 카드(주제·핵심 표현, 수준별 버전), 발언 순서/타이머, 자막·요약·추천 문장.

## 다언어 사용자(튜터) 역할·보상

- 핵심 질문: **상급자가 왜 이 방에 머무는가.**
- 1단계(MVP): 앱 안 보상만 — 튜터 배지·평점·방 개설 우선권, **초보를 도운 방장에게 기간제 VIP권**(헬로우톡 방식 참고).
  기준은 방을 오래 연 시간이 아니라 도움 지표(초보의 "도움 됐어요", 초보 발화 수, 세션 후 복습 생성 수).
- 2단계(나중): 검증된 튜터만 유료 세션(프로 튜터). 현금화는 결제 중개·세금·근로자성·앱스토어 결제 정책 검토 필요(전문가 확인).
- 튜터에게 진행·교정 권한, 초보는 튜터를 평가 → 권한 남용 견제.

## 주의점

- 녹음·자막 데이터 쌓는 데 참여자 동의. 학습자 문장 서버 미저장 원칙(RULES.md)과 어떻게 맞출지 정해야 함.
- 자막만 보느라 듣기를 안 하는 문제(자막 지연 표시 등).
- 어뷰징: 방 켜두고 방치, 친구끼리 평가 몰아주기 → 여러 사람 평가만 인정. VIP는 기간 한정(유료 구매자 형평).

## 정할 것 (사용자)

- MVP 범위: 메이트 방부터? 팀 방부터?
- 음성 인프라(실시간 음성 서비스 선택), 매칭 기준.
- VIP 지급 기준·기간, 기존 요금제(`pricing-2026-10.md`)와의 관계.

## 대화로 정해진 방향 (2026-10-18)

- 화자 구분: 각자 자기 마이크만 받아쓰고, 합치지 않는다. 대화 보기(시간 순서)와 사람별 보기를 사용자가 고름. 번역 맥락은 어느 보기든 시간 순서 앞 줄.
- 비용(30분 1:1, 1인 약 100원): 대부분 받아쓰기·음성 연결. 받아쓰기는 말한 시간만, 자막은 한 번 만들어 모두에게 공유 → 관전자는 거의 0.
- 무료: 입장·관전·자막·하루 일정 시간 말하기. 구독: 줄 번역·분석·질문, 추천 문장, 끝난 뒤 교정·복습, My 반영, 긴 말하기. 방장·튜터는 VIP로 시간 해제.

## 시험판 (2026-10-18)

- 입구: "?" 길게 누르기 → 입장 코드 → 방. 코드를 넣은 기기엔 상단 🎙. 웹은 `?rooms=1`.
- 음성: 사람끼리 직접(WebRTC 메시, STUN만 — 중계 서버 없음, 비용 0). 말하기 자리 8, 전체 16.
- 자막: 소리가 커지면 녹음 시작, 1.2초 조용하면 한 덩어리 → `/api/roleplay/listen`(gpt-4o-mini-transcribe) → 줄. 서버 시계로 시작 시각 맞춤.
- 아직 없음: 신고·차단·강퇴, 무료 시간 한도, 구독 구분, 추천 문장·교정·My 반영, 14개 언어.

## 헬로우톡 구조 참고 (2026-10-18, 사용자 스크린샷)

- 방 안: 방장 자리 + 말하기 자리 8(2×4), 관전자 줄("N 다른 참여자"), 손들기(자리 요청), 고정 공지, 텍스트 댓글(댓글마다 번역), CC(자막, 보조 수준), 선물·상점·상자·레벨.
- 목록: 언어 필터(All·영어·한국어·KR⇌EN·상호) + 주제 태그, 방장 Creator 배지, 참여자 수. 1:1 채팅은 메시지 번역·통화, 파트너 찾기는 언어 조합 + 실력 점·필터.
- 빈틈: 말은 흘러가고 댓글만 남음. 우리는 말이 자막으로 남아 번역·복습 자료가 된다.
- 가져올 것: ①손들기 → 방장 승인 ②텍스트 댓글 + 표현 보기(편한 말 → 학습 언어 문장) ③목록 언어 조합 필터·태그 ④고정 공지 자리 = 오늘의 미션 카드.
- 안 가져올 것: 실력 점(수준을 보여주지 않는 원칙), 선물·레벨 수익(구독이 중심).
